## 四、参考答案

> ⚠️ 以下代码在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

### 第1题

**错误类型**：单点/批量规范外取值，属于准确性问题中的"非法取值"类型，根因是标注员误选或工具录入异常，非理解性偏差。

```python
import pandas as pd
d = pd.read_csv("service_annotations.csv")
valid = ["咨询","投诉","闲聊"]
illegal = d[~d["意图标签"].isin(valid) & d["意图标签"].notna()]
print("非法取值记录数:", len(illegal))
print(illegal[["标注记录ID","意图标签"]])

# 纠正：人工复核后按规范修正，此处假设复核结论为"咨询类"→"咨询"，"其他"需逐条人工复核
d.loc[d["意图标签"]=="咨询类", "意图标签"] = "咨询"
```

**实测**：共6条非法取值（"其他"3条、"咨询类"3条）。"咨询类"可直接规则批改为"咨询"；"其他"3条无法自动判断，需人工逐条复核后分类，并检查是否有同类遗漏（即检查是否还有其他拼写变体未被发现）。

### 第2题

```python
d["筛选状态"] = "可用"
d.loc[d["标注依据"].isna(), "筛选状态"] = "待补录"
print(d["筛选状态"].value_counts())
```

**判定依据**：标注依据是审核复核的关键凭证，缺失意味着无法验证该条标注的合理性，故标记"待补录"而非直接判定可用，暂不进入训练集，待补充依据或经复核确认后再转为"可用"。

### 第3题

**A03批次处理**：不能直接判定为"可用"（偏见未经确认处理会污染数据），也不能直接判定"应剔除"（并非所有记录都标错，剔除会浪费可用数据）。正确做法是标记该批次为**"需返工"**，对A03标注过的全部记录进行人工重新审核，逐条确认标签是否正确，确认合格后才转为"可用"，不合格的部分退回重新标注。
