## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

### 第1题

```python
import pandas as pd
d = pd.read_csv("service_annotations.csv")
print("标注依据缺失:", d["标注依据"].isna().sum())
print("意图标签取值:", d["意图标签"].value_counts().to_dict())
```

**实测**：共900条记录，标注依据缺失**12条**（完整性问题）；意图标签出现"其他"（3条）、"咨询类"（3条）等6条非法取值（规范只定义咨询/投诉/闲聊三类，准确性问题）。

### 第2题

```python
print(d.groupby("标注员")["意图标签"].value_counts())
```

**实测**：A01咨询207/投诉58，A02咨询205/投诉64，**A03咨询116/投诉155**——A03的投诉/咨询比例与其他两人明显相反。

**判断依据（不能直接下结论）**：这个差异可能有两种原因——① A03负责的批次原始数据本身投诉类占比就高（任务分配差异）；② A03确实存在把"咨询"偏标为"投诉"的系统性倾向。**必须进一步抽样复核A03标注的具体样本**，对照规范和其他标注员对同类样本的判断，才能确认真正原因，不能仅凭分布数字直接判定为"标注错误"。

### 第3题

**审核报告**：
> **审核对象与范围**：客服对话意图标注数据，共900条，3名标注员。
> **方法与样本**：全量自动化校验+分组对比分析。
> **问题清单**：① 标注依据缺失12条（1.3%）；② 非法标签取值6条（0.7%）；③ A03标注员投诉/咨询比例与其他人显著不同，疑似存在系统性偏差（待复核确认）。
> **量化结论**：完整性问题占比1.3%，准确性问题占比0.7%，均在可接受范围内；A03的分布异常需要进一步抽样复核才能定性。
> **处置建议**：① 标注依据缺失记录标记"待补录"；② 非法取值记录直接按规范修正；③ 对A03标注过的样本抽取20%做人工复核，确认是任务分配因素还是标注偏见后再决定是否需要返工整批数据。
