## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

```python
import pandas as pd
from pathlib import Path

labels = pd.read_csv("transport_labels.csv")
images = set(p.name for p in Path("transport_images").glob("*.jpg"))

missing_img = set(labels["image_file"]) - images
print("标注指向不存在图像数:", len(missing_img))
print("坐标非法(x2<x1):", (labels.x2 < labels.x1).sum())
print("坐标越界(y2>480):", (labels.y2 > 480).sum())
print("类别分布:", labels["label"].value_counts().to_dict())
```

**实测结果**：共106条标注记录。标注指向不存在图像**4条**；坐标非法(x2<x1)**3条**；坐标越界(y2>480)**4条**；类别分布 bus 66条(62%)、car 20条(19%)、bicycle 11条(10%)、truck 5条(5%)、tram 4条(4%) —— **bus类占比过高，tram/truck类样本量过少，分布严重不均衡**。

**处理建议**：
1. 对标注指向不存在图像的4条记录，核查是否因图像文件丢失导致，若确认丢失则删除对应标注记录；
2. 对坐标非法/越界的7条记录，退回标注环节重新核实并修正坐标；
3. 对类别分布不均衡问题，建议针对性补充采集tram、truck类图像，或对现有少数类样本做数据增强，避免模型对少数类识别能力不足。
