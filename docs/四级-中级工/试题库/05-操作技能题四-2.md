## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

### 第1题

```python
import pandas as pd
d = pd.read_csv("cosmetics_sales.csv")
print("销售额缺失:", d["销售额"].isna().sum())
print("会员等级缺失:", d["会员等级"].isna().sum())
print("门店编码取值:", d["门店编码"].value_counts().to_dict())
```

**实测**：销售额缺失120条（15%）；会员等级缺失144条（18%）；门店编码存在大小写混用，共8种取值（应归并为4种）。

### 第2题

```python
print("均值:", d["销售额"].mean(), " 中位数:", d["销售额"].median())
d["销售额"] = d["销售额"].fillna(d["销售额"].median())
```

**实测**：均值约3689.6，中位数约194.0，相差近19倍，销售额呈严重长尾分布。**应使用中位数填充**，因均值会被少数大额订单拉高，用均值填充会系统性高估大多数缺失样本的真实水平；中位数不受极端值影响，更能代表典型水平。

### 第3题

```python
sku_mean = d.groupby("SKU")["销售额"].mean().sort_values(ascending=False)
print(sku_mean.head(5))
```

**实测**：SKU003均值39700.6、SKU022均值28900.9、SKU011均值27164.2，远超正常SKU（通常800-900元），相差约30-45倍，**疑似数量级录入错误**（如单价多打了两个零）。

**处理方案**：不能直接用中位数替代掩盖，应先核实原始价格表或订单记录，确认是否确为录入错误；确认后按正确值修正，并检查是否存在其他同类遗漏的数量级错误SKU。
