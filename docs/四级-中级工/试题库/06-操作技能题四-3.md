### 第1题

```python
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler

d = pd.read_csv("user_behavior.csv")
F = ["访问次数","平均客单价","平均停留时长秒","近30天下单数"]
print(d[F].describe().loc[["min","max"]])

X = d[F]
km_raw = KMeans(n_clusters=4, random_state=42, n_init=10).fit(X)

Xs = StandardScaler().fit_transform(X)
km_std = KMeans(n_clusters=4, random_state=42, n_init=10).fit(Xs)
```

**实测**：平均客单价范围11.61-4983.21元，近30天下单数范围0-25，量纲差异显著。未标准化聚类质量明显低于标准化后（用调整兰德系数ARI对比，未标准化0.533，标准化后0.905）。**结论：必须先标准化再聚类**，否则客单价会主导距离计算，淹没下单数、访问次数等特征的区分贡献。

### 第2题

基于4个分群的典型特征（高频高额/高频低额/低频高额/沉睡用户），设计标签体系：

| 维度 | 取值 |
|---|---|
| **活跃度**（单选） | 高频 / 低频 |
| **消费水平**（单选） | 高额 / 低额 |

**互斥性说明**：两个维度独立单选，组合后恰好对应4个分群（高频高额/高频低额/低频高额/低频低额=沉睡），不存在重叠。
**完备性说明**：活跃度和消费水平两个维度的取值组合已覆盖全部用户情形，无遗漏。
