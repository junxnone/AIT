## 一、审核报告结构

```
审核对象与范围 → 方法与样本 → 问题清单（分类分级）→ 量化结论 → 处置建议
```

审核报告不是审核工作之外额外要交的"作业"，它本身就是审核成果的唯一载体——报告写得不完整，审核就等于白做，因为后面接手处理的人没法据此采取正确行动。五段式里，**最容易被省略、也最容易出问题的是后两段**：

- **量化结论**：必须是具体数字和占比，比如"标注依据缺失12条（1.3%），非法标签取值6条（0.7%）"，而不是"存在少量错误"。为什么？因为后续要不要返工、返工到什么范围，全靠这个数字支撑——"少量"两个字谁都可以写，但支撑不了任何决策。
- **处置建议**：必须对应每一类问题分别给出处理方式，不能笼统写"整体返工"。12条依据缺失和6条非法取值是完全不同性质的问题，处理方式理应不同（见下一节），笼统处理往往意味着成本花错了地方。

**现在回答开头那个判断题**：那份"本批次数据存在少量错误，建议整体返工"的结论，**不能直接执行**。它恰好同时踩中了量化结论模糊、处置建议笼统这两个坑。

## 二、错误类型对应不同纠正方式——不能一刀切

| 错误类型 | 表现 | 纠正方式 |
|---|---|---|
| 单点错误 | 个别记录标注取值非法，且彼此没有共同成因 | 逐条人工核实后分别修正 |
| 批量同类错误 | 大量记录犯同一类错误，背后是**同一种成因** | 用规则批量批改，并回溯检查是否有遗漏的同类记录 |
| 规范理解偏差 | 标注员对某类情形理解有误（如疑似系统性偏见） | 需返工该部分数据，并补充细则到手册防止再犯 |

> ⚠️ **常见错误**：发现任何问题都要求"全部重新标注"，这既浪费成本又没有针对性。应先判断错误的**规模**（孤立/反复出现）和**性质**（执行疏漏/理解偏差），再选对应的纠正方式。

**用本批次的真实数据拆一遍，看清楚"规模"和"性质"到底怎么判断**：

课题2-3发现的6条非法取值，拆开看其实是两种完全不同的情况：

| | "咨询类"3条 | "其他"3条 |
|---|---|---|
| 分布 | A02（2条）、A03（1条），不同的人 | A01（1条）、A03（2条），不同的人 |
| 取值本身 | 比合法标签"咨询"多一个字 | 规范里从未定义过这个取值 |
| 能否直接判断成因 | 能——很可能是同一个输入习惯或工具联想导致 | 不能——必须打开原始对话逐条核实 |
| 应归类为 | **批量同类错误**，规则批改为"咨询"即可 | **3个独立的单点错误**，各自核实 |

这里最容易踩的坑是：**只看取值字符串是否相同，而不去看背后的成因是否相同**。"其他"这3条虽然都用了同一个字符串，但逐条核实后结论可能完全不一样（比如一条该归"闲聊"、一条该归"咨询"、一条该归"投诉"）——结论互相不同，恰恰说明它们不是同一种成因，不能套用一条规则统一改掉。而"咨询类"3条尽管分布在不同标注员身上，但取值构成方式高度一致，可以合理推断是同一种录入习惯造成的，用一条规则就能全部修正。

**判别口诀**：判断是不是批量错误，**看复核结论是否高度一致**，不是看取值字符串是否相同。结论一致 → 批量同类错误，用规则处理；结论互相不同 → 各自独立的单点错误，逐条处理。

**如果把"批量同类错误"误判为"规范理解偏差"，会怎样？** 比如把"咨询类"也当成理解偏差处理，要对A02、A03做专项培训——但这3条的真正原因可能只是一个输入习惯，培训成本花错了地方，而且培训完问题照样存在，因为根本没有人真正"理解错了"。

## 三、数据筛选三档

审核完成后，数据应被分为三档，并且每一档都要**说明判定依据**：

- **可用**：审核通过，无需处理
- **需返工**：存在规范理解偏差或批量错误，需重新标注后再审核
- **应剔除**：原始数据本身存在问题（如内容无效），无法通过标注修复

以课题2-3的发现为例：标注依据缺失的12条记录标记为"待补录"（不直接进入训练集，等待补充依据后再确认是否可用）；若复核确认A03存在系统性偏见，其负责批次需整体标记"需返工"，重新审核后才能转为"可用"。

**"待补录"为什么不直接归入可用/需返工/应剔除三档中的任何一档？**

因为这12条记录的标注本身**对不对，暂时无法验证**——标注依据是审核复核的关键凭证，缺了它，既没有证据证明标注错了（不能判"需返工"），也没有证据证明标注是对的（不能直接判"可用"），更不能因为缺证据就认定原始数据有问题（不是"应剔除"）。所以用一个过渡态"待补录"来如实反映"证据不全、暂不确定"这个真实状态，而不是为了图省事随手归到最近的一档。**筛选的本质是对"能否验证"这件事保持诚实。**

**A03批次为什么不能直接剔除，也不能直接判可用？**

A03一共负责300条记录，如果确认存在系统性偏见就直接把300条全部剔除，等于把其中实际标注正确的部分也一起浪费掉了；但如果因为"大部分应该没问题"就标记为可用，偏见造成的错误样本就会混进训练集，模型会学到这个系统性偏差。正确做法是标记"需返工"，对300条逐条重新人工审核，确认合格的转为"可用"，确认有问题的再返工或剔除——这和三级课题讲过的"标注员系统性偏见"诊断流程是一脉相承的：先承认不确定，再想办法验证，不能跳步直接下结论。

## 随堂练习

**练习 1**：审核发现某批标注中有5条记录的标签取值明显打错字（如"投拆"应为"投诉"），这属于哪种错误类型？该怎么处理？

<details><summary>答案</summary>单点错误（打字疏漏，非理解偏差）。应直接按规范修正这5条记录的取值，无需对整批数据返工或重新培训标注员。</details>

**练习 2**：为什么把"批量同类错误"误判为"规范理解偏差"会导致处理方向完全用错？

<details><summary>答案</summary>批量同类错误往往是执行层面的技术性疏漏（比如某个脚本bug或工具故障导致的固定模式错误），只需要用规则批量修正即可解决；而规范理解偏差是标注员认知层面的问题，需要返工数据并补充细则培训。如果把执行层面的问题当作认知问题处理，会投入大量返工和培训成本，但没有真正解决根源问题（根源可能只是一个需要修复的工具bug）。</details>

**练习 3**：审核报告的"量化结论"部分，为什么不能写"存在一些错误"这种模糊表述？

<details><summary>答案</summary>模糊表述无法支撑后续的处置决策。合格的量化结论应该是具体数字，如"抽检200条，发现标注依据缺失12条（6%），非法标签取值9条（4.5%）"，这样的结论才能让读者判断问题的严重程度，并据此决定是否需要返工、返工范围有多大。</details>

**练习 4**：数据筛选的"可用/需返工/应剔除"三档，为什么每一档都必须说明判定依据？

<details><summary>答案</summary>因为筛选结果直接决定了哪些数据能进入训练集，如果没有判定依据，别人（包括算法团队和后续审核的人）无法判断筛选是否合理，也无法在发现问题时追溯是哪个环节、哪条标准导致了错误的筛选决定。判定依据是保证整个流程可追溯、可核查的关键。</details>

**练习 5**：若复核确认某标注员存在系统性偏见，其负责的全部批次应该直接标记为"应剔除"吗？

<details><summary>答案</summary>不应该。直接剔除会浪费该批次中实际标注正确的数据。正确做法是标记为"需返工"，对该批次全部记录重新人工审核，确认合格的转为"可用"，确实存在问题的部分再返工或剔除，而不是因为标注员存在偏见就一刀切剔除全部数据。</details>
