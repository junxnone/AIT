## 一、两个审核维度

- **完整性审核**：该标的字段有没有漏标（必填字段是否齐全）
- **准确性审核**：标注的取值对不对（是否符合规范、是否在合法取值范围内）

**为什么要把这两件事分开看，不能只做一种？**

因为它们失败的方式完全不同，检测方法和后果也完全不同。一条记录可以字段填得整整齐齐、格式规范，但标注内容是错的——这是**准确性问题**，完整性检测（查有没有空值）完全查不出来；反过来，一条记录"标注依据"写得清清楚楚，但"意图标签"这个核心字段压根没填——这是**完整性问题**，哪怕你把标出来的内容反复核对一百遍，也发现不了"它根本没标"。

**只做一种检测，另一种问题会被完全放过**——这也是为什么"完整性审核和准确性审核是同一回事，检测其中一个即可"这种说法是错的：两者是互补的不同维度，必须分别检测，谁也替代不了谁。

## 二、实操：自动化校验 + 标注员对比

```python
import pandas as pd
d = pd.read_csv("../数据集/service_annotations.csv")
print("标注依据缺失:", d["标注依据"].isna().sum())
print("意图标签缺失:", d["意图标签"].isna().sum())

合法取值 = ["咨询", "投诉", "闲聊"]
非法取值记录 = d[~d["意图标签"].isin(合法取值) & d["意图标签"].notna()]
print("非法取值记录数:", len(非法取值记录))
print(非法取值记录["意图标签"].value_counts().to_dict())

print(d.groupby("标注员")["意图标签"].value_counts())
```

**实测**：

- 标注依据缺失 **12条**——完整性问题
- 意图标签缺失 **3条**——同样是完整性问题（而且这个字段比标注依据更核心：标注依据缺了，至少标签还在、记录还能用；意图标签缺了，这条记录等于白标，必须补标）
- 非法取值记录 **6条**："其他"3条、"咨询类"3条（规范只定义了咨询/投诉/闲聊三类）——准确性问题
- 标注员对比：A01咨询207/投诉58，A02咨询205/投诉64，**A03咨询116/投诉155**——A03的投诉/咨询比例与另外两人明显相反

> 💡 代码里的 `df["列"].isin(合法取值列表)` 是审核代码里最常用的一招：判断某一列的值是不是都落在一份"白名单"里，不在白名单里的就是潜在的非法取值。这个写法实操题和单选题都会直接考，记住它。

**只看到A03这个差异，能直接下结论"A03标注错误"吗？不能。**

可能的原因不止一种：

1. A03负责的批次本身投诉类占比就高（任务分配不均导致的客观差异）
2. A03确实存在系统性偏见（把本应标"咨询"的对话偏向标成"投诉"）

**这两种原因造成的统计结果一模一样**，光看分布数字根本分不出是哪一种。必须进一步抽样复核A03标注的具体样本，对比其他标注员对同一批/同类对话的标注结果，才能确认真正原因。这和三级课题2-2"标注员偏见"的诊断流程是一脉相承的——**先描述现象，再深挖归因，不能止步于发现差异就下结论**。

**如果跳过复核直接下结论，后果是什么？** 如果真相是"任务分配不均"，你去培训或处罚A03，既冤枉了人，也没解决真正的问题——下一批任务分配不均，差异还会再出现；如果真相是"系统性偏见"，你没有发现，这批带偏见的数据会原样交付去训练模型，模型学到的就是同样的偏差。两种误判的代价都不小，这就是为什么"抽样复核"这一步不能省。

## 三、更可靠的审核方法：多标注员交叉复核

开头那个判断题，现在可以揭晓答案了。这批数据的设计很特别：**每条对话都由3位标注员独立标注**，这意味着我们可以不止看"一个标注员的分布"，还能直接看"同一条对话，3个人标的是不是一样"。

```python
import pandas as pd
d = pd.read_csv("../数据集/service_annotations.csv")
valid = d.dropna(subset=["意图标签"])
per_dialog = valid.groupby("对话ID")["意图标签"].nunique()
print("参与复核的对话总数:", len(per_dialog))
print("三人标签完全一致的对话数:", (per_dialog == 1).sum())
print("存在分歧的对话数:", (per_dialog >= 2).sum())
print("分歧占比: {:.1%}".format((per_dialog >= 2).sum() / len(per_dialog)))
```

**实测**（已验证，你的结果应与此完全一致）：

```
参与复核的对话总数: 300
三人标签完全一致的对话数: 167
存在分歧的对话数: 133
分歧占比: 44.3%
```

**开头判断题的答案：不可靠。** 全量复核发现，**接近一半的对话（44.3%）存在标注员意见分歧**。质检员随手抽到的那10条恰好全部一致，很可能只是运气好，落进了167个"三人一致"的对话里，根本没有代表性。

**为什么小样本抽查会"骗人"？** 不是质检员不认真，而是抽样本身的统计特性：167/300≈55.7%的对话本身就是三人完全一致的，这个比例**比分歧率44.3%还高**。随手抽10条，命中"一致"对话的概率反而更高——**样本量太小，就撑不起"整体没问题"这个结论**。

> 🔑 **判别口诀**：抽查结果好看，不代表总体没问题；**样本代表性不够，再好看的抽查结果也只是巧合**。

## 四、抽样审核的方法与样本量确定

上面这个坑，指向了一个常被忽视的问题：抽样比例该怎么定？不能拍脑袋写"抽10条"或"统一抽10%"了事，至少要想清楚三件事：

**第一，抽样比例要和数据规模、下游用途挂钩。** 数据量越大、用途越关键（比如要喂给模型训练），抽样比例应该越高，必要时改用全检，而不是无论什么场景都用同一个固定比例。

**第二，对小众类别、重点类别要单独提高比例甚至全检。** 本例中"闲聊"类只有86条，如果整体按10%比例抽，闲聊类可能一条都抽不到——这个类别的质量就完全没被审核到。这正是"分层抽样"要解决的问题：**按类别/批次分层后各自抽样，而不是对全体数据不分青红皂白地统一抽一个比例。** 分层抽样的作用不是"抽得更多"，而是"保证每一类都被覆盖到"。

**第三，出现异常信号后，要对异常对象提高复核比例。** 比如A03这种分布明显异常的情况，应该比常规抽样比例更高（甚至全检A03标注过的对话），而不是继续用统一比例应付了事。

> 🔑 **判别口诀**：抽样比例"一刀切"是外行做法；**按类别分层、按异常程度加码**，才是训练师该有的抽样方案。

**容易被忽略的另一个信号——标注时间**：数据里的"标注时间"字段同样可以拿来审核。如果某个标注员在短时间内连续产出大量标注、间隔异常短，这不一定是作弊，但很可能是赶速度导致判断潦草——应当作为抽样复核时优先抽取的对象，而不是因为"速度快"就默认这个人能力强、可以少抽查。

## 随堂练习

**练习 1**：审核发现某批次标注的"闲聊"类占比明显高于其他批次，这说明什么？该怎么处理？

<details><summary>答案</summary>不能直接下结论。需要先确认：该批次的原始数据本身是否闲聊类占比就高（如来自某个闲聊场景更多的渠道），还是负责该批次的标注员存在把其他类别误标为"闲聊"的倾向。应抽样复核该批次具体样本，对照规范判断标注是否正确，再决定是数据特性还是标注问题。</details>

**练习 2**：标注"依据"字段缺失12条，这属于完整性问题还是准确性问题？

<details><summary>答案</summary>完整性问题——必填字段没有填写，属于"该有的信息没有"，而不是"信息本身不正确"。准确性问题指的是已填写的内容是否正确，比如标签取值错了，而字段整体缺失是完整性维度的问题。</details>

**练习 3**："发现差异→不下结论→抽样复核→再归因"这个诊断顺序，为什么不能跳过中间两步？

<details><summary>答案</summary>因为差异背后可能有多种原因（任务分配不均、原始数据特性不同、标注员真实偏见等），不抽样复核具体样本就无法判断究竟是哪种原因。跳过这两步直接下结论，很可能把"任务分配导致的客观差异"误判为"标注员的主观错误"，导致处理方向完全错误（比如冤枉了没有问题的标注员，或者错过了真正需要纠正的系统性偏见）。</details>

**练习 4**：标注员之间标签分布不同的可能原因有哪些？请列举至少两种非"标注员能力问题"的原因。

<details><summary>答案</summary>①任务批次分配不均——不同标注员分到的原始数据本身类别分布就不一样；②原始数据本身特征不同——比如某批次来源渠道的内容天然偏向某一类。这些都不是标注员能力或态度问题，但表现出来的统计结果和"标注员真的有偏见"是相似的，必须靠抽样复核来区分。</details>

**练习 5**：制定审核方案时，抽样比例和重点类别全检之间是什么关系？

<details><summary>答案</summary>常规抽样比例（如10%）适用于整体数据的常规质量把关，而对业务重要性高、样本量小的关键类别，或者审核中发现异常的类别/标注员，应该采用全检而非抽样，以确保不遗漏潜在的系统性问题。两者是互补关系，不是互相替代。</details>
