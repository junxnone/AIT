# 四级/中级工 自学使用说明

本文件夹是为**完全没有老师、没上过课**的自学者准备的第三类材料——不同于"教案"（教师授课用）和"学员讲义"（配合课堂使用），这里的材料假设你手边没有老师、没有课堂进度，要独自把四级/中级工全部13个课题学完并备考。

本文件夹下有三类材料，定位不同、适用阶段也不同：

## 一、苏格拉底问答自学（`苏格拉底问答自学/`）—— 建立直觉，适合初次接触

5份文档，用对话式提问-引导-解答的方式，像一位辅导老师坐在你身边，先抛出一个判断题让你自己想，再带你一步步推导出结论，而不是直接把结论摆给你背。覆盖全部13个课题：

| 文档 | 覆盖课题 |
|---|---|
| 01-四级定位与基础工具 | 0-1、0-2、0-3 |
| 02-数据质量六维度与检测实操 | 1-1、1-2 |
| 03-数据处理方法优化与建议书撰写 | 1-3、1-4 |
| 04-数据聚类标注设计与审核全流程 | 2-1、2-2、2-3、2-4 |
| 05-智能系统运维与功能优化 | 3-1、3-2 |

**适合什么阶段用**：第一次接触某个课题的知识点时用，目的是建立"为什么是这样"的直觉和机制理解，不追求覆盖所有考点细节。每篇结尾有1-2道自测题，不提供标准答案——合上文档自己想清楚，才算真的理解了，直接翻答案是在骗自己。

## 二、自学教材（`自学教材/`）—— 系统学习，覆盖全部考点

每课题一份，内容融合了（深化后的）教案讲授脚本和学员讲义正文，以"自学者旁白"的口吻重新组织，不依赖课堂、从头读到尾就能自学完成，篇幅比苏格拉底问答篇更完整、更系统，考点覆盖也更全。

**适合什么阶段用**：对某个模块已经有了基本直觉（读过对应的苏格拉底问答篇）之后，再系统通读自学教材，把该课题要求的全部知识点、操作细节一次学扎实，不留遗漏。

## 三、速查手册（`速查手册.md`）—— 考前冲刺，不讲道理只给结论

一份文件，按13个课题顺序分节，每节只给**核心考点、关键规则/数据、易错点**，不包含任何讲解过程，追求信息密度和检索速度。已经存在于本文件夹下，可以直接打开使用。

**适合什么阶段用**：考前最后冲刺，已经系统学过（至少读完自学教材或上过正式课程）、只需要在考前快速过一遍所有知识点、查缺补漏的时候用。**不建议作为第一次学习某个知识点的入口**——它默认你已经理解了背后的道理，只是帮你唤醒记忆。

---

## 建议的学习顺序

```
苏格拉底问答自学（建立直觉，知道"为什么"）
        ↓
自学教材（系统学习，覆盖全部考点，知道"是什么、怎么做"）
        ↓
速查手册（考前冲刺，快速过一遍，不再重复讲道理）
```

三类材料不是互相替代关系，而是**同一批知识点在不同学习阶段的三种呈现方式**——第一次学追求"理解", 系统学追求"全面", 考前追求"速度"。如果你时间紧张，至少应该完整走一遍"苏格拉底问答自学 + 速查手册"这两类，跳过系统学习直接刷速查手册，很容易变成死记硬背，遇到实操题或场景变化题容易翻车。
