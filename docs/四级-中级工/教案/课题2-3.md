## 一、教学目标

### 知识目标
1. 能区分准确性审核（标得对不对）与完整性审核（该标的有没有漏标）。
2. 能说明抽样审核的方法与样本量确定思路。
3. 能说明"发现标注员间统计差异"与"确认系统性偏见"之间必须经过抽样复核这一步，不能把统计差异直接等同于归因结论。

### 技能目标
1. **能制定审核方案**。
2. **能用pandas实现标注数据的自动化校验**。
3. **能通过多标注员交叉复核识别数据中潜在的标注分歧**，为审核方案设计抽样/复核机制提供依据。

### 素养目标
1. 养成"发现差异→不下结论→抽样复核→再归因"的审核工作习惯，不因追求效率而跳过验证环节。

---

## 二、教学重点与难点

**重点**：区分必填字段缺失（完整性问题）与标注错误（准确性问题）。

**难点**：学员容易止步于"发现标注员之间标签分布不同"，不去深挖是否存在系统性偏见——即只做描述性统计，不做归因分析。

---

## 三、学情分析与前置知识

**前置知识**：课题2-1（聚类分析）、课题2-2（归类定义与标签体系设计）。

**学情判断**：学员已学完课题2-1、2-2，对pandas数据分析操作较为熟练，能熟练完成 `isna()`、`value_counts()`、`groupby()` 等常规统计调用。但"审核"这项四级核心能力要求的不只是跑出统计数字，还要能对异常现象做归因判断——这正是学员最容易卡住的地方：看到一个标注员的标签分布和别人不一样，就急着下"这个人标错了"的结论，跳过了"这个差异到底是谁造成的、为什么"这一步。此外，学员对"抽查几条看看"这种经验式审核方法比较依赖，对"抽多少条才够、为什么这么定"缺乏系统认识，需要本课题专门补上这一块。

---

## 四、教学方法与手段

1. **认知冲突法**：先让学员用小样本抽查下结论，再用全量数据的真实分歧率推翻过于乐观的判断。
2. **自动化校验演示法**：用代码演示审核可以部分自动化（缺失值、非法取值检测），但归因判断必须人工介入。
3. **数据实证法**：全程用同一份真实数据集（`service_annotations.csv`）串联审核的四个层次——完整性检测、准确性检测、分布差异归因、交叉复核，让学员看到审核是一套连贯方法而非孤立的代码片段。
4. **任务驱动法**：以"产出一份可交付的审核方案"作为本课题终产物，并通过分组互评典型不合格方案强化"能判断别人方案的问题"这项更高阶能力。

### 环节一：导入（0–15′）

**教师活动**——投影展示（不给结论）：

> "某批客服对话的意图标注任务，每条对话都安排了3位标注员独立标注（这样设计是为了互相校验）。质检员工作很忙，随手从900条记录里抽了10条看了看，发现这10条里三位标注员给出的标签都完全一致，于是在审核报告里写：『抽查结果一致性良好，本批数据审核通过。』"

**提问话术**：

> "大家说，这个审核结论靠谱吗？如果是你，会不会也这样审？"

（停顿，等待反应，可追问："抽10条看，和把900条全部看一遍，结论会一样吗？"）

**设计意图**：不直接否定，让"抽几条看着都对就算通过"这种经验式审核的直觉先被说出来，后面用真实分歧率数据反转。

---

### 环节二：新授——审核两个维度与审核流程（15–35′）

**讲授脚本**：

> "标注数据审核要回答两个完全不同的问题。第一个问题：**该标的字段，有没有漏标？**——这是完整性审核。第二个问题：**标出来的东西，对不对？**——这是准确性审核。
>
> 这两个问题互相独立：一条记录可以字段齐全但标错了（完整性没问题，准确性有问题），也可以标注依据写得很清楚但漏填了核心字段（完整性有问题，准确性未必有问题）。审核方案如果只查一个维度，另一个维度的问题就会被完全放过。"

**板书核心句**：

> **完整性：该填的地方是不是空的（漏标）。准确性：填的内容是不是对的、合规的（标错）。**

**审核流程框架**（板书，先给框架，后面每个实操环节对应填充其中一步）：

```
自动化校验（机器能查的：缺失、非法取值）
        ↓
描述性统计（标注员/批次维度对比，发现分布差异）
        ↓
抽样/交叉复核（人工介入，确认差异的真实原因）
        ↓
归因与处理（任务分配问题 / 系统性偏见 / 其他）
```

**学员活动**：记录两个维度的定义与审核流程四步，举出自己过去标注工作中见过的"完整性问题"和"准确性问题"各一例。

### 环节四：关键讨论——差异≠结论（难点突破，65–90′）

**教师提问（难点突破核心）**：

> "只看到A03和其他人不一样，能直接下结论吗？"

**预期学员反应与教师应对**：

| 学员反应 | 教师应对 |
|---|---|
| "能，A03标注有问题" | 追问："你凭什么排除了'A03负责的批次本身投诉类占比就高'这个可能性？你看过A03具体标的是哪些对话吗？" |
| "不能，需要再看看" | 追问："那具体该看什么？只说'再看看'不够，要讲清楚看什么、怎么判断。" |
| "可能是A03偷懒乱标" | 追问："偷懒乱标会是什么表现？是集中偏向某一类，还是随机分散？A03的116/155是集中偏向'投诉'，这和'乱标'的表现一样吗？" |

**教师总结**：

> "不能直接下结论'A03标注错误'。至少有两种可能：
> 一是**A03负责的批次本身投诉类占比就高**（任务分配不均导致的客观差异，不是A03的问题）；
> 二是**A03确实存在系统性偏见**（把本该标'咨询'的对话习惯性标成'投诉'）。
>
> 这两种可能表现出来的统计结果**一模一样**，光看分布数字根本区分不了。**必须进一步抽样复核A03标注的具体样本**，对照其他标注员对同类对话的判断，才能确认真正原因。
>
> 记住这个顺序：**发现差异 → 不下结论 → 抽样复核 → 再归因**，跳过中间两步直接下结论，是审核工作最常见的失误——而且后果很具体：如果真相是'任务分配不均'，你去培训或处罚A03，既冤枉了人，也没解决问题，下一批任务分配不均，差异还会再出现；如果真相是'系统性偏见'，你没有发现，这批带偏见的数据会被原样交付去训练模型。"

**学员活动**：讨论并记录"接下来具体要看什么、怎么判断"的操作步骤（为环节六的交叉复核做铺垫）。

### 环节六：新授——抽样审核方法与样本量确定（100–125′）

> 📌 **教学提示**：这一环节支撑"知识目标2"，是原教案此前完全没有展开的内容，本轮补齐。

**讲授脚本**：

> "回到导入环节那个场景。质检员抽了10条，三人标签都一致，就写'审核通过'。现在我们可以算一笔账：他抽到'10条全一致'，到底说明了什么？"

（停顿）

> "我们等会儿会用代码对全部900条、300个对话做完整的交叉复核，提前把结论告诉大家：全量复核算出来，**300个对话里有133个存在标注员意见分歧，占比44.3%**。也就是说，这批数据里接近一半的对话，三位标注员给出的标签并不完全一致。"

**认知冲突提问**：

> "分歧率明明高达44.3%，为什么质检员随手抽10条，却可能恰好抽到'全部一致'？"

（引导学员意识到：抽样具有偶然性，样本量太小时，哪怕总体里问题很普遍，小样本也可能"恰好没抽中"问题。本例中167/300≈55.7%的对话本身就是完全一致的，随手抽10条，命中"一致"对话的概率反而更高。）

**板书核心句**：

> **样本量太小、抽样没有章法，"抽查通过"不代表"整体没问题"。**

**抽样方法要点**（讲解）：

> "确定样本量和抽样方式，至少要想清楚三件事：
>
> 第一，**抽样比例要和整体规模、风险承受度挂钩**，不能固定写'抽10条'这种一刀切的数字——数据量越大、后续用途越关键（比如要喂给模型训练），抽样比例应该越高，或者干脆改用全检。
>
> 第二，**对重点类别、小众类别要单独提高抽样比例甚至全检**。本例中'闲聊'只有86条，如果按整体10%的比例抽，闲聊类可能一条都抽不到，这个类别的标注质量就完全没被审核到——这就是试题库里考的'分层抽样'：按类别/批次分层后各自抽样，而不是对全体数据不分青红皂白地统一抽一个比例。
>
> 第三，**出现异常信号（比如某标注员分布明显异常）后，应针对该异常对象提高复核比例**，而不是继续沿用常规抽样比例一视同仁。"

**补充提醒**：

> "数据里还有一个容易被忽视的字段——**标注时间**。如果发现某个标注员在短时间内连续产出大量标注，间隔异常短，这也是一个值得关注的信号：不一定是作弊，但很可能是赶速度导致判断潦草，应当作为抽样复核时优先抽取的对象，而不是因为'速度快'就默认这个人能力强、可以少抽查。"

**学员活动**：讨论"如果你是审核方案设计者，面对A03这个异常分布信号，会把A03标注的对话抽样复核比例定为多少？为什么？"（无标准答案，重点看是否说出"异常信号应提高复核比例"这一原则）

### 环节七：实操二——多标注员交叉复核（125–150′）

**教师指令**：

> "刚才我们'剧透'了44.3%这个数字。现在亲手算一遍，看看是怎么算出来的，顺便验证一下A03的分布差异到底是任务分配问题还是真实偏见。"

**投影代码**（学员照抄运行）：

```python
import pandas as pd
d = pd.read_csv("../数据集/service_annotations.csv")
valid = d.dropna(subset=["意图标签"])
per_dialog = valid.groupby("对话ID")["意图标签"].nunique()
print("参与交叉复核的对话总数:", len(per_dialog))
print("三人标签完全一致的对话数:", (per_dialog == 1).sum())
print("存在分歧的对话数:", (per_dialog >= 2).sum())
print("分歧占比: {:.1%}".format((per_dialog >= 2).sum() / len(per_dialog)))
```

**实测结果（已验证，学员结果应完全一致）**：

```
参与交叉复核的对话总数: 300
三人标签完全一致的对话数: 167
存在分歧的对话数: 133
分歧占比: 44.3%
```

**学员活动**：填写对比表

| | 数值 |
|---|---|
| 一致对话数 | 167 |
| 分歧对话数 | 133 |
| 分歧占比 | 44.3% |
| 随机抽10条，最可能抽到"一致"还是"分歧"？ | |

**关键提问**：

> "167/300约55.7%的对话完全一致，131个对话两种标签并存，还有2个对话三人意见各不相同。随机抽10条，确实更可能抽到'一致'的那一类——但这不代表整体没问题，只是**样本量太小，没能把分歧暴露出来**。这就是为什么刚才强调，抽样比例不能拍脑袋定。"

**追加任务（回应环节四遗留的疑问）**：

> "现在用同样的方法单独验证一下A03。筛出A03标注过的对话，看看这些对话在其他两位标注员手里，标签一致的比例是不是和整体水平差不多，还是明显偏低。"

（引导学员操作：先取出A03标注过的全部`对话ID`，再对这些对话重复交叉复核统计——如果这部分对话的分歧率明显高于44.3%的整体水平，提示这批对话本身争议较大，可能是批次难度问题；如果分歧率与整体接近，则A03与其他人的差异更可能来自个人系统性偏向，而非批次差异。）

**教师总结**：

> "这就是交叉复核的价值：它把'发现差异'到'确认原因'之间的鸿沟，用真实数据而不是猜测填上了。"

### 环节八：实操三——制定审核方案（150–175′）

**任务书**（投影 + 讲义附）：

> 请你为 `service_annotations.csv` 这批客服意图标注数据设计一份完整的审核方案。

**方案必备要素**（教师给模板，学员填充）：

```
一、审核范围与目标
二、完整性审核方法与阈值（必填字段清单、缺失率可接受上限及依据）
三、准确性审核方法（取值合规性检测、标签体系校验）
四、抽样/交叉复核机制（抽样比例依据、异常对象加强复核规则）
五、归因与处理流程（差异→复核→归因→对应处理方案）
六、审核结论的产出格式
```

**教师点拨要点**：

> "两个地方最容易写得不合格：
>
> **第一，只写了完整性和准确性检测，漏掉交叉复核机制。** 环节六、七已经证明了，光靠分布统计发现差异后不去复核，结论随时可能下错。
>
> **第二，抽样比例写死一个数字不说理由。** 要写成'常规类别按X%抽样，异常信号对象/小众类别全检或提高至Y%，理由是……'，不能只写'抽10%'。"

**巡回指导**：重点检查学员是否写出"异常对象应提高复核比例"这一条——这是区分方案是否真正吸收了本课题核心逻辑的关键项。

### 环节九：分组互评与典型错误诊断（175–195′）

**教师活动**：投影展示2-3份教师预先准备的"典型不合格方案"（如：只检测完整性未提准确性；抽样比例固定10%不区分类别和异常对象；发现A03分布异常直接写"建议重新培训A03"），组织学员分组诊断问题所在。

**预期诊断点**：

| 典型错误 | 应诊断出的问题 |
|---|---|
| 方案只写"检测缺失值，缺失率超过5%不合格" | 遗漏准确性审核（非法取值、标签规范性）；缺失率阈值未说明业务依据 |
| 抽样比例写"统一抽10%" | 未对小众类别、异常对象做差异化处理 |
| 发现A03分布异常，方案直接写"建议对A03重新培训" | 跳过抽样复核直接归因，可能冤枉A03（若根因是任务分配不均）或遗漏真实偏见的进一步确认 |

**学员活动**：分组讨论，每组派代表指出至少1处问题并给出修改建议。

**汇报与点评**（约5 min）：每组汇报1处，教师重点点评判别依据而非结论对错。

### 环节十：阶段性小测（195–215′）

**教师活动**：发放5道小测题（覆盖完整性/准确性判别、抽样方法、交叉复核结论解读），当堂巡视，统一讲评。

**题目方向**（示例，正式题目见题库对应区间）：
1. 判断题：给定一个具体问题描述，判断属于完整性还是准确性问题。
2. 简答：说明为什么抽样比例不能统一写死一个数字。
3. 案例判断：给出标注员分布差异场景，判断下一步该做什么。

**学员活动**：独立完成，交卷后对照答案自评。

### 环节十一：点评小结与作业（215–240′）

**知识回顾**（请学员口述，教师补全）：

1. 完整性审核和准确性审核分别回答什么问题？
2. 发现标注员分布差异后，正确的处理顺序是什么？
3. 抽样比例应该依据什么来确定？

**回扣主线**：

> "这节课的核心不是记住'完整性'和'准确性'这两个词，而是建立'**发现差异不等于找到原因**'的审核习惯——10条抽查全部一致，不代表900条都没问题；A03的分布和别人不一样，不代表A03一定错了。都需要用抽样复核把'差异'和'原因'之间的距离填上。下一课题你会看到同样的习惯用在另一个场景：审核报告撰写和数据筛选，怎么把这里诊断出的问题落地成可执行的纠正动作。"

## 七、板书设计

**主板书区**

```
                    标注数据审核两个维度

完整性：该填的地方是不是空的（漏标）        准确性：填的内容对不对、合规不合规

┌──────────────── 自动化校验实测 ────────────────┐
│ 标注依据缺失 12条       意图标签缺失 3条        │
│ 非法取值（其他/咨询类）共6条                    │
└──────────────────────────────────────────────────┘

┌────────────── A03分布差异 ──────────────┐
│ A01 咨询207/投诉58   A02 咨询205/投诉64  │
│ A03 咨询116/投诉155  ← 与另两人明显相反  │
└────────────────────────────────────────────┘
       ↓
   发现差异 → 不下结论 → 抽样复核 → 再归因

┌──────────── 交叉复核实测（300个对话）──────────┐
│ 三人一致 167个(55.7%)   分歧 133个(44.3%)       │
│ → 抽10条很可能恰好抽到"一致"，掩盖真实分歧率    │
└──────────────────────────────────────────────────┘
```

**副板书区（完整性 vs 准确性 判别）**

```
                完整性                准确性
问的是          该有值的地方是否为空   填的内容对不对/合规不合规
本课题例子      标注依据/意图标签缺失   意图标签非法取值6条

判别口诀：先问"有没有填"，再问"填得对不对"
```
