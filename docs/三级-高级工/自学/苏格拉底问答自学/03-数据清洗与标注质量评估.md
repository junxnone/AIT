## 第一部分：数据清洗规则怎么设计，而不是套模板（课题 2-1）

### 1. 先纠正一个误区

四级/五级做清洗，是拿到既定规则去执行。三级要自己设计这套规则，而设计规则的核心难点**不是技术，是判断力**。常见问题类型无非是重复、缺失、异常、噪声、格式不一致这几类，技术上用 pandas 处理都不难，难的是"这条规则该怎么定"。

### 2. 先看一组对比，自己判断哪条规则更合理

学员甲的清洗规则写"删除所有超过100字的评价"；学员乙写"删除超过200字**且内容高度重复**的评价"。

**你会选哪条？为什么？**

甲的规则很武断——长评价不一定是垃圾数据，可能是用户认真写的详细体验，这条规则会把真实有价值的样本误删掉。乙加了"内容高度重复"这个判定条件，更贴近真实业务场景（刷屏灌水的典型特征就是内容重复），不会误伤真实的长篇评价。

**记住这条自检方法**：每条清洗规则写出来之后，自己要能回答一个问题——**这条规则会不会把有价值的真实数据误删？** 回答不上来，说明规则本身需要重新设计判定依据，而不是急着去跑代码。

### 3. 用一份真实的商品评价数据练一下

如果你先随机抽样看20条真实评论，会发现完全重复、空文本、HTML标签、emoji、超长刷屏、超短文本、含手机号邮箱、非法评分（比如0分或6分，超出1-5分的合法范围）这些问题真实存在。针对这些问题，清洗规则大致是这样设计的：

| 处理对象 | 处理方式 | 判定依据 |
|---|---|---|
| 完全重复记录 | 整行去重 | 重复样本会使模型对特定表述过拟合 |
| HTML标签 | 正则剥离 | 标签是采集残留，非用户语义内容 |
| 个人信息（手机号/邮箱） | 替换为占位符，不整条删除 | 合规要求脱敏，但保留样本的情感语义 |
| 超长文本（>200字） | 整条剔除 | 经查为刷屏灌水样本，非真实评价 |
| 非法评分（不在1-5） | 剔除 | 字段定义域为1-5，越界属录入错误 |

**注意看"个人信息"这一行**——为什么是替换为占位符而不是整条删除？因为整条删除会损失该样本里其他有价值的情感语义信息；用占位符替换既满足脱敏合规要求，又保留了样本的可用性。这是比"一刀切删除"更精细化的处理思路，也是三级和四级在同一个清洗任务上的能力差异——四级可能会想"有敏感信息就删掉最省事"，三级要想"怎么处理才能既合规又不浪费数据"。

### 4. 清洗规范文档只写代码够不够

不够。实操评分表里，"判定依据"是独立于代码正确性之外的单独配分项——哪怕代码跑通了，没写清楚每条规则的判定依据，也拿不到满分。规范文档至少要包含适用范围、逐条规则（对象+处理方式+判定依据）、例外情形、产出字段说明。

## 第二部分：从"感觉标得不对"到"量化诊断"（课题 2-2）

现在回到开场那道题：87.8%的一致率，这批数据能交付吗？

### 1. 先看一个极端例子，建立直觉

假设某标注任务只有"是/否"两个选项。找两个完全不懂业务、闭着眼睛随机选的人来标，他们的一致率大概是多少？

**约50%，纯靠概率。** 这意味着一致率这个指标的起点不是0，是50%——在二分类任务里，什么都不做就能白拿50分。

更麻烦的还在后面。如果标签分布本身很不均衡，比如95%的样本本来就该标"否"，这两个什么都不懂的人干脆一律标"否"，一致率会是多少？**100%。** 一致率完美，但这批标注有任何价值吗？**零，他们根本没有在做判断。**

问题的本质是：**一致率里混进了"碰巧一致"的成分，而且标签分布越不均衡，这个成分越大。**

回到87.8%——如果"是否礼貌"这个任务里客服本来90%的时候就是礼貌的，那么两个人哪怕不认真判断，一致率也能轻松冲到80%以上。**87.8%这个数字，可能几乎全是碰巧。**

### 2. Cohen's Kappa：把"碰巧"减掉

既然一致率里混进了碰巧，把它减掉就行。这就是 Kappa 做的事：

```
Kappa = (观测一致率 − 期望偶然一致率) / (1 − 期望偶然一致率)
```

分子是实际观测到的一致率减去"纯靠标签分布就能蒙到的一致率"，剩下的才是真正因为标注标准统一而产生的一致。分母表示"扣除碰巧之后，最多还能有多少一致空间"。所以 Kappa 回答的是：**在所有"非碰巧"的一致空间里，你们真正达成了多少？**

判读区间：小于0.2很差（标注标准可能存在严重问题）；0.2-0.4一般；0.4-0.6中等；0.6-0.8良好；大于0.8几乎完全一致。考试不会让你手算这个公式，但要能根据给定的 Kappa 值判断质量、解释反差、提出下一步动作。

### 3. 真实数据——亲眼见证这个反直觉的结果

两组真实标注数据对比：

| | 不均衡组（90%为"是"） | 均衡组（约50/50） |
|---|---|---|
| 观测一致率 | **87.8%** | 76.2% |
| Kappa | **0.217** | **0.524** |
| 一致率判断 | 看起来更好 | 看起来更差 |
| Kappa判断 | 一般，逼近"很差" | 中等 |

**一致率更高的那一组，Kappa反而更低。** 这就是本课题要你亲眼见证的反直觉结果。

### 4. 这里有一道全课程最容易"只拿一半分"的题

如果考试问你"为什么一致率高但Kappa低"，**只答"样本分布不平衡"只能拿一半分**——这说出了原因，但没说出机制。完整答案要有两句话：

> **原因**：标签分布严重不均衡（90%都是"是"）。
> **机制**：不均衡本身就抬高了偶然一致率——两个标注员哪怕完全不认真判断，光靠"多数样本本来就该标是"，碰巧一致的概率就很高。Kappa把这部分扣掉后，发现几乎没有超出偶然一致的部分，所以只有0.217。

**结论**：这两位标注员对真正有判断难度的那部分少数样本，根本没有稳定一致的标准。87.8%是多数类造出来的假象。**这批数据不能交付**——交付出去，模型在关键的少数类样本上学到的全是噪声。

### 5. 拿到低 Kappa 值，下一步不是"重新标一遍"

要先诊断错误属于四种类型中的哪一种，因为不同类型的修复方法完全不同，判错方向等于白干。

**类型一·标准不一致**：标注手册描述模糊，导致不同人理解不同。比如"这个产品质量真不咋地，不过客服态度还行"，有人标负面（提到质量差），有人标中性（夸了客服）——根因在**手册本身**没定义混合情感怎么判定主次。修复：补充细则和边界案例到手册。

**类型二·边界模糊**：两个类别之间天然存在灰色地带，手册写多细都解决不了。比如"你们这物流也太慢了吧，大概还要多久到"，既像投诉又像咨询。修复：引入"模糊/待裁定"中间类别，交由仲裁机制处理。

**怎么区分这两类？** 记一条判别口诀：**把手册写得再细，这个样本能不能确定地归入某一类？能→标准不一致；不能→边界模糊。**

**类型三·标签体系缺陷**：整个分类体系设计有问题，维度混乱、互斥性不足。比如客诉分类设有"物流问题/态度问题/退款问题"，一条"物流延迟导致我要求退款，客服态度还很差"的对话三类全沾边——根因是"物流/态度"是问题来源维度，"退款"是用户诉求维度，两个不同维度被并列成了单选项。修复：重新设计成多维度标签。

**类型四·标注员系统性偏见**：某个标注员在某类判断上持续偏向同一个方向。比如标注员A把几乎所有"轻微负面"都标成"强烈负面"，其他人没有这个倾向——手册和体系可能完全没问题，是具体的人产生了系统性偏差。

**这一类的处理顺序特别容易考，而且特别容易丢分**——题干常会带一句"而不是简单地说重新培训"。这句话不是否定培训，而是否定"不经诊断直接跳到培训"这个顺序。正确顺序是：①先量化偏差程度，确认是系统性单方向偏移而非随机波动；②抽样复核该标注员的样本，确认偏差是全类别还是只在某个维度；③和本人沟通、展示具体错误案例，了解偏差来源；④确认是理解偏差后才做针对性培训，若是难以纠正的个人倾向就调整任务类型或增加复核频次。

**怎么区分"体系缺陷"和"标注员偏见"？** 另一条判别口诀：**是所有人都在同一批样本上分歧，还是某个人持续偏向？所有人→体系问题；某个人→个人偏见。**

### 6. 诊断流程，一句话记住

低Kappa值 → **抽样查看分歧样本**（关键动作，不能只看汇总数字）→ 判断属于四类中的哪一种（或多种并存）→ 对症下药。这个"先看汇总指标、再下钻具体样本"的思路，后面讲模型训练和系统监控时还会再用到，是训练师通用的诊断方法论。

### 7. Kappa、IoU、WER——三个名字，一个逻辑

Kappa 针对离散标签任务（文本情感、意图识别、图像分类）。图像和语音任务的质检指标名字完全不同，但本质是一回事：**独立的标注结果之间，到底有多少是真实共识，多少是巧合或噪声？**

空间区域任务（目标检测、语义分割）用 **IoU**（交并比）= 两个框的重叠面积 ÷ 并集面积。因为两个标注员画的框几乎不可能像素级完全重合，不能用离散的"一致/不一致"判断，业界常用阈值 IoU≥0.5（更严格取0.7）视为一致。

序列文本任务（语音转写）用 **WER**（词错误率）= (替换+删除+插入的词数) ÷ 参考文本总词数。**WER为15%的准确含义是：每100个参考词中，平均有15个词存在替换、删除或插入错误。** 商用成熟ASR系统的WER常在5%~10%，所以15%属于"中等偏可用"——不要笼统说成"质量很差"，训练师要用具体数字描述，不用模糊定性。

**迁移规则，记住这句就够了**：考试给你一个没见过的任务，不要去背"这个任务用什么指标"，只问一句——这个任务的输出是分类、是空间框、还是序列文本？三选一，指标就定了。

### 8. 最后一个陷阱——WER为0就代表没问题吗

如果一个语音转写任务的WER做到了0，是不是说明标注完全没问题？**不是。** WER=0只说明"转写结果和参考文本逐词吻合"，但如果参考文本的转写标准本身就定错了呢？比如团队规定"所有语气词'嗯、啊'一律不转写"，但这个项目恰恰要训练语气分析模型，语气词正是关键信息。那么哪怕所有标注员完美遵守规则、WER做到0，产出的数据对训练目标来说仍然是系统性错误的。

**这是贯穿全课程的一条主线**，本课题里已经出现了三次：一致率87.8%但Kappa只有0.217；WER=0但转写标准本身错了；全体标注员高度一致但分类体系有缺陷。**单一指标变好，不代表真实目标达成，必须有一个独立于该指标之外的检验手段。** 记住这条主线，后面讲模型训练、模型测试、系统监控时它还会反复出现，每次换一个场景，逻辑完全一样。
