# 自学使用说明

本文件夹是为**完全没有老师、没上过课、想独立自学考过三级/高级工**的人准备的第三类材料——和"教案"（给老师上课用）、"学员讲义"（配合课堂使用）是不同定位，彼此不冲突，不需要都读。如果你正在跟班上课，直接用学员讲义即可；如果你是自学，继续看下面的安排。

本文件夹下有三类材料，建议按下面的顺序使用：

## 1. 苏格拉底问答自学（`苏格拉底问答自学/` 文件夹，约5篇）

**定位**：建立直觉、搞懂"为什么"。采用一对一辅导式的对话体——不断向你提问、给你判断的机会，再揭晓答案和背后的机制，而不是直接把结论摆在你面前。内容按模块分组，每篇覆盖2-3个课题，合计覆盖全部12个课题。

**什么时候用**：**最先读**。每开始学一个新模块之前，先读对应的那一篇，目的是让你先对这块内容"有感觉"、知道这里面藏着哪些反直觉的坑，而不是追求记住所有细节。读的时候不要跳过文档里"先自己判断""停一下想想"这些提示，花时间自己先想一遍再看答案，效果会完全不同。

**读完之后应该达到的状态**：知道这个模块大概在讲什么问题、有哪些容易踩的坑，但还记不住具体的公式、流程细节、考点清单——这些留给下一步。

## 2. 自学教材（`自学教材/` 文件夹，每课题一份，共12份）

**定位**：系统学习、完整掌握。每课题一份，内容融合了（深化后的）教案里教师要讲的内容和讲义的正文叙事，以"自学者旁白"的口吻重新组织，不依赖课堂、从头读到尾就能自学完成，篇幅介于教案和讲义之间偏讲义一侧。

**什么时候用**：读完对应的苏格拉底问答篇、对这块内容有了初步直觉之后，再逐课题系统通读自学教材，把知识点、流程、公式、案例、随堂练习都做扎实。这是本文件夹里信息量最完整的一类材料，备考的主干学习应该在这里完成。

> 说明：这个子文件夹的内容建设是另一项工作，如果你发现暂时还没有内容或内容不全，说明还在产出中，可以先用学员讲义顶替系统学习这一步。

## 3. 速查手册（`速查手册.md`）

**定位**：考前冲刺、快速检索。按课题顺序分节，每节只压缩成核心考点、公式/规则、易错点，不重复讲解过程，追求信息密度和检索速度。

**什么时候用**：**留到考前**。不要用它来学新知识——它假设你已经通过前两类材料理解了"为什么"，这里只是帮你在考前几天快速过一遍所有知识点、查漏补缺，或者考场前最后翻一眼易错点列表。

## 三类材料的关系，一句话总结

> 苏格拉底问答篇负责"让你明白为什么" → 自学教材负责"让你把内容学完整" → 速查手册负责"让你考前十分钟内想起所有要点"。

三者内容来源一致（都复用教案与讲义中已经验证过的真实数据和案例，不会出现相互矛盾的数字），只是呈现方式和使用阶段不同。按顺序走一遍，比同时打开三份文档来回对照效率更高。
