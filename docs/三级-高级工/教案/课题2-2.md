## 一、教学目标

### （一）知识目标

1. 能说明**一致率（Agreement Rate）的根本缺陷**——未排除偶然一致成分。
2. 能写出 **Cohen's Kappa 的定义式**，并解释分子分母各自的含义。
3. 能依据 Kappa 值区间，判断标注一致性处于何种水平。
4. 能说明**标注错误的四种类型**及其根本成因的差异。
5. 能说明 **Kappa / IoU / WER 三个指标的共同底层逻辑**，以及为何任务输出形式不同就要换指标。

### （二）技能目标

1. **能用 scikit-learn 计算 Cohen's Kappa**，并对结果作出业务解释。
2. **能解释"一致率高而 Kappa 低"的成因机制**，而不只是复述现象。
3. **能依据质检报告中的错误样例，判定错误属于四种类型中的哪一种，并给出对应修复方案。**
4. **能针对给定分类任务制定一份可交付的标注规范**（标签定义、判定优先级、边界案例、不确定样本处理、质检方式与合格线）。
5. 能依据任务输出形式（离散分类 / 空间区域 / 序列文本）选对质检指标。

### （三）素养目标

1. 建立"**指标好看 ≠ 质量真好**"的职业警觉。
2. 养成**先诊断、再处方**的工作习惯，不跳步给方案。
3. 理解问题归因应**先查制度、再查人**——多数标注质量问题的根因在规范和体系，而非标注员态度。

## 二、教学重点与难点

### 重点

1. Kappa 相对一致率的改进点，以及"刨除偶然一致"的含义。
2. 四种标注错误类型的**判别依据**与**对应修复方案的一一对应关系**。
3. 标注规范的完整要素。

### 难点

| 难点 | 学员典型错误预判 | 突破方式 |
|---|---|---|
| 理解"一致率高而 Kappa 低" | 只答"样本不平衡"，**说出了现象但说不出机制**——说不清"为什么不平衡会抬高一致率" | 不讲公式推导，让学员**亲手跑两组数据对比**：不均衡组一致率 87.8%/Kappa 0.217，均衡组一致率 76.2%/Kappa 0.524。用"一致率更高的反而 Kappa 更低"这个反直觉结果制造认知冲突 |
| 区分"标准不一致"与"边界模糊" | 两者都表现为"标注员意见不一"，学员常混为一谈 | 抓**根因提问**："把手册写得再细，这个样本能不能确定地归入某一类？"能 → 标准不一致（手册问题）；不能 → 边界模糊（数据固有） |
| 区分"标签体系缺陷"与"标注员偏见" | 误判方向会导致修复方案完全用错（去培训人，而不是去重设体系） | 看**分歧是否集中在特定人身上**：全体标注员都在同一批样本上分歧 → 体系问题；只有某个人持续偏向某方向 → 个人偏见 |
| 由"错误类型"推出"修复方案" | **跳过诊断直接给方案**——看到"偏见"就答"重新培训" | 强调实操题评分表是"判断 + 理由"双配分；演示一道题干含"而不是简单地说……"提示的真题式问法 |

### 环节一：导入（0–10′）

**教师活动** —— 投影展示（不给结论）：

> 某语音质检项目要求标注员判断"客服是否使用了礼貌用语"。质检报告显示：
> **两位标注员的一致率为 87.8%。**
> 项目经理据此认为标注质量达标，准备把数据交付给算法团队训练。

**提问话术**：

> "请大家用三十秒判断：这批数据能交付吗？举手表决——认为能交付的请举手。"

（预期：多数学员举手或犹豫）

> "好，先记住你刚才的判断。这节课结束前我们会回来看这个决定会造成什么后果。"

**设计意图**：不急于否定，**让错误判断先被公开表达出来**，后面的推翻才有冲击力。

### 环节二：一致率的根本缺陷（10–25′）

**讲授脚本**：

> "我们先不谈这个 87.8%，换一个更极端的例子。
>
> 假设有个标注任务只有'是/否'两个选项。现在我找两个**完全不懂业务、闭着眼睛随机选**的人来标。他们的一致率大概是多少？"

（引导学员答出 50%）

> "对，纯靠概率就有 50%。也就是说，**一致率这个指标的起点不是 0，是 50%**——在二分类任务里，什么都不做就能白拿 50 分。
>
> 更麻烦的在后面。如果这个任务的标签分布本身很不均衡，比如 95% 的样本本来就该标'否'。现在这两个人还是什么都不懂，但他们学聪明了，**一律标'否'**。一致率是多少？"

（引导答出 100%）

> "一致率 100%，完美。但这批标注有任何价值吗？**零。** 他们根本没有在做判断。
>
> 所以问题的本质是——"

**板书核心句**：

> **一致率里混进了"碰巧一致"的成分，而且标签分布越不均衡，这个成分越大。**

> "回到开头那个 87.8%。如果这个'是否礼貌'的任务里，客服本来 90% 的时候就是礼貌的，那么两个人哪怕不认真判断，一致率也能轻松上 80%。**87.8% 这个数字，可能几乎全是碰巧。**"

---

### 环节三：Cohen's Kappa（25–40′）

**讲授脚本**：

> "既然一致率里混进了'碰巧'，那把它减掉就行了。这就是 Kappa 做的事。"

**板书定义式**：

```
          观测一致率 − 期望偶然一致率
Kappa = ──────────────────────────────
             1 − 期望偶然一致率
```

**逐项解释话术**：

> "**分子**：你实际观测到的一致率，减去'纯靠标签分布就能蒙到的一致率'。剩下的，才是**真正因为标注标准统一而产生的一致**。
>
> **分母**：1 减去偶然一致率，表示'在扣除碰巧之后，最多还能有多少一致空间'。
>
> 所以 Kappa 回答的是：**在所有'非碰巧'的一致空间里，你们真正达成了多少？**
>
> 两个极端：如果观测一致率等于偶然一致率，分子为 0，Kappa = 0——意思是'你们的一致性和瞎标没区别'。如果完全一致，分子分母相等，Kappa = 1。"

**判读区间表**（投影 + 讲义已有）：

| Kappa 值 | 一致性水平 |
|---|---|
| < 0.2 | 很差，标注标准可能存在严重问题 |
| 0.2 – 0.4 | 一般 |
| 0.4 – 0.6 | 中等 |
| 0.6 – 0.8 | 良好 |
| > 0.8 | 几乎完全一致 |

**强调**：

> "**考试不会让你手算 Kappa 公式。** 要考的是：给你一个 Kappa 值，你能不能判断质量、能不能解释高一致率低 Kappa 的反差、能不能据此提出下一步动作。"

### 环节四：实操一 —— 亲手跑出反差（40–60′）

**教师指令**：

> "打开 Jupyter，新建 Notebook。我们来算一下开头那个 87.8% 背后的 Kappa 到底是多少。另外我准备了第二份数据作对照。"

**投影代码**（学员照抄运行）：

```python
import pandas as pd
from sklearn.metrics import cohen_kappa_score

for path, name in [
    ("../数据集/annotation_agreement.csv",          "不均衡组（90% 为'是'）"),
    ("../数据集/annotation_agreement_balanced.csv", "均衡组（约 50/50）"),
]:
    df = pd.read_csv(path)
    a = df["标注员甲_是否礼貌"]
    b = df["标注员乙_是否礼貌"]

    agreement = (a == b).mean()          # 观测一致率
    kappa = cohen_kappa_score(a, b)      # Cohen's Kappa

    print(f"{name}")
    print(f"  标签分布：{a.value_counts(normalize=True).round(3).to_dict()}")
    print(f"  观测一致率：{agreement:.1%}")
    print(f"  Cohen's Kappa：{kappa:.3f}\n")
```

**预期输出**（已实测验证，学员结果应完全一致）：

```
不均衡组（90% 为'是'）
  标签分布：{'是': 0.864, '否': 0.136}
  观测一致率：87.8%
  Cohen's Kappa：0.217

均衡组（约 50/50）
  标签分布：{'否': 0.504, '是': 0.496}
  观测一致率：76.2%
  Cohen's Kappa：0.524
```

**学员活动**：填写对比表

| | 不均衡组 | 均衡组 |
|---|---|---|
| 观测一致率 | 87.8% | 76.2% |
| Kappa | 0.217 | 0.524 |
| 按一致率排序，哪组好？ | | |
| 按 Kappa 排序，哪组好？ | | |

**关键提问**（本课题认知冲突的引爆点）：

> "看这两行数字。**一致率更高的那一组，Kappa 反而更低。**
>
> 这是不是和直觉完全相反？谁来解释一下，为什么会这样？"

**预期学员回答与教师应对**：

| 学员可能的回答 | 教师应对 |
|---|---|
| "因为样本不平衡" | **追问**："不平衡为什么会导致这个结果？不平衡本身不是原因，它通过什么机制起作用的？"——必须把学员推到"机制"层面 |
| "因为大部分都标'是'，所以容易一致" | **肯定并补全**："对，这就是机制。标签越集中，偶然一致率越高，Kappa 扣掉的就越多" |
| 答不上来 | **引导**："回想刚才那两个闭眼瞎标的人。在 90% 都是'是'的数据上，他们的一致率能有多高？Kappa 要扣掉的就是这一块" |

**教师总结话术**：

> "所以标准答案是两句话，缺一不可：
> **原因**是标签分布不均衡；
> **机制**是不均衡抬高了偶然一致率，Kappa 把这部分扣掉后，暴露出真实一致性其实很低。
>
> 只说'样本不平衡'——在实操题里只能拿一半分。考试要的是机制。"

**回扣导入**：

> "现在回到开头。还认为那批数据能交付吗？Kappa 只有 0.217，落在'一般'区间、逼近'很差'。意味着两位标注员**对真正有判断难度的那 10% 样本，根本没有统一标准**。交付出去，模型学到的就是噪声。"

### 环节五：四种标注错误类型（70–100′）

> 📌 **教学提示**：这是本课题**配分最重**的知识块，务必讲透"根因差异"而非只记名字。每讲一类，立刻给样例、立刻给修复方案，形成"表现 → 根因 → 方案"的三段式。

#### 类型一：标准不一致（Inconsistent Criteria）

**定义**：标注手册对某判断标准描述模糊，不同标注员理解不同。

**样例**：
> "这个产品质量真不咋地，不过客服态度还行"
> 甲标**负面**（因为提到质量差），乙标**中性**（因为夸了客服）。

**根因**：**手册本身没定义"混合情感如何判定主次"。**

**修复**：补充细则和边界案例到标注手册。

**教师强调**：
> "注意——**不是标注员不认真**。两个人都很认真，只是手册没告诉他们该怎么办。这类问题去培训标注员是无效的，手册不改，换一批人照样分歧。"

#### 类型二：边界模糊（Boundary Ambiguity）

**定义**：两个类别间天然存在灰色地带，手册写多细都有样本难归类。

**样例**：
> "你们这物流也太慢了吧，大概还要多久到"
> 既像抱怨（投诉），又像问进度（咨询）。

**与类型一的关键区别**（板书对比）：

| | 标准不一致 | 边界模糊 |
|---|---|---|
| 根因在 | **手册**没写清 | **数据**本身固有 |
| 把手册写细能否解决 | **能** | **不能** |
| 修复方案 | 补充细则与边界案例 | 引入"模糊/待裁定"中间类 + 仲裁机制 |

**教师提问**（难点突破）：
> "怎么快速区分这两类？问自己一句话：**把手册写得再细，这个样本能不能确定地归入某一类？** 能 → 标准不一致。不能 → 边界模糊。"

#### 类型三：标签体系缺陷（Taxonomy Flaw）

**定义**：分类体系本身设计有问题——维度混乱、互斥性不足，或缺失实际存在的类别。

**样例**：
> 客诉分类设有"物流问题""态度问题""退款问题"三类。
> 一条对话："物流延迟导致我要求退款，客服态度还很差"——**三类全沾边**。

**根因**：**分类体系的维度从一开始就互相重叠**（"物流/态度"是问题来源维度，"退款"是诉求维度，两个维度被并列成了单选项）。

**修复**：重新设计分类体系，如改为多维度标签（来源维度 + 诉求维度各标一个），而非单选一类。

**教师强调**：
> "这类问题最容易被误判成'标注员水平差'。判别信号是：**全体标注员都在同一批样本上出现分歧**，而不是某个人特别奇怪。"

#### 类型四：标注员系统性偏见（Annotator Bias）

**定义**：某标注员在某类判断上**持续偏向同一方向**，而非随机出错。

**样例**：
> 标注员 A 把几乎所有"轻微负面"的评论都标成了"强烈负面"，其他标注员无此倾向。

**根因**：手册和体系**可能完全没问题**，是具体的人产生了系统性偏差。

**修复 —— 必须按顺序走，不可跳步**：

1. **量化偏差程度** —— 确认是系统性单方向偏移，还是随机波动（先排除巧合）
2. **抽样复核 A 标注过的样本** —— 看偏差是全类别存在，还是只在"负面情绪"这一维度
3. **与 A 沟通、展示具体错误案例** —— 了解偏差来源（是对"轻微/强烈"分级理解有误？还是个人情绪敏感度不同？）
4. **确认是理解偏差后，才针对性培训**；若是难以通过培训纠正的个人倾向，则调整其负责的任务类型或增加复核频次

> ⚠️ **本课题最高频失分点，必须当堂强调**
>
> "直接答'重新培训'是会扣分的。注意实操题经常这样写题干：
> 『……你会怎么处理，**而不是简单地说"A 标注不认真，重新培训"**？』
>
> 这句话不是在否定培训这个动作，**是在否定'不经诊断直接跳到培训'这个顺序**。出题人专门用这句话筛掉跳步的答案。
>
> 同样的套路在合规题里也有：看到'敏感信息'就条件反射答'脱敏'，而不去核对题干真正强调的是'授权是否具体'。
> **做三级的题，先抓题干里反复强调的那个细节，再给方案。**"

#### 诊断流程（板书）

```
低 Kappa 值
   ↓
抽样查看分歧样本        ← 关键动作，不能只看汇总数字
   ↓
判断属于四类中的哪一种（或多种并存）
   ↓
对症下药
```

**教师话术**：
> "注意中间这一步。**不要只看一个汇总数字就下结论**，一定要把标注员意见不一致的具体样本挑出来人工看。往往一眼就能看出是哪类问题。
>
> 这个'先看汇总指标、再下钻具体样本'的思路，下一课题讲模型评测时还会再用一遍——这是训练师通用的诊断方法论，不只是标注环节专属。"

### 环节六：实操二 —— 分组诊断（100–125′）

**任务布置**：

> "每组发一套质检样例卡片，共 4 张。请你们判断每张卡片描述的错误属于哪一类，并写出修复方案。**判断和理由都要写**，待会儿每组派一人汇报。15 分钟。"

**样例卡片内容**（教师预先准备）：

| 卡片 | 场景描述 | 标准答案 |
|---|---|---|
| A | 三位标注员对"北京大学第三医院"的实体边界标法各不相同：有人整体标一个机构，有人拆成两个 | **标准不一致** —— 手册未定义嵌套机构名的切分规则。修复：补充实体边界切分细则与示例 |
| B | 某批客服对话中，15 条样本三位标注员给出三种不同标签，复核发现这些对话确实既像投诉又像咨询 | **边界模糊** —— 数据固有灰色地带。修复：增设"待裁定"类 + 仲裁机制 |
| C | 标注员 B 标注的"中性"样本比例显著低于其他所有人，且其标为"负面"的样本中，复核判定为中性的占 40% | **标注员系统性偏见** —— 修复：按四步流程，先量化、再复核、再沟通、最后才培训 |
| D | 一套"用户反馈"分类含"功能建议""BUG 反馈""体验吐槽"，但大量反馈同时属于后两类，标注员各凭感觉选 | **标签体系缺陷** —— 类别互斥性不足。修复：重设体系，如拆为"反馈类型 + 情绪倾向"两个维度 |

**教师巡回指导要点**：

- 发现学员把 **A 误判为边界模糊** 时，追问："手册把切分规则写清楚之后，这个样本还会有分歧吗？"（会意识到不会 → 属标准不一致）
- 发现学员对 **C 直接答"培训"** 时，追问："你怎么知道这是理解问题而不是标注任务分配问题？你做了哪一步确认？"
- 发现学员把 **D 误判为标注员偏见** 时，追问："是只有一个人这样，还是所有人都这样？"

**汇报与点评**（10 min）：每组汇报 1–2 张，教师重点点评判别依据而非结论对错。

### 环节七：三指标的共同逻辑（125–140′）

**讲授脚本**：

> "前面讲的 Kappa 是针对文本分类这类**离散标签**任务的。但你们在实际工作里还会遇到图像和语音。这两类任务的质检指标名字完全不同——但本质是一回事。"

**并置对比**（板书三列）：

| 任务输出形式 | 典型任务 | 质检指标 | 指标在问什么 |
|---|---|---|---|
| **离散分类** | 文本情感、意图识别、图像分类 | **Kappa** | 两人的标签是否相同（扣除碰巧） |
| **空间区域** | 目标检测、语义分割、车道线 | **IoU**（交并比） | 两人画的框/区域重叠程度 |
| **序列文本** | 语音转写（ASR） | **WER**（词错误率） | 转写结果差多少次编辑操作 |

**IoU 补充**：

> IoU = 两个框的重叠面积 ÷ 两个框的并集面积
> 业界常用阈值 **IoU ≥ 0.5**（更严格取 0.7）视为"一致"。

**WER 补充**：

> WER = (替换词数 + 删除词数 + 插入词数) ÷ 参考文本总词数
> WER 15% 的准确含义是：**每 100 个参考词中，平均有 15 个词存在替换、删除或插入错误**。
> 注意：商用成熟 ASR 系统 WER 常在 5%~10%，所以 15% 属"中等偏可用"，**不要笼统说成"质量很差"**——训练师要用具体数字描述，不用模糊定性。

**归纳提问**：

> "这三个指标在回答的是不是同一个问题？"

**板书核心句**：

> **独立的标注结果之间，到底有多少是真实共识，多少是巧合或噪声？**
>
> 区别只在任务输出形式不同，衡量"重合"的数学方式就不同。

**迁移规则**（应对陌生场景的万能方法）：

> "考试如果给你一个你没见过的任务，不要去背'这个任务用什么指标'。
> 只问一句：**这个任务的输出是分类、是空间框、还是序列文本？** 三选一，指标就定了。"

**延伸追问**（埋下一课题的钩子）：

> "最后一个问题：如果一个语音转写任务的 **WER 做到了 0**，是不是就说明标注完全没问题？"

（让学员思考 30 秒）

> "不是。WER = 0 只说明'转写结果和参考文本逐词吻合'。但如果**参考文本的转写标准本身就定错了**呢？
>
> 比如团队规定'所有语气词嗯、啊一律不转写'——可这个项目恰恰是要训练语气分析模型，语气词是关键信息。那么哪怕所有人完美遵守规则、WER 做到 0，产出的数据对训练目标来说仍然是**系统性错误**的。
>
> 这和我们这节课开头的 87.8% 是同一个陷阱结构。记住这条主线：**指标完美只能说明'大家标得很一致'，不能说明'标准本身是对的'。**"

### 环节八：实操三 —— 制定标注规范（140–170′）

**任务书**（投影 + 讲义附）：

> 某电商平台要训练商品评价情感识别模型，标签体系为**积极(1) / 消极(0)** 两类。
> 请你作为三级训练师，**制定这份情感识别标注规范**。

**规范必备要素**（教师给模板，学员填充）：

```
一、适用范围与标注目标
二、标签定义
    1 = 积极：……（要给出可操作的判定依据，不能只写"表达正面情绪"）
    0 = 消极：……
三、判定优先级规则        ← 本任务的核心难点
    · 混合情感如何定主次
    · 否定句式如何处理
    · 与商品无关的内容如何处理
四、边界案例库（至少 5 条，含原文 + 应标标签 + 判定理由）
五、不确定样本处理方式
六、质检方式与合格线
    · 抽检比例、一致性指标（指标选型需说明理由）、合格阈值
```

**教师点拨要点**：

> "三个地方最容易写得不合格：
>
> **第一，标签定义写空话。** 写'积极 = 表达正面情绪'等于没写，标注员照样分歧。要写成可操作的判定依据。
>
> **第二，漏掉判定优先级。** 这份数据里有大量'质量一般，但客服态度不错'这种混合情感。**规范里不写清主次规则，就是在制造类型一错误。**
>
> **第三，质检方式不说理由。** 写'用 Kappa'不够，要写'因为本任务输出是离散二分类，故选用 Cohen's Kappa；考虑到实际标签分布可能不均衡，不以一致率作为验收依据'。**实操题评分表里，'理由'是单独配分的。**"

**巡回指导**：重点检查学员有没有写判定优先级——这是区分三级与四级答卷的关键项。

**点评**（5 min）：选 1–2 份当堂投影点评，对照上述三个易错点。
