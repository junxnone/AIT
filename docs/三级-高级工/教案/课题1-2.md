## 一、教学目标

### 知识目标
1. 能说明业务分析常用方法（漏斗分析、对比分析、根因分析）。

### 技能目标
1. **能结合业务知识识别业务流程中单一模块的问题**。
2. **能结合AI技术设计业务模块优化方案，并说明推动实现的路径**。
3. 能为优化方案定义可度量的成功指标。

### 素养目标
1. 建立"**一个现象可能有多个独立原因**"的分析习惯，不满足于找到第一个问题就停止分析。

---

## 二、教学重点与难点

**重点**：漏斗分析方法，以及"全局瓶颈"与"局部异常"的区分。

**难点**：学员典型错误预判——**找到一个问题就停止分析**，漏掉数据中同时存在的第二个独立问题。本课题数据集故意设计了两个问题（全局的"加购→下单"转化率低，以及渠道C局部的"点击→加购"异常低），很多学员只报出其中一个，交卷后才发现漏了一半分。

---

## 三、学情分析与前置知识

学员已学完课题1-1（流程设计），具备"针对真实数据设计方案"的基本意识，但尚未接触过"同一数据里可能藏着不止一个问题"这种多重归因的分析训练。日常工作经验里，很多学员习惯于"找到一个说得通的原因就提交报告"，这正是本课题要纠正的思维惯性。

---

## 四、教学方法与手段

1. **阶梯式提问法**（核心）：先引导学员发现一个问题，制造"已经找到答案"的满足感，再通过追问揭穿"还有一个问题没找到"，用这种认知落差强化记忆。
2. **数据驱动分析法**：全程基于真实漏斗数据计算，不做抽象讨论。
3. **案例诊断法**：展示典型不合格优化方案，组织学员分组互评诊断问题所在。
4. **任务驱动法**：以"产出一份覆盖全部独立问题、指标可度量的优化方案"作为本课题的终产物。

### 环节一：导入——只看一张表，你会下什么结论？（0–15′）

**教师活动** —— 投影展示（不给结论）：

> "给大家看一张各渠道汇总的转化率表：点击率、加购率、下单率、支付率。花2分钟，找出这条营销漏斗里最大的问题在哪个环节，并说出你准备怎么写这份优化报告。"

（学员观察后，多数能发现"下单率普遍只有10.8%左右，远低于加购率27%和支付率91%"）

> "很好，大家都找到了——加购到下单这一步转化率最低，这是**全局瓶颈**。现在把你的结论写下来，假设这就是你要交的最终报告，交卷吗？"

**预期学员反应**：多数学员会说"是"或犹豫片刻后说"差不多了"。

**教师收口话术**：

> "先别急着交，把这句话记住。这正是我今天要讲的核心——**找到一个问题就以为分析完了，是三级实操题最容易丢分的地方。** 这节课结束前，我们回来看这个决定会让你在实操题里丢掉多少分。"

**设计意图**：不直接否定学员的第一反应，而是让"只找到一个问题"的直觉判断先被公开表达出来，后面的推翻才有冲击力，比直接讲授"要多角度分析"更有记忆点。

---

### 环节二：新授——漏斗分析方法（15–40′）

**讲授脚本**：

> "判断一条营销漏斗哪个环节有问题，不能只看曝光量、点击量这些绝对数字，要看**环节之间的转化率**——上一步到下一步，流失了多少人。"

**投影代码**（学员照抄运行）：

```python
import pandas as pd
d = pd.read_csv("../数据集/marketing_funnel.csv")
agg = d.groupby("渠道")[["曝光量","点击量","加购量","下单量","支付量"]].sum()
agg["点击率"] = agg.点击量 / agg.曝光量
agg["加购率"] = agg.加购量 / agg.点击量
agg["下单率"] = agg.下单量 / agg.加购量
agg["支付率"] = agg.支付量 / agg.下单量
print(agg.round(3))
```

**讲解要点**：

> "注意每个转化率的分母是**上一环节**，不是曝光量。'加购率'是'加购量 ÷ 点击量'，回答的是'点进来的人里有多少继续加购'——分母用对，才能准确定位是哪一步在流失用户。"

**板书核心句**：

> **漏斗分析看的是相邻环节之间的转化率，不是单一环节的绝对数量。**

**学员活动**：记录计算口径，跟随运行代码，确认自己算出的数字与教师一致。

---

### 环节三：难点突破——揭示双重问题（40–65′）

**第二轮提问**：

> "好，现在按渠道拆开看。渠道C的加购率是多少？"

（学员分渠道计算后发现：渠道C加购率仅**3.0%**，而A/B/D都在27%左右）

**教师追问**：
> "这个3.0%和刚才找到的'加购→下单10.8%'全局瓶颈，是同一个问题吗？"

**预期学员反应与应对**：

| 学员反应 | 教师应对 |
|---|---|
| "是同一个，都是转化率低" | 纠正："看清楚，一个是'加购→下单'环节的问题，一个是'点击→加购'环节的问题，发生在流程的不同位置，而且渠道C的加购率问题其他渠道根本不存在——这是两个独立问题，不能混为一谈" |
| "不是，这是渠道C单独的问题" | 肯定："对，这就是局部异常，和全局瓶颈需要分别诊断、分别给方案" |
| 一时说不清楚怎么判断 | 引导："问自己一句话——下钻之后，是不是**所有渠道**都有这个问题？是 → 全局瓶颈；只有渠道C有 → 局部异常" |

**教师总结话术**：
> "如果你只报'加购→下单转化率低，建议优化下单流程'，这个方案对渠道C完全不对症——渠道C的问题根本不在下单环节，在更前面的加购环节，可能是渠道C的流量质量或页面体验有问题。**漏斗分析必须做渠道/人群下钻，不能只看总体一个数字就下结论。**"

**为什么总体数字会把渠道C的问题盖住？**

> "追问一句：渠道C这么极端的异常（27% 掉到 3%），为什么看总体汇总表的时候完全看不出来？因为总体数字是四个渠道加总之后算出来的——只要渠道C不是流量绝对主导的那个渠道，它的极端值就会被其余三个渠道的正常值'平均'稀释掉，总体层面看起来依然在正常区间。**这就是为什么总体指标'正常'，不代表每个子群体都正常**——必须下钻才能看见。"

**回扣导入**：

> "现在回到环节一你写下的那份'报告'。只写'优化下单流程'，渠道C的问题完全没被覆盖，这份方案在实操题评分表里只能拿到一半分。"

---

### 环节四：延伸发现——时序异常（75–95′）

**教师提问**：
> "我们已经从渠道维度发现了一个局部异常。现在换个维度——按时间看，渠道B有没有什么变化？"

```python
b = d[d["渠道"]=="B"]
before, after = b[b["周次"]<5], b[b["周次"]>=5]
print("第5周前曝光均值:", before["曝光量"].mean(), "CTR:", before["点击量"].sum()/before["曝光量"].sum())
print("第5周后曝光均值:", after["曝光量"].mean(), "CTR:", after["点击量"].sum()/after["曝光量"].sum())
```

**实测**：渠道B第5周前曝光均值约5.9万/周、CTR约4.85%；第5周后曝光均值约12.8万/周、CTR约2.43%——投放量翻倍但流量质量下降。

**预期学员反应与应对**：

| 学员反应 | 教师应对 |
|---|---|
| "渠道维度不是已经查过了吗，这不是重复？" | 解释："渠道维度回答的是'哪个渠道有问题'，渠道B本身在按渠道汇总时表现并不异常——这个问题只有按**时间**切片才能看见，是另一个维度" |
| 能自己说出"投放量涨了但质量跌了" | 肯定并追问："那如果公司打算追加预算，预算该不该投给渠道B？" |

**为什么必须专门按时间下钻，渠道维度不能替代？**

> "渠道维度下钻，算的是渠道B**整个统计周期内**的平均CTR，如果前5周和后面的数据被合在一起平均，前面高、后面低会相互抵消，算出来的'渠道B整体CTR'看起来可能还算正常——**阶段性变化会被平均值掩盖**。只有专门按周次切开对比，才能看到'投放质量从什么时候开始下降'这种渐变趋势。"

**教师收束**：
> "三个发现，三个独立问题，分别在三个不同维度（全局环节、渠道、时间）。**这才是完整的分析。** 记住今天的教训：漏斗分析不能止步于第一个发现，要习惯性地换维度再看一遍。"

---

### 环节五：新授——优化方案撰写要素（95–115′）

**讲授脚本**：

> "找到问题只是第一步。一份能交付的优化方案，必须包含五个要素，缺一个都算不合格。"

**板书五要素**：

```
1. 问题定位（分清全局瓶颈 vs 局部异常，不要混为一谈）
2. 根因假设（为什么会出现这个问题，可能有多个假设）
3. 优化方案（针对每个独立问题分别给方案，不能用一个方案覆盖所有问题）
4. 可度量的成功指标（如"下单率从10.8%提升到15%"，而非"提升转化率"这类无法验证的表述）
5. 推动实现的路径（涉及的角色、数据支持、验证方式）
```

**重点讲解要素4——为什么"可度量"是硬性要求**：

> "对比这两种写法：
>
> **不合格**：'将下单率尽可能提升。'
> **合格**：'将下单率从10.8%提升至15%以上，观察周期4周。'
>
> 为什么前者不合格？因为'尽可能'没有一个具体数字和时间点，**4周后你根本没法判断这个方案到底有没有生效**——涨到11%算不算达成？涨到20%又是不是方案本身的功劳还是别的因素？目标写不清楚，连验证的起点都没有，训练师的工作成果也就没法被考核。"

**判别口诀**（板书）：

> **这个目标写出来后，能不能在未来某个时间点，拿一个具体数字去验证"达成了"还是"没达成"？能 → 合格目标；只有"尽量""提升""优化"这类词、没有数字和周期 → 需要重写。**

**要素5简要说明**：

> "'推动实现的路径'不是空话，要具体写清楚：这个方案需要产品/技术/运营哪些角色配合、需要什么数据支持去验证（比如要监测哪些后续指标）、多久之后回看一次效果。"

**学员活动**：对照五要素，口头评价环节一自己写下的初版结论，指出其中缺了哪几项。

---

### 环节六：实操——完整优化方案撰写（115–175′）

**任务书**（投影）：

> 输出一份完整的业务模块优化分析报告，覆盖本课题已发现的至少两类问题（全局瓶颈 + 渠道局部异常；时序异常可作加分项），每一类问题分别写出"问题定位 / 根因假设 / 优化方案 / 可度量指标 / 推动路径"五要素，对接实操试题 1.1.2。

**巡回指导重点**：

- 检查学员是否只报告了一个问题就停止，若是则现场追问"还有没有换个维度看过？"
- 检查可度量指标是否写了具体数字和观察周期，若写"尽量提升"类表述，当场要求改写成具体数字。
- 对完成较快的学员追问："如果渠道C排查后发现是流量质量问题，而不是落地页问题，你的方案要怎么调整？"——训练"根因假设可能不止一个"的意识。

**学员活动**：独立分析数据、撰写方案，遇到不确定的问题定位举手提问。

---

### 环节七：分组互评与典型错误诊断（175–195′）

**教师活动**：投影展示2–3份教师预先准备的"典型不合格方案"，组织学员分组诊断问题所在。

**典型案例卡片**：

| 案例 | 方案内容摘录 | 应诊断出的问题 |
|---|---|---|
| A | "加购→下单转化率低，建议优化下单流程。"（全文未提渠道差异） | 漏掉局部异常——未分渠道下钻，渠道C的问题完全没被发现 |
| B | "渠道C和其他渠道一起优化下单流程即可。" | 方案不对症——渠道C的真实问题在"点击→加购"环节（加购率仅3.0%），不在下单环节 |
| C | "将整体转化率尽量提升，持续观察效果。" | 指标不可度量——没有具体数字和观察周期，无法验证是否达成 |

**预期学员反应与教师应对**：

| 学员诊断 | 教师应对 |
|---|---|
| 只看出案例B"方案错了"，说不清为什么 | 追问："渠道C真正的问题发生在流程的哪一步？和下单流程是一回事吗？" |
| 认为案例C"写得挺好，态度很积极" | 追问："'尽量提升'这四个字，4周后你怎么判断方案有没有生效？" |
| 能完整说出三个案例各自缺陷 | 追问进阶问题："如果让你给案例A补全方案，你会先做什么？"——检验是否具备"先下钻，再补方案"的顺序意识 |

**学员活动**：分组讨论，每组派代表指出至少1处问题并给出修改建议，教师重点点评判别依据而非结论对错。

---

### 环节八：阶段性小测（195–215′）

**教师活动**：发放5道小测题，当堂巡视，统一讲评。

**题目方向**（示例，正式题目见题库对应区间）：
1. 判断题：某渠道某环节转化率明显低于其他渠道，这一定说明问题出在该渠道本身，与其他渠道无关。
2. 选择题：给定一份只报告了一个问题的优化方案，判断其缺陷属于"漏判局部异常"还是"方案不对症"。
3. 简答：为什么"将转化率尽量提升"这种写法在优化方案里不合格？应该怎么改？

**学员活动**：独立完成，交卷后对照答案自评。

---

### 环节九：小结与作业（215–240′）

**知识回顾**（请学员口述，教师补全）：

1. 全局瓶颈和局部异常分别是什么？怎么判别？
2. 一份合格的优化方案必须包含哪五个要素？
3. 为什么"可度量"是优化指标的硬性要求？

**回扣主线**：

> 本课题三次发现，分别在三个不同维度（全局环节、渠道、时间），都遵循同一个教训：**找到一个问题 ≠ 分析完了，要习惯性地换维度再看一遍。** 这个习惯不只用在营销漏斗分析上——下一课题讲数据清洗规范制定时，你会发现"只查了一类问题就收工"同样是最容易丢分的地方。

## 七、板书设计

**主板书区**

```
                     一个现象 ≠ 一个原因

分析方法：先看总体 → 分维度下钻（渠道/时间/人群）→ 分别诊断

┌──────────────────── 实测发现 ────────────────────┐
│ 全局瓶颈：加购→下单 转化率 ≈10.8%（所有渠道共性问题）│
│ 局部异常：渠道C 点击→加购 仅 3.0%（个别渠道专属问题）│
│ 时序异常：渠道B 第5周后曝光翻倍但CTR腰斩（投放质量下降）│
└──────────────────────────────────────────────────┘

核心教训：找到一个问题 ≠ 分析完了，习惯性换维度再看一遍
```

**副板书区（全局瓶颈 vs 局部异常 判别）**

```
            全局瓶颈              局部异常
表现        所有渠道/群体都存在    只有个别渠道/群体存在
本课题例子  加购→下单 ≈10.8%       渠道C 加购率 3.0%
对应方案    全局优化下单流程       单独排查渠道C加购环节

判别口诀：下钻之后，是不是所有子群体都有同样的问题？
  是 → 全局瓶颈      不是，只有个别群体 → 局部异常
```
