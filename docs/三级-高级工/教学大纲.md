## 一、课程性质与定位

三级/高级工是**无需前置证书即可直接报考的最高等级**，也是本职业能力结构发生**质变**的分水岭。

本课程不是四级内容的加深，而是模块的整体更换：

| | 四级 / 五级 | 三级 / 高级工 |
|---|---|---|
| 职业功能 | 数据采集和处理、数据标注、智能系统运维 | **业务分析、智能训练、智能系统设计、培训与指导** |
| 能力动词 | 完成、记录、审核、纠正 | **设计、制定、诊断、评估、指导** |
| 角色 | 执行者 / 质量把关者 | **设计者 + 判断者 + 指导者** |

因此本课程的训练目标不是"把操作做得更准"，而是三件事：

1. **会设计** —— 业务流程、清洗规范、标注规范、交互流程，都要能从零设计出来，而不是照着别人的规范执行；
2. **会诊断** —— 给一个"结果不理想"的现象，能倒推是流程哪一环、哪个超参数、哪类标注错误造成的；
3. **会指导** —— 能把上述判断讲清楚，编成讲义，培训和指导五级/四级的从业者。

> 📌 **贯穿全课程的一条主线**：**单一指标变好 ≠ 真实目标达成**。
> 一致率高不代表标注质量好（要看 Kappa）；WER 为 0 不代表标注体系对（规范本身可能错）；训练集 Loss 持续下降不代表模型好（要看验证集）；准确率 95% 不代表模型可用（要看混淆矩阵与业务代价）。
> 这个"必须有一个独立于该指标之外的检验手段"的思维模式，是三级考试（尤其实操题与判断题）反复设置的考点。所有课题都会回到它。

## 二、培训对象与前置要求

**申报条件**（满足其一，以当地公告为准）：

- 累计从事本职业或相关职业工作满 **10** 年；
- 取得四级/中级工证书后，累计从事本职业满 **4** 年；
- 取得符合专业对应关系的初级职称后，累计从事本职业满 **1** 年；
- 取得本专业或相关专业技工院校**高级工班及以上**毕业证书（含在读应届生）。

**知识前置**：

- 具备计算机操作与常用办公软件使用能力；
- 了解数据采集、清洗、标注的基本概念（四级/五级范围）；
- **具备 Python 基础读写能力**（能看懂并修改 pandas 数据处理代码）。零基础者建议先补 `四级-中级工/学员讲义/课题0-3.md`。

## 四、各课题教学要求

> 标注说明：**【知】** = 知识要求（理论考点）｜**【技】** = 技能要求（实操考点）｜**【素】** = 素养要求

### 课题 0-1 三级能力跃迁与考试结构（2 学时）

- 【知】能表述职业定义中的四个关键词（数据库管理、算法参数设置、人机交互设计、性能测试跟踪）及其对应的职业功能模块
- 【知】能说明五级 / 四级 / 三级的职业功能差异与能力边界
- 【知】能说明两科考核形式、题型与合格标准
- 【素】建立"从执行者到设计者"的角色认知

### 课题 0-2 机器学习范式与神经网络基础（2 学时）

- 【知】能解释监督学习、无监督学习、强化学习的定义与区别
- 【技】**能判断给定 AI 任务属于哪种范式**，并说明该范式下训练师的工作重心（标注质量 / 聚类业务意义 / 奖励函数设计）
- 【知】能说明神经网络的输入层—隐藏层—输出层结构，以及"训练即调整权重"的本质
- 【知】能说明深度学习与神经网络的关系，及层数加深带来的过拟合风险

### 课题 0-3 数据合规红线与职业道德（2 学时）

- 【知】能表述职业守则三条（诚实公正严谨求是；遵章守法恪尽职守；勤勉好学追求卓越）
- 【知】能说明《网络安全法》《数据安全法》《个人信息保护法》《知识产权法》与数据工作的关联点
- 【技】**能在具体业务场景中识别违规点并提出整改方案**，覆盖三条红线：数据来源合法性（授权是否具体、知情同意）、敏感信息脱敏（含标注环节访问控制）、特殊群体特殊保护（未成年人需监护人单独授权）
- 【素】**纠正"关键词条件反射"的答题习惯**——先抓题干反复强调的细节，而非对关键词直接套用标准动作

### 课题 1-1 业务数据采集 / 处理 / 审核流程设计（4 学时｜实操码 1.1.1）

- 【知】能说明采集→清洗→归类→标注→质检五环节各自的质量控制点
- 【知】能说明该流程是**可反向反馈优化的闭环**，而非单向流水线
- 【技】**能针对给定业务场景，设计完整的数据采集流程、处理流程与审核流程，并给出详细步骤**
- 【技】能针对"流程跑下来结果不理想"的场景，倒推问题出在哪一环并给出修正方案
- 【技】能说明保证数据准确性、一致性、可用性的具体处理措施

### 课题 1-2 业务模块问题识别与优化方案（4 学时｜实操码 1.1.2）

- 【知】能说明业务分析常用方法（指标拆解、漏斗分析、对比分析、根因分析）
- 【技】**能结合业务知识识别业务流程中单一模块的问题**
- 【技】**能结合 AI 技术设计业务模块优化方案，并说明推动实现的路径**（涉及的角色、数据、上线与验证方式）
- 【技】能为优化方案定义可度量的成功指标与观察周期

### 课题 2-1 数据清洗规范制定（4 学时｜实操码 2.1.1）

- 【知】能说明常见数据质量问题类型（重复、缺失、异常、噪声、格式不一致）
- 【知】能说明清洗规则阈值**必须有业务依据**，不能套用通用脚本（如订单金额为负是异常，金额特别大可能是大客户批量采购）
- 【技】**能针对给定原始数据制定数据清洗标准，并用 pandas 实现清洗、输出清洗后数据文件**
- 【技】能为清洗规范撰写可交付文档（适用范围、逐条规则、处理方式、例外情形、产出字段说明）

### 课题 2-2 标注规范制定与质量评估（4 学时｜实操码 2.1.1）

- 【知】能说明一致率的缺陷与 Cohen's Kappa 的作用（刨除偶然一致），能依 Kappa 区间判断一致性水平
- 【知】**能解释"一致率高而 Kappa 低"的机制**（标签分布不均衡时偶然一致率本身很高）
- 【技】**能诊断标注错误的四种类型并对症给出修复方案**：标准不一致（补细则与边界案例）、边界模糊（设中间类与仲裁机制）、标签体系缺陷（重设分类体系/改多维标签）、标注员系统性偏见（量化偏差→抽样复核→沟通→针对性培训或调岗）
- 【技】能按任务输出形式选择质检指标：离散分类→Kappa，空间区域→IoU，序列文本→WER
- 【技】**能针对给定分类任务制定标注规范**（标签定义、判定优先级、边界案例、不确定样本处理、质检方式与合格线）

### 课题 2-3 训练超参数与过拟合 / 欠拟合诊断（4 学时｜实操码 2.2.1）

- 【知】能说明学习率、Batch Size、Epoch 的含义及设置不当的后果
- 【知】能计算 Iteration 数 = 训练集样本总数 ÷ Batch Size
- 【知】能说明学习率调度与 Warmup 的作用；能说明大 Batch Size "效率高但泛化可能更差"的反直觉结论
- 【技】**能依据训练现象反推超参数问题**（Loss 不降→学习率过小/欠拟合；Loss 震荡或 NaN→学习率过大；训练集 Loss 低而验证集 Loss 升→过拟合）
- 【技】能说明过拟合与欠拟合的判别依据与应对手段（Early Stopping、正则化、增加数据、调整模型复杂度）

### 课题 2-4 算法测试与错误分析（4 学时｜实操码 2.2.1）

- 【知】能读懂混淆矩阵（TP/FP/FN/TN），能计算准确率、精确率、召回率、F1
- 【知】**能说明准确率在类别不均衡下的失效**（99% 负样本时全判负也有 99% 准确率）
- 【技】**能结合业务代价判断该优先保精确率还是召回率**（风控漏判 vs 误判、医疗筛查 vs 垃圾邮件）
- 【技】**能用 scikit-learn 完成模型训练、输出混淆矩阵与分类报告，并据此分析错误、提出改进方向**
- 【知】能说明 ROC 曲线与 AUC 的含义及阈值调整对 P/R 的影响

### 课题 3-1 智能系统监控与优化（4 学时｜实操码 3.1.1）

- 【知】能说明数据漂移、概念漂移、模型退化的定义与成因
- 【知】能设计监控指标体系（业务指标、模型指标、数据质量指标、时效指标）与告警阈值
- 【技】**能对单一智能产品的使用数据做全面分析并输出分析报告**（结构：结论先行→关键指标→分群下钻→问题定位→优化建议→验证方案）
- 【技】**能提出产品优化需求并设计智能解决方案**
- 【技】能说明"先看汇总指标、再下钻具体样本"的通用诊断方法论

### 课题 3-2 人机交互流程设计（4 学时｜实操码 3.2.1）

- 【知】能说明人机协同的基本模式（全自动、AI 建议+人工确认、人工兜底转接、人工复核抽检）
- 【知】能说明置信度阈值、转人工触发条件、兜底话术的设计原则
- 【技】**能通过数据分析找到单一场景下人工与智能交互的最优方式**（依据置信度分布、各区间准确率、人工成本与用户满意度）
- 【技】**能设计单一场景下的人机交互最优流程**，含流程图、分支条件、异常与降级路径、效果度量指标

### 课题 4-1 培训讲义编写与技术指导（2 学时｜实操码 4.2.1）

- 【知】能说明培训讲义的基本结构（培训目标、受众与前置、内容要点、案例、练习、考核方式）
- 【技】**能针对五级/四级从业者编写初级培训讲义**
- 【技】**能指导五级/四级解决数据采集、处理与标注中的常见问题**，并能列举常见问题方向及指导要点（如采集口径不一致、字段缺失、标注标准理解偏差、边界样本处理、效率与质量失衡等）
- 【素】能用对方听得懂的语言讲清判断依据，而非仅给结论

## 六、考核方式与评分

### 理论知识考试

- 形式：闭卷机考
- 本资料题库：单选 140 + 多选 30 + 判断 30 = 200 题，另配 100 题模拟卷
- 内容分布（参考权重，**非国标原文数值**，来源见 `../00-国标对应表.md` 第五节）：职业道德与法规 10%、基础知识 10%、业务分析 20%、智能训练 30%、智能系统设计 25%、培训与指导 5%

### 操作技能考核

- 形式：现场 / 模拟操作，4 道题，各 25 分，共 100 分，120 min
- 本资料提供 7 道全真格式实操题，覆盖全部实操码：

| 实操码 | 试题名称 | 考核时间 | 配分 |
|---|---|---|---|
| 1.1.1 | 智能客服系统业务数据处理流程设计 | 25 min | 25 |
| 1.1.2 | 自动化营销模型业务模块效果优化 | 15 min | 25 |
| 2.1.1 | 商品评价情感识别的数据清洗与标注规范制定 | 25 min | 25 |
| 2.2.1 | 智能信用评分模型开发与测试 | 30 min | 25 |
| 3.1.1 | 智能音箱产品数据分析与优化 | 25 min | 25 |
| 3.2.1 | 客户体验管理智能系统人机交互流程设计 | 15 min | 25 |
| 4.2.1 | 智能零售分析系统数据采集和处理指导 | 15 min | 25 |

- 每题含场地设备要求、试题正文（分小问标配分）、评分表、参考答案（含可运行代码）

### 常见失分点（授课时须反复强调）

1. **跳过诊断直接给方案** —— 题干出现"而不是简单地……"这类提示时，出题人正是在筛掉跳过诊断步骤的答案。
2. **对关键词条件反射** —— 见"敏感数据"就答脱敏、见"标注员偏见"就答培训，不核对题干真正给出的线索。
3. **只给结论不给依据** —— 实操题评分表普遍为"方案 + 理由"双配分，缺理由直接丢一半分。
4. **指标理解表面化** —— 把"一致率 92%"当成质量好、把"准确率 95%"当成模型可用。
5. **流程设计缺质量控制点** —— 只写出采集→清洗→标注的步骤，没写每步的校验方式与不合格处理。
6. **忽略「培训与指导」模块** —— 误以为三级不考，实操有独立试题。
