## 四、参考答案

> ⚠️ 以下代码与数值在 **Python 3.11.17 + pandas 2.3.3 + scikit-learn 1.9.1** 下实测验证通过。

### 第1题参考答案

```python
import pandas as pd
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

d = pd.read_csv("credit_data.csv")
print("违约率:", d["is_default"].mean())
print("缺失:", d.isnull().sum()[lambda s: s > 0].to_dict())
print("年龄异常:", sorted(d.age[(d.age < 18) | (d.age > 100)].tolist()))

# 处理异常值：用中位数替换不合理年龄（0/150/199岁）
d["age"] = d["age"].mask((d.age < 18) | (d.age > 100), d.age.median())
# 处理缺失值：用中位数填充（收入呈长尾分布，中位数比均值更稳健）
d["monthly_income"] = d["monthly_income"].fillna(d["monthly_income"].median())

F = ["age","monthly_income","debt_ratio","credit_history_months","late_payment_times","credit_lines"]
X, y = d[F], d["is_default"]
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.3, random_state=42, stratify=y)
sc = StandardScaler().fit(Xtr)
model = LogisticRegression(max_iter=1000).fit(sc.transform(Xtr), ytr)
```

**实测**：违约率15.5%，收入缺失160条（8%），年龄异常值[0.0, 150.0, 199.0]三条。`stratify=y`确保训练/测试集的违约比例一致，这在类别不均衡数据上尤为重要。

### 第2题参考答案

```python
from sklearn.metrics import confusion_matrix, classification_report, roc_auc_score

pred = model.predict(sc.transform(Xte))
proba = model.predict_proba(sc.transform(Xte))[:, 1]
print(confusion_matrix(yte, pred))
print(classification_report(yte, pred, target_names=["未违约","违约"], digits=3))
print("AUC =", round(roc_auc_score(yte, proba), 3))
```

**实测输出**：

```
[[499   8]
 [ 84   9]]
              precision    recall  f1-score
       未违约      0.856     0.984     0.916
        违约      0.529     0.097     0.164
accuracy = 0.847    AUC = 0.768
```

**模型是否可用的判断**：**不能认为模型可用**。关键依据：
1. 违约率15.5%，意味着"全判不违约"的基线准确率就是84.5%，而模型准确率84.7%**只比基线高0.2个百分点**；
2. 违约类召回率仅**0.097**——100个真实违约客户中，模型只找出约10个，对风控场景而言这个模型形同虚设；
3. AUC=0.768表明**模型本身具备一定判别力**（远高于随机水平0.5），说明问题更可能出在决策阈值而非模型能力。

### 第3题参考答案

```python
pred_03 = (proba >= 0.3).astype(int)
print(confusion_matrix(yte, pred_03))
print(classification_report(yte, pred_03, target_names=["未违约","违约"], digits=3))
```

**改进方向**：降低决策阈值至0.3，以更好地服务风控"宁可错杀不可放过"的业务目标。

**效果对比**：

| 阈值 | 违约类精确率 | 违约类召回率 | F1 |
|---|---|---|---|
| 0.5（原始） | 0.529 | 0.097 | 0.164 |
| 0.3（调整后） | 0.500 | **0.366** | **0.422** |

召回率从0.097提升到0.366（提升3.8倍），精确率仅从0.529降至0.500（降2.9个百分点）——用很小的精确率代价换来大幅召回率提升，符合风控业务对漏判代价的权衡。

> 💡 本题的核心评分逻辑：**只要准确率高就判断模型可用**是最常见的失分点。必须对比类别分布基线、拆解混淆矩阵、结合业务代价判断该保哪个指标。
