## 四、参考答案

> ⚠️ 以下数值在 **Python 3.11.17 + pandas 2.3.3** 下实测验证通过。

### 第1题参考答案

```python
import pandas as pd
d = pd.read_csv("speaker_logs.csv")
overall = d.groupby("周次")["识别成功"].mean()
print("第1周:", round(overall.iloc[0], 3), "第12周:", round(overall.iloc[-1], 3))
print("下滑幅度:", round((overall.iloc[0] - overall.iloc[-1]) * 100, 1), "个百分点")
```

**实测**：第1周91.4% → 第12周82.6%，下滑**8.8个百分点**。

### 第2题参考答案

```python
seg = d.pivot_table(index="周次", columns="用户群体", values="识别成功", aggfunc="mean")
child_ratio = d.groupby("周次")["用户群体"].apply(lambda s: (s == "儿童").mean())
print(seg.round(3))
print("儿童占比: 第1周", round(child_ratio.iloc[0],3), "第12周", round(child_ratio.iloc[-1],3))
```

**实测分解**：
- 成人群体成功率：92.6% → 87.3%，下滑**5.3个百分点** → **真实模型退化**
- 儿童用户占比：7.7% → 28.8%（第7周起骤升），儿童群体成功率始终比成人低约16-20个百分点 → 占比上升拉低整体均值约**3.5个百分点** → **数据漂移**

**8.8pp = 5.3pp（模型退化）+ 3.5pp（数据漂移）**

### 第3题参考答案

**分析报告**：

> **结论**：智能音箱识别成功率12周内下滑8.8个百分点，经分群下钻分析，**该下滑由两个独立原因共同构成**：约5.3个百分点源于模型本身判别能力的真实退化；约3.5个百分点源于用户群体结构变化——儿童用户占比从7.7%上升至28.8%，而儿童语音天然识别难度更高。
>
> **优化方案**：
> 1. 针对模型退化（5.3pp）：收集近期使用数据重新训练模型，重点关注近4周的语音样本分布；
> 2. 针对数据漂移（3.5pp）：专项补充儿童语音训练数据，评估是否需要针对儿童语音单独调优声学模型参数。
>
> **若只做方案1（单纯重训练），无法解决方案2对应的那部分问题**——这是本题的核心评分逻辑。

### 第4题参考答案

```python
print("响应时长异常(-1)记录数:", (d["响应时长ms"] == -1).sum())
print("占比:", (d["响应时长ms"] == -1).mean())
```

**实测**：约2%的日志记录响应时长为-1，属于**埋点/采集环节的数据质量问题**，与模型能力无关，不应混入对模型表现的归因判断。处理方式：将这类异常值标记为无效记录，从响应时长的统计分析中剔除，同时上报技术团队排查埋点bug本身。
