## 四、参考答案

> ⚠️ 数据在 **Python 3.11.17 + pandas 2.3.3** 下实测验证。

### 第1题参考答案

```python
import pandas as pd
d = pd.read_csv("marketing_funnel.csv")
agg = d.groupby("渠道")[["曝光量","点击量","加购量","下单量","支付量"]].sum()
agg["点击率"] = agg.点击量 / agg.曝光量
agg["加购率"] = agg.加购量 / agg.点击量
agg["下单率"] = agg.下单量 / agg.加购量
agg["支付率"] = agg.支付量 / agg.下单量
print(agg.round(3))
```

**实测结果**：

| 渠道 | 点击率 | 加购率 | 下单率 | 支付率 |
|---|---|---|---|---|
| A | 5.1% | 27.0% | 10.8% | 91.1% |
| B | 3.0% | 27.7% | 10.8% | 90.5% |
| C | 6.2% | **3.0%** | 10.6% | 87.0% |
| D | 4.3% | 26.7% | 10.8% | 90.1% |

**识别出两个独立问题**：
1. **全局瓶颈**：所有渠道"加购→下单"转化率均约10.8%，远低于加购率（~27%）和支付率（~90%）
2. **局部异常**：渠道C加购率仅3.0%，远低于其他渠道的27%左右——这是渠道C专属的问题，不是全局瓶颈的一部分

**时序异常（加分项）**：

```python
b = d[d["渠道"]=="B"]
before, after = b[b["周次"]<5], b[b["周次"]>=5]
print("第5周前曝光均值:", before["曝光量"].mean(), "CTR:", before["点击量"].sum()/before["曝光量"].sum())
print("第5周后曝光均值:", after["曝光量"].mean(), "CTR:", after["点击量"].sum()/after["曝光量"].sum())
```

实测：渠道B第5周前曝光均值约5.95万/周、CTR约4.85%；第5周后曝光均值约12.79万/周、CTR约2.43%——投放量翻倍但流量质量下降。

### 第2题参考答案

| 问题 | 优化方案 | 成功指标 |
|---|---|---|
| 全局"加购→下单"转化率低 | 排查下单页面流程（步骤数、必填信息量、支付方式选择），简化流程，增加限时优惠等下单激励 | 下单率从10.8%提升至15%以上，观察周期4周 |
| 渠道C"点击→加购"异常低 | 排查渠道C的流量画像是否与商品匹配、落地页加载速度与体验是否存在问题，必要时暂停渠道C投放直至问题定位 | 渠道C加购率从3.0%提升至渠道平均水平（约27%）的一半以上，即13%以上 |

### 第3题参考答案

> 不能只看总体转化率，因为总体数字是各渠道/各群体加权平均的结果，**会掩盖局部异常**。本例中若只看总体"加购→下单"转化率，会得出"下单流程需要优化"的单一结论，但实际上渠道C存在一个完全独立、更严重的问题（点击→加购仅3%），如果不下钻到渠道维度就永远发现不了。**分维度（渠道/时间/人群）下钻，是为了避免用一个方案覆盖本质不同的多个问题。**
