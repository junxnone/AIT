### ⚠️ 为什么要锁定 pandas 2.x，不要装 3.x

pandas 3.0 把 **Copy-on-Write 改为默认行为**，链式赋值与 `inplace` 操作的语义和 2.x 不同。同一段教材代码在 3.x 上可能不报错但结果不同，或直接抛出警告/异常。

考区与学员机器上普遍仍是 2.x，因此本资料全部代码按 **pandas 2.x** 编写。`requirements.txt` 已用 `pandas>=2.0,<3.0` 锁定，**请勿手动升级**。

## 二、安装方式（三选一）

### 方式 A：conda（推荐）

已装 Anaconda / Miniconda / Miniforge 的用户：

```bash
conda create -n aitrainer python=3.11 -y
conda activate aitrainer
pip install -r requirements.txt
```

> **Windows 上 conda 不在 PATH 时**：用全路径调用。例如 miniforge3 默认安装在用户目录下，对应
> `C:\Users\<你的用户名>\miniforge3\Scripts\conda.exe`
> Anaconda 则通常在 `C:\Users\<你的用户名>\anaconda3\Scripts\conda.exe`。
> 也可以直接从开始菜单打开「Anaconda Prompt」/「Miniforge Prompt」，在其中执行上述命令。

### 方式 B：venv（系统已装 Python 3.11+）

```bash
# Windows
python -m venv aitrainer-env
aitrainer-env\Scripts\activate
pip install -r requirements.txt

# macOS / Linux
python3 -m venv aitrainer-env
source aitrainer-env/bin/activate
pip install -r requirements.txt
```

### 方式 C：全新安装 Python

从 <https://www.python.org/downloads/> 下载 **3.11** 或 3.12 安装包。

> **Windows 安装时务必勾选 `Add Python to PATH`**，否则命令行找不到 `python` 命令。
> 若在命令行输入 `python` 后跳转到 Microsoft Store，说明系统里只有占位别名、没有真实 Python：
> 到「设置 → 应用 → 高级应用设置 → 应用执行别名」中关闭 `python.exe` / `python3.exe` 两项，再重新安装。

安装完成后执行方式 B 的 venv 步骤。

**这一步是必须的** —— 所有实操题的数据文件都由脚本生成，仓库中不直接存放大文件。

cd 公共资源

### 关于可复现性

脚本固定了随机种子 `SEED = 20261012`，**任何人、任何时候运行，生成的数据完全一致**。

这一点很重要：参考答案里的所有数字（缺失值个数、准确率、Kappa 值、混淆矩阵）都是在这份确定的数据上实测得出的。如果你算出来的数和参考答案不一致，是你的处理步骤有差异，而不是数据随机性造成的——这反而成了一个有用的自查手段。

### 数据集说明

- 生成的数据全部是**程序合成的虚构数据**，不含任何真实个人信息或企业数据，可安全用于教学与考核。
- 数据**故意**包含缺失、重复、异常、格式混乱、标注分歧等问题。**这些"脏"是题目本身，不是 bug。**
- 部分文件含以下划线开头的列（如 `_参考答案`、`_真实分群`），是供教师核对用的。**发给学员前请删除这些列**，否则答案直接暴露。

```python
# 发给学员前清理内部列
import pandas as pd
df = pd.read_csv("user_behavior.csv")
df = df.loc[:, ~df.columns.str.startswith("_")]
df.to_csv("user_behavior_for_student.csv", index=False, encoding="utf-8-sig")
```

## 五、Jupyter Notebook 使用

部分考区的操作技能考核以 Jupyter Notebook 提交答题过程，建议平时就用它练习。

```bash
jupyter notebook
```

浏览器会自动打开。常用快捷键：

| 操作 | 快捷键 |
|---|---|
| 运行当前单元格并跳到下一个 | `Shift + Enter` |
| 运行当前单元格不跳转 | `Ctrl + Enter` |
| 在下方插入单元格 | `Esc` 后按 `B` |
| 删除单元格 | `Esc` 后按 `D` `D` |
| 切换为 Markdown 单元格 | `Esc` 后按 `M` |
| 切换为代码单元格 | `Esc` 后按 `Y` |

> 💡 **考试提示**：实操题通常要求同时提交**代码**和**文字说明**（设计思路、判断依据）。用 Markdown 单元格写说明、代码单元格写实现，是最稳妥的答题组织方式。**只有代码没有说明，按评分表会丢掉"理由"那部分的分。**

## 六、常见问题

**Q：CSV 用 Excel 打开中文乱码？**

本资料生成的 CSV 均使用 `utf-8-sig` 编码，Excel 双击可直接正常显示。若你自己导出的文件乱码，在 `to_csv` 时加上 `encoding="utf-8-sig"`。

**Q：`ModuleNotFoundError: No module named 'sklearn'`？**

包名和导入名不同。安装用 `pip install scikit-learn`，导入用 `import sklearn`。另请确认当前激活的是 `aitrainer` 环境（命令行提示符前应有 `(aitrainer)`）。

**Q：matplotlib 画图中文显示成方框？**

```python
import matplotlib.pyplot as plt
plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei", "DejaVu Sans"]
plt.rcParams["axes.unicode_minus"] = False   # 负号正常显示
```

**Q：`生成数据集.py` 报找不到路径？**

脚本按**相对自身位置**定位输出目录（`Path(__file__).resolve().parent.parent`），所以必须保持 `公共资源/` 与三个等级目录的同级结构。不要单独把脚本拷到别处运行。

**Q：提示 `PermissionError` 写不进文件？**

通常是该 CSV 正在 Excel 中打开着。关闭 Excel 后重新运行。

**Q：想清除这个环境？**

```bash
conda env remove -n aitrainer      # conda 方式
# venv 方式：直接删除 aitrainer-env 目录即可
```

## 七、不需要安装的内容

以下内容本资料**不要求**安装，相关课题讲方法与规范，不绑定具体工具：

- **数据库服务端**（MySQL / PostgreSQL）—— 五级课题 1-2 的 SQL 练习使用 `practice.db`（SQLite 文件库），Python 标准库自带 `sqlite3`，无需额外安装。
- **深度学习框架**（PyTorch / TensorFlow）—— 三级考核不要求手写神经网络训练代码，模型相关实操用 scikit-learn 即可覆盖。
