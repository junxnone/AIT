# 人工智能训练师 职业技能培训资料（三级 / 四级 / 五级）

> 依据《国家职业技能标准·人工智能训练师》（职业编码 **4-04-05-05**，2021 年版，人社部与工信部联合颁布）编写。
> 适用对象：参加五级/初级工、四级/中级工、三级/高级工职业技能等级认定的考生，以及承担相应培训任务的授课教师。

---

## 一、这套资料是什么

每个等级都包含五类材料，互为索引、可独立使用：

| 材料 | 用途 | 位置 |
|---|---|---|
| **教学大纲** | 课题清单、学时分配、国标条目对应、考核对接 | `<等级>/教学大纲.md` |
| **教案** | 教师授课用。含教学目标、重难点、教学过程逐环节时间分配与师生活动、板书设计、作业 | `<等级>/教案/` |
| **学员讲义** | 配合课堂的学员自学材料。含正文讲解、案例、可运行代码、考点清单、随堂练习与答案 | `<等级>/学员讲义/` |
| **自学文件夹** | 面向**完全没有老师、没上过课**的自学者的第三类材料，见下方说明 | `<等级>/自学/` |
| **试题库** | 理论 200 题（带解析/考点/易错点）+ 操作技能全真题（带评分表与参考答案）+ 模拟卷 | `<等级>/试题库/` |

**`自学/` 文件夹里有三类材料，定位不同：**

| 子材料 | 定位 | 位置 |
|---|---|---|
| 苏格拉底问答自学 | 对话式提问-引导-解答，模拟一对一辅导，适合零基础建立直觉 | `<等级>/自学/苏格拉底问答自学/` |
| 自学教材 | 合并教案讲授内容与讲义叙事，不依赖课堂、从头读到尾可独立学完的完整教材 | `<等级>/自学/自学教材/` |
| 速查手册 | 考前冲刺用，每课题压缩成核心考点+公式/规则+易错点，不含讲解过程 | `<等级>/自学/速查手册.md` |

建议顺序：先读苏格拉底问答篇建立直觉 → 再系统读自学教材 → 考前用速查手册冲刺。每个等级的 `自学/00-自学使用说明.md` 有更详细的说明。

配套资源：

- `00-国标对应表.md` —— 三个等级的「职业功能—工作内容—技能要求—相关知识要求」对照表，以及每条技能要求到课题、到试题的双向映射。**查漏补缺时先看这份。**
- `公共资源/` —— Python 环境搭建指南、`requirements.txt`、数据集生成脚本。
- `<等级>/数据集/` —— 该等级实操题所需的数据文件（由生成脚本产出）。

## 二、职业定义与等级阶梯

**职业定义**：使用智能训练软件，在人工智能产品实际使用过程中进行**数据库管理、算法参数设置、人机交互设计、性能测试跟踪**及其他辅助作业的人员。本职业包含**数据标注员**、**人工智能算法测试员**两个工种。

本职业设五个等级：五级/初级工、四级/中级工、三级/高级工、二级/技师、一级/高级技师。**本套资料覆盖五级、四级、三级。**

### 等级能力分界（理解这张表，是备考的前提）

| | 五级/初级工 | 四级/中级工 | 三级/高级工 |
|---|---|---|---|
| **职业功能模块** | 数据采集和处理<br>数据标注<br>智能系统运维 | 数据采集和处理<br>数据标注<br>智能系统运维 | **业务分析**<br>**智能训练**<br>**智能系统设计**<br>**培训与指导** |
| **能力动词** | 完成、记录、使用 | 审核、检测、优化、纠正 | **设计、制定、诊断、评估、指导** |
| **角色定位** | 执行者 | 执行者 + 质量把关者 | **设计者 + 判断者 + 指导者** |
| **考核最大比重** | 数据标注 | 数据标注 | 智能训练、智能系统设计 |
| **国标培训参考学时** | 60 标准学时 | 50 标准学时 | 40 标准学时 |
| **典型岗位** | 数据标注员、数据采集员 | 数据审核员、初级数据处理工程师 | AI 流程设计师、算法测试工程师、解决方案设计师 |

**三处最容易被误解的地方：**

1. **五级和四级的职业功能模块名称相同，但要求完全不同。** 同样是「数据标注」：五级是"能根据标注规范完成文本/视觉/语音数据的清洗与标注"；四级是"能完成标注数据准确性和完整性审核，输出审核报告，并对发现的错误进行纠正"。前者是**做**，后者是**审**。

2. **三级不是"把四级做得更熟练"，而是模块整体换了一批。** 「数据采集和处理」「数据标注」「智能系统运维」这三个模块在三级理论考试中不再是主体，取而代之的是「业务分析」「智能训练」「智能系统设计」「培训与指导」。从四级考上三级，最大的转变是从"按规范执行"变成"设计规范本身、并判断规范对不对"。

3. **三级包含「培训与指导」模块。** 很多备考资料把"培训与指导"当成二级/技师才有的内容，这是错的。三级要求"能编写初级培训讲义""能对五级/初级工、四级/中级工开展知识和技术培训"，并且操作技能考核中有独立试题（试题代码 **4.2.1 数据采集和处理指导**）。本套三级资料的**课题 4-1** 专门覆盖这一块。

## 三、考核形式

认定分**理论知识考试**与**操作技能考核**两科，**两科均需 ≥60 分**方为合格（二级/技师及以上另有综合评审）。

各地评价机构的题量与时长口径存在差异，常见两种：

| 口径 | 理论知识考试 | 操作技能考核 |
|---|---|---|
| 社会化评价常见口径 | 单选 80 + 多选 10 + 判断 10，各 1 分，共 100 分 / 90 min | 4 道实操题，各 25 分，共 100 分 / 120 min |
| 地方技能竞赛口径 | 单选 140（0.5 分）+ 多选 20（1 分）+ 判断 20（0.5 分），共 100 分 | 含业务分析、智能训练、智能系统设计、培训与指导等模块 |

本套试题库按**每级理论 200 题**（单选 140 / 多选 30 / 判断 30）建设，覆盖面大于任一口径的单次考试题量，便于按需抽卷；另各配 **1 套 100 题模拟卷 + 4 道实操题**，按社会化评价口径编排，可直接计时模考。

> ⚠️ **以当地公告为准**：报考条件、题型题量、考试时长、所用软件平台因认定机构和考区而异。本资料提供知识与能力训练，不替代当地考试大纲。

## 四、怎么用这套资料

**如果你是考生（有老师/上课）**

1. 先读 `00-国标对应表.md`，确认自己报考等级要考哪些模块。
2. 按 `<等级>/教学大纲.md` 的课题顺序读 `学员讲义/`。每篇讲义末尾有**考点清单**和**随堂练习**，读完立刻做。
3. 做完全部课题后，刷 `试题库/` 的单选、多选、判断（带解析，错题看「易错点」栏）。
4. 最后计时做 `模拟卷`。实操题务必**动手写**，不要只看参考答案——操作技能考核是现场提交成果物的。

**如果你是考生（完全自学，没有老师/没上课）**

1. 先读 `<等级>/自学/00-自学使用说明.md`。
2. 按 `<等级>/自学/苏格拉底问答自学/` 顺序读，建立对每个模块的直觉。
3. 再通读 `<等级>/自学/自学教材/` 对应课题，每篇末尾的自测练习要动手做。
4. 刷 `试题库/`，考前用 `<等级>/自学/速查手册.md` 冲刺。

**如果你是授课教师**

1. `教学大纲.md` 给出完整学时分配方案，可按实际课时裁剪。
2. 每份 `教案/` 的第六节「教学过程设计」含时间轴、师生活动与讲授脚本，可直接照讲；第九节「考核对接」标明本课题对应的试题库题号，便于随堂测验。
3. 学员材料直接发 `学员讲义/` 对应课题即可，两者课题编号一一对应。

**实操环境**：见 `公共资源/环境搭建指南.md`。所有参考代码均在 Python 3.11 + pandas 2.x + scikit-learn 1.x 环境下编写。

## 五、资料来源与免责说明

**依据的权威来源**

- 《国家职业技能标准·人工智能训练师（2021 年版）》，人社部、工信部联合颁布（人社厅发〔2021〕81 号）。该标准由人社部职业技能鉴定中心、浙江省人社厅指导，阿里巴巴集团牵头，科大讯飞、百度等十余家单位参与起草。
- 标准含职业概况、基本要求、工作要求、权重表四部分；工作要求采用「职业功能—工作内容—技能要求—相关知识要求」四列结构。

**关于权重数值的重要说明**

本资料「命题蓝图」中使用的各模块百分比，来源为**地方技能竞赛技术文件与评价机构公开培训口径**，属于**改编/参考口径，并非国标权重表原文数值**。凡出现权重百分比处，均已就地标注来源。编写时未能获取国标 4.1/4.2 权重表的官方百分比原文，故不以国标名义呈现这些数字。请以当地鉴定机构发布的考试大纲为准。

**关于操作技能试题代码**

三级操作技能题按公开考区试题单的代码体系编排（1.1.1 业务流程设计、1.1.2 业务模块优化、2.1.1 数据清洗与标注规范、2.2.1 算法开发与测试、3.1.1 系统监控与优化、3.2.1 人机交互流程设计、4.2.1 培训与指导）。**不同年份、不同考区同一代码对应的试题名称可能不同**，代码仅用于标识考核模块归属，不代表真题。

**本资料性质**：自主编写的培训与复习材料，非官方教材，不含任何考试真题。
