## 一、Excel核心函数——为什么不能只靠"眼看手数"

先问一个问题：如果给你一张260行的门店销售表，让你数一下"已完成"状态的订单有多少条，你打算怎么数？

多数人的第一反应是肉眼一行行扫描数数，或者用Ctrl+F搜索再数。**行数一多，这种做法大概率会数错**——眼睛容易重复数或漏数，而且表只要一改动（比如又新增了几条订单），就得从头再数一遍。

这正是函数存在的意义：**把重复性的条件判断、计数、查找这类工作交给电脑去做，电脑不会累、不会漏，表格改了也能一键刷新结果。**

| 函数 | 作用 | 回答的问题 |
|---|---|---|
| `IF` | 条件判断 | "满足条件该归到哪一类？" |
| `COUNTIF` | 按条件计数 | "符合条件的有几个？" |
| `SUMIF` | 按条件求和 | "符合条件的加起来是多少？" |
| `VLOOKUP` | 按条件查找匹配值 | "这个编号对应的是什么？" |

配合数据透视表，可以完成大部分日常数据整理归类与汇总任务。

> 🔑 **判别口诀**：COUNTIF和SUMIF最容易被记混。记住——**问"有几个"用 COUNTIF，问"加起来是多少"用 SUMIF，问"对应的值是什么"用 VLOOKUP。** 别死记函数名，记它们各自回答的是哪一种问题，自然就不会用错。

**VLOOKUP为什么是这四个里最容易出错的一个？**

因为它的查找区域必须**锁定**。如果你把公式往下拉填充时忘了给查找区域加 `$` 符号（绝对引用），这个区域会跟着每一行悄悄往下偏移，查出来的值全是错的，甚至直接报 `#N/A`。这是Excel实操中最高频的一类报错来源，几乎每个新手都会踩一次——记住这个坑，下拉填充VLOOKUP之前，先检查查找区域是不是已经按 `F4` 锁定了。

**数据透视表解决的是什么问题？**

如果你要同时按"门店"和"月份"两个维度交叉汇总销售额，用SUMIF得为每一个"门店×月份"的组合单独写一条公式，表一改字段就要重写一遍。数据透视表不需要写公式——**把字段拖到行、列、值三个区域，它自动帮你交叉汇总；改变字段摆放的位置，就能立刻重新汇总出另一种视角的结果。** 这就是它比手写一堆SUMIF组合更高效的根本原因：它把"换个角度看数据"这件事，从"重写公式"变成了"拖一下鼠标"。

## 二、Python环境搭建——环境变量和命令行到底是什么

详细安装步骤见 `公共资源/环境搭建指南.md`。这里先讲清楚两个最容易让零基础学员发怵的词。

**命令行**，就是不用鼠标点图标，直接打字告诉电脑"做什么"的一个窗口——比如不点Jupyter的图标，而是在命令行里打字输入 `jupyter notebook` 回车，效果完全一样，只是换了一种"发指令"的方式。

**环境变量**里有一项叫 `PATH`，可以把它想象成电脑的一张"查找清单"：你在命令行输入 `python`，电脑会按这张清单上登记的路径，一个一个去找有没有一个叫 `python.exe` 的文件。**如果安装时没有勾选"Add Python to PATH"，这张清单里就没有登记这条路径，电脑压根不知道去哪找，输入 `python` 自然就报错或者跳到别的地方。**

### 一个真实的坑：输入python却跳到应用商店

Windows系统本身会预置一个"占位别名"——没装真正的Python时，在命令行输入 `python` 回车，系统会直接把你带到Microsoft应用商店，让你觉得"好像点一下就能装"。**这不是真的装上了Python，是系统的一个假动作。**

> 🔑 **判别口诀**：输入 `python` 后如果跳到应用商店，说明根本没装（或者装的路径没登记进环境变量）；如果弹出一堆看不懂的红字再报错，说明装是装了，但执行时另有问题（比如某个包没装、文件路径不对）。两种现象，对应完全不同的排查方向，别搞混。

### 为什么要用"专门的环境"，不直接装进系统默认环境

不同项目依赖的包版本可能互相冲突——比如本课程要求 `pandas` 锁定在 2.x 版本，而你以后参与的别的项目可能需要 3.x。如果所有项目都装进同一个系统默认环境，版本一冲突，新装的包就可能把旧项目依赖的版本覆盖坏，导致旧代码突然跑不通。**所以要用 conda / venv 建一个"隔离的工具箱"，每个项目用自己的工具箱，互不影响。** 本资料统一使用名为 `aitrainer` 的独立环境，已验证版本为 Python 3.11、pandas 2.x、scikit-learn 1.x——**按指南装，不要自己手贱升级版本**，尤其不要把pandas升到3.x，因为3.x默认行为和2.x有差异，同一段代码在两个版本上可能跑出不同结果。

安装完成后，核心使用流程是：安装Python → 安装依赖包 → 打开Jupyter Notebook → 运行代码。

### 验证是否装对了

```bash
python -c "import sys, pandas, numpy, sklearn, matplotlib, PIL, openpyxl; print('python', sys.version.split()[0])"
```

能看到各个包的版本号且没有报错，就说明环境是通的。

## 三、常见报错怎么看——报错不是惩罚，是地图

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError` | 包未安装 | `pip install` 对应包名 |
| `FileNotFoundError` | 文件路径或工作目录不对 | 核对相对/绝对路径 |
| `UnicodeDecodeError` | 编码格式不匹配 | 尝试指定 `encoding="gbk"` 或 `"utf-8"` |

**为什么会出现这些报错？把机制说清楚，而不只是记对照表：**

**`ModuleNotFoundError`**：Python执行 `import` 时，会去**当前激活环境**的包安装目录里找这个名字的模块，找不到就报错。注意——最常见的原因往往**不是真的没装**，而是**装到了别的环境里**（比如你装包时命令行提示符前没有 `(aitrainer)` 这个环境名，说明切错了环境，装进了别处）。

**`FileNotFoundError`**：Python读取文件用的是**相对当前工作目录**的路径，而"当前工作目录"不一定是你以为的那个文件夹——这才是报错的真正原因，并不一定是文件真的不存在。排查时先确认代码实际运行时的工作目录在哪，再核对文件路径写得对不对。

**`UnicodeDecodeError`**：文件在保存时用了某一种编码方式（比如GBK），而你读取时让Python按另一种编码方式（比如UTF-8）去解析——机制上相当于"拿错误的字典去翻译一段文字"，自然读不通，于是报错或者显示乱码。

### 正反对比：读不读最后一行，差的不只是几分钟

同一个 `FileNotFoundError`：同学A一看见报错就直接举手求助，等了5分钟老师才过来看；同学B自己翻到最后一行，发现是路径写错了一个字母，10秒自己改好继续做题。**同样的报错，有没有掌握"先看最后一行"这个方法，差的是分钟级别的效率——在有时间限制的实操考核里，这个差距会被放大成好几道题的分差。**

> 💡 **读报错的技巧**：Python报错信息通常最后一行是最关键的（错误类型+简要原因），不要被一长串红色文字吓到，先看最后一行。

### 回到开头的判断

现在回答最开始那个问题：遇到 `ModuleNotFoundError: No module named 'pandas'` 这种报错，该怎么办？

用这一节学到的方法——**先看最后一行**，锁定"pandas这个包没装好"；再确认一下是不是激活了正确的环境（命令行提示符前有没有 `(aitrainer)`）；运行 `pip install pandas` 或切换到正确环境即可。**30秒之内能解决的事，不需要重装系统，也不需要干等人来救场。**

## 随堂练习

**练习 1**：运行代码时出现`FileNotFoundError: [Errno 2] No such file or directory: 'data.csv'`，该怎么排查？

<details><summary>答案</summary>检查当前工作目录是否与data.csv文件所在目录一致，或改用绝对路径指定文件位置；也可能是文件名拼写错误或扩展名不符。</details>

**练习 2**：运行代码提示`ModuleNotFoundError: No module named 'pandas'`，该怎么解决？

<details><summary>答案</summary>说明pandas这个包还没有安装，在命令行执行`pip install pandas`安装后再运行。注意要确认当前激活/使用的是正确的Python环境，否则可能装到了别的环境里，运行代码时还是提示找不到模块。</details>

**练习 3**：打开一个中文CSV文件时出现乱码或`UnicodeDecodeError`，该怎么处理？

<details><summary>答案</summary>多数情况是编码格式不匹配，可以尝试在读取时指定编码参数，比如`encoding="gbk"`或`encoding="utf-8"`，如果一种不行就换另一种尝试。也可以在保存文件时统一使用"UTF-8 with BOM"（即utf-8-sig）编码，避免Excel等软件打开时乱码。</details>

**练习 4**：Excel的VLOOKUP函数和COUNTIF函数分别用来做什么？

<details><summary>答案</summary>VLOOKUP用来按条件在另一张表或区域中查找匹配的值（如根据商品编号查找对应的商品名称）；COUNTIF用来统计满足特定条件的单元格数量（如统计某一列中某个值出现了多少次）。两者都是数据整理归类汇总时的常用函数。</details>

**练习 5**：遇到报错信息一大段看不懂的红色文字，正确的心态和做法是什么？

<details><summary>答案</summary>不要被一长串文字吓到，先看报错信息的最后一行——这通常包含了最关键的错误类型和简要原因（如ModuleNotFoundError、FileNotFoundError等）。根据最后一行的信息类型，再结合报错提到的文件名、模块名等具体信息去排查，而不是一看到报错就直接放弃。</details>
