## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + Pillow 12.3.0 下实测验证通过。

```python
from PIL import Image
from pathlib import Path
import re

files = sorted(Path("images").glob("*.jpg"))
sizes = {}
irregular_names = []
for p in files:
    img = Image.open(p)
    sizes.setdefault(img.size, []).append(p.name)
    if not re.match(r"^[a-z]+_\d{3}", p.name):
        irregular_names.append(p.name)

print("分辨率分布:", {k: len(v) for k, v in sizes.items()})
print("命名不规范文件:", irregular_names)
print("总文件数:", len(files))
```

**实测**：共42张图像。分辨率分布：640×480规格37张、320×240规格4张、1280×960规格1张——**存在分辨率不一致问题**；命名不规范文件（含中文、空格、非标准格式）若干张，如`IMG_3.jpg`、`商品图片16.jpg`、`new photo 29.jpg`等；另存在两组因重复保存产生的重复图像（文件名含"copy"/"副本"后缀）。

**处理措施**：
1. 分辨率不一致的5张图像，若内容可用，应统一重新采集为标准规格（640×480）；
2. 命名不规范的文件应按规范重命名（如`类别_序号.jpg`的标准格式）；
3. 重复图像去重，仅保留一份，避免同一样本在数据集中被重复计入。
