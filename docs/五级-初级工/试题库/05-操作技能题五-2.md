## 一、场地设备要求

## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

```python
import pandas as pd
d = pd.read_csv("sales_raw.csv")

print("归一化前:", d["商品类别"].value_counts().to_dict())

d["商品类别"] = d["商品类别"].str.strip().replace({"手機": "手机"})
d["销售地区"] = d["销售地区"].str.strip()
d["下单日期"] = pd.to_datetime(d["下单日期"], errors="coerce", format="mixed")

print("归一化后:", d["商品类别"].value_counts().to_dict())
print("日期转换失败数:", d["下单日期"].isna().sum())
```

**实测**：归一化前"手机"分散为94+20（含尾空格）+21（手機）三行；归一化后合并为**135条**。统一格式后商品类别分布更真实地反映了销量占比。

**汇总对比结论**：归一化前的汇总会让"手机"品类的统计值显著低于其真实销量（94 vs 135，低估约30%），若业务方据此判断品类受欢迎程度会产生误导性结论。这说明**汇总前的归类整理工作直接影响业务决策的可靠性**。
