## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

```python
import pandas as pd
d = pd.read_csv("labeled_results.csv")

print("情感标签分布:")
print(d["情感标签"].value_counts(dropna=False))
print("占比:")
print(d["情感标签"].value_counts(dropna=False, normalize=True).round(3))

print("标注员完成量:")
print(d["标注员"].value_counts())
```

**实测**：共400条记录。

**情感标签分布**：正面348条（87.0%）、负面28条（7.0%）、中性12条（3.0%）、**"中性偏正"5条（1.25%，规范外取值）**、**"3"4条（1.0%，规范外取值）**、空值3条（0.75%）。

**标注员完成量**：A02完成120条、A01完成99条、A03完成90条、A04完成84条、**A05仅完成7条**。

**异常识别**：
1. **"中性偏正""3"属于规范外的标签取值**（标注规范只定义了"正面/负面/中性"三类）——需核查这9条记录的来源，可能是标注工具输入校验缺失或标注员理解偏差；
2. **A05完成量仅7条，远低于其他标注员的84-120条**——明显异常，需要上报核实是任务分配问题、设备故障，还是其他原因，不能当作正常的个体差异忽略。
