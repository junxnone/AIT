## 一、场地设备要求

计算机一台，Python 3.11 + pandas，提供`reviews_raw.csv`（625条评价原始数据），不得联网。

## 二、试题正文

**第1题（20分）** 按规范完成数据清洗：去除完全重复记录、空/空白文本、HTML标签、非法评分（不在1-5范围）；清洗后另存为`reviews_cleaned.csv`，不得覆盖原文件。

**第2题（5分）** 输出清洗前后的数据量对比及各类问题的记录数。

## 三、评分表

| 序号 | 考核内容 | 配分 | 评分标准 |
|---|---|---|---|
| 1.1 | 去重 | 5 | 正确识别并去除重复行得5分 |
| 1.2 | 去空/空白 | 5 | 正确处理得5分 |
| 1.3 | HTML标签清理 | 5 | 正确清理得5分 |
| 1.4 | 非法评分过滤 | 5 | 正确过滤得5分 |
| 2.1 | 结果统计 | 5 | 完整统计得5分 |
| | **合计** | **25** | |

**否决项**：未提交`reviews_cleaned.csv`或直接覆盖了原始文件`reviews_raw.csv`，本题不得分。

## 四、参考答案

> ⚠️ 以下数值在 Python 3.11.17 + pandas 2.3.3 下实测验证通过。

```python
import pandas as pd

df = pd.read_csv("reviews_raw.csv")
n_raw = len(df)
report = {}

report["完全重复行"] = int(df.duplicated().sum())
df = df.drop_duplicates()

df["评价内容"] = df["评价内容"].astype(str).str.replace(r"<[^>]+>", "", regex=True)

report["空/空白评价"] = int(df["评价内容"].str.strip().eq("").sum())
df = df[df["评价内容"].str.strip() != ""]

report["非法评分"] = int((~df["评分"].between(1, 5)).sum())
df = df[df["评分"].between(1, 5)]

df.to_csv("reviews_cleaned.csv", index=False, encoding="utf-8-sig")

print(f"清洗前 {n_raw} 行 → 清洗后 {len(df)} 行")
for k, v in report.items():
    print(f"  {k}: {v} 条")
```

**实测输出**：

```
清洗前 625 行 → 清洗后 581 行
  完全重复行: 25 条
  空/空白评价: 9 条
  非法评分: 10 条
```

> 📌 注意：空/空白评价与非法评分的计数是在**去重之后**依次统计的（而非对原始625行分别统计），因此这三项之和（25+9+10=44）恰好等于"清洗前-清洗后"的差值（625-581=44）。若直接对原始数据分别统计三类问题再相加，数字可能对不上（因为可能有记录同时满足多个问题条件）——写报告时应如实按清洗流程**依次过滤后**观测到的数字记录，而不是把各类问题在原始数据上分别统计再相加。

> 💡 清洗结果已另存为`reviews_cleaned.csv`，原始文件`reviews_raw.csv`保持不变——这是本题的否决项考核要点。
