# 教案 · 课题 0-2：法律法规与数据安全基础

| 项目 | 内容 |
|---|---|
| 所属等级 | 五级 / 初级工 |
| 对应国标 | 2.2 相关法律法规 |
| 学时 | **4 学时**（理论 4，共 240 min） |
| 授课类型 | 纯理论（案例讨论为主，无需机房环境） |
| 教学场地 | 普通教室 |

---

## 一、教学目标

### （一）知识目标
1. 能说明《劳动法》《劳动合同法》《网络安全法》《知识产权法》的基本规定（国标明列四部）。
2. 能说明《数据安全法》《个人信息保护法》的基本要求（延伸内容），并**能说明为什么这两部"延伸法规"在日常工作中比国标四部更高频触发**。

### （二）技能目标
1. **能识别日常工作中的数据安全违规行为**。
2. **能运用判别口诀对未见过的新场景做出判断**，而不是只会照搬记忆过的几个违规案例——即能区分"真正违规"与"看似可疑但不违规"的边界，不过度泛化规则。

### （三）素养目标
1. 建立"**标注员本人就是数据安全链条上的一环**"的岗位责任意识，摒弃"出发点是好的/只是工作需要，就不算违规"的侥幸心理。

---

## 二、教学重点与难点

### 重点
1. 日常工作场景中的违规行为识别（私自拷贝、截图分享、非授权设备处理数据等）。
2. 延伸法规（数据安全法、个人信息保护法）适用场景的识别——明确其比国标四部更高频触发的原因。

### 难点

| 难点 | 学员典型错误预判 | 突破方式 |
|---|---|---|
| 零基础学员容易认为"反正是工作需要，拷贝一下数据没关系"，缺乏对数据安全链条的风险认知 | 把"出发点是工作需要／没有恶意"直接等同于"行为合规"，只关注动机，不关注客观后果 | 用判别口诀把关注点从"动机"转移到"信息流向"：**这条信息离开我手上之后，去的是受公司管控、能追责的地方，还是管不着、追不到的地方？** 配合三场景案例讨论与后果分析，让学员亲眼看到"动机良好 ≠ 没有风险" |

---

## 三、学情分析与前置知识

**前置知识**：课题0-1（职业认知与职业守则）。

**学情判断**：

- 零基础学员普遍对"数据安全"缺乏切身体会，容易认为"反正是工作需要，拷贝一下数据没关系""只是发个截图又不是故意泄露"。这种认知偏差**不是知识性的，而是风险意识层面的**——他们不是不知道有这些法规，而是意识不到自己日常的小动作已经触碰了红线，需要用真实后果案例逐一打破，而不是靠背法条解决。
- 学员对国标明列的《劳动法》《劳动合同法》这类"大而远"的法律有模糊印象（听过名字），但对《数据安全法》《个人信息保护法》这类"管自己每天具体操作"的延伸法规普遍陌生——这个认知落差本身就是本课题要纠正的重点。
- 刚接触行业，容易把"合规"理解成一张静态的"违规清单"去死记硬背，而不是建立一套可以推广到新场景的判断逻辑，这也是技能目标2（举一反三）要专门训练的地方。

---

## 四、教学方法与手段

1. **认知冲突法**（开篇）：用一个"看起来很合理、出发点也不坏"的真实场景做判断钩子，让学员先公开表达判断，再在课程推进中用后果分析推翻直觉。
2. **案例讨论法**（核心）：用真实（或贴近真实）的日常场景，让学员自己先判断再公布解析，而非直接灌输结论。
3. **口诀内化法**：把"识别违规"的判断逻辑收敛成一句可复用的判别口诀，并用变式练习（含不违规的反例）检验学员是否真正掌握了判断逻辑，而不是死记硬背案例表面。
4. **分组互评法**：让学员自己编场景、互相判断，从"听教师讲案例"升级到"自己能出题、能判断别人的场景"。

### 环节一：导入——判断钩子（0–10′）

**教师活动**——投影展示（不给结论）：

> "某标注员觉得一条标注规则写得不清楚，为了向同事请教，把一张**含有用户手机号**的原始样本截图发到了工作群里讨论。
>
> 这是工作群，又不是私人聊天，而且出发点是认真讨论工作——**这样做违规吗？**"

**提问话术**：

> "请大家花三十秒，把你的判断写下来：违规，还是不违规？先不说理由，只写结论。"

（预期：学员意见会分裂，相当一部分认为"工作群+出发点正当"应该不算违规）

> "好，先记住你刚才的判断，和你写下的理由。这节课快结束时我们会回来验证——你会发现这个看起来'很合理'的操作，恰恰是最容易被忽视的违规高发点。"

**设计意图**：不急于否定，让错误或模糊的判断先被公开写下来，后面环节五的解析才有冲击力。

---

### 环节二：新授——国标四部法规基本规定（10–50′）

**讲授脚本**：

> "我们先打基础。国标明确列出了四部和我们这个职业相关的法律：《劳动法》《劳动合同法》《网络安全法》《知识产权法》。这四部法规到底管什么，我们逐个过一遍——不要求你背条文，但要知道每一部'管的是哪一块'。"

**逐部讲解**（板书 + 结合岗位举例）：

| 法规 | 管什么 | 和训练师岗位的关联 |
|---|---|---|
| 《劳动法》 | 规范劳动者的工作时间、休息休假、劳动安全卫生等基本权利义务 | 关系到你作为员工的基本权益，入职后接触一次，日常工作中较少直接用到 |
| 《劳动合同法》 | 规范用人单位与劳动者签订、履行、变更、解除劳动合同的具体规则 | 签合同时最相关，日常标注工作里基本不会触发 |
| 《网络安全法》 | 规范网络运行安全、网络信息安全，要求对个人信息和重要数据采取保护措施 | 是后面要讲的《数据安全法》《个人信息保护法》的"上位法"，三部法规一脉相承 |
| 《知识产权法》 | 保护著作权、专利权、商标权等智力成果 | 标注工作中如果使用了他人拥有版权的图片、文本语料做训练数据，必须确认授权范围，不能擅自使用 |

**教师追问**：

> "大家留意一下，这四部里，哪两部是'入职签一次字、基本就用不太上'的？哪两部是跟'你每天干的具体活儿'关系更紧的？"

（引导学员答出：劳动法/劳动合同法偏用工关系，网络安全法/知识产权法开始和日常数据处理沾边）

> "记住这个区分，下一个环节我们要讲的两部延伸法规，管的就是'你每天具体在干的事'。"

**学员活动**：记录四部法规的基本规定与关联场景，对照表格复述一遍每部法规"管什么"。

---

### 环节三：新授——延伸法规及为什么更高频触发（50–80′）

**讲授脚本**：

> "国标明列的是这四部，但实际工作中，**真正高频被触发的往往不是这四部，而是两部国标之外的延伸法规**：《数据安全法》《个人信息保护法》。"

**逐部讲解**：

| 法规 | 管什么 |
|---|---|
| 《数据安全法》 | 规范数据处理活动，要求按重要程度对数据分类分级保护，建立数据安全管理制度 |
| 《个人信息保护法》 | 规范个人信息处理活动，要求遵循最小必要、目的限制等原则，不得超出授权范围处理个人信息 |

**为什么延伸法规比国标四部更高频触发（机制讲解）**：

> "回想上一环节的结论：《劳动法》《劳动合同法》规范的是你和公司之间的用工关系，日常标注工作中很少直接碰到；《知识产权法》也只在涉及他人作品、素材版权时才会用上。
>
> 但《数据安全法》《个人信息保护法》管的恰恰是你**每天都在接触的东西**——原始数据本身。只要你的工作内容是处理、标注、审核数据，你每一次打开一条含用户信息的样本、每一次导出、每一次转发，理论上都受这两部法规约束。"

**板书核心句**：

> **它们管的是你每天都在做的具体动作，而不是入职时签一次字就完事的条款。**

> "这就是为什么新人最容易'踩坑'的，不是劳动合同条款，而是这两部延伸法规——触发频率和你每天打开多少条数据直接挂钩。"

**学员活动**：对照自己过去一天的工作流程（如果已有实习或实训经历），说出一个可能涉及《数据安全法》或《个人信息保护法》的具体操作环节（提问2–3人）。

### 环节五：案例讨论——三场景日常违规行为识别（难点突破核心，90–130′）

> 📌 **教学提示**：本环节是全课题重点+难点交汇处，务必让学员"先判断、再公布答案"，不要提前剧透。

**教师逐条提问，先让学员自己判断**：

| 场景 | 学员判断 | 正确答案 |
|---|---|---|
| 把工作中接触的样本截图发到个人社交账号炫耀 | | **违规**——即便"只是截图"，只要截图里含有用户信息，就构成数据泄露：数据离开了公司授权的处理范围，进入了完全不受管控的个人社交空间 |
| 在家用个人电脑远程处理公司标注任务 | | **违规**——非授权设备处理数据存在泄露风险：个人电脑的安全防护水平、数据留存和清理方式都不受公司管控，设备丢失或被攻击时数据可能直接泄露 |
| 发现规范有歧义，截图发给同事讨论（样本含用户隐私信息） | | **违规**——应先脱敏再讨论，或走正式上报渠道，"讨论工作"这个出发点不能成为未脱敏信息扩散的理由 |

**预期学员反应与教师应对**（以第一条为例）：

| 学员反应 | 教师应对 |
|---|---|
| "只是分享工作成果，又没有恶意，应该没事" | 追问："截图里如果包含了用户的照片、文字内容，这些信息一旦发到公开或半公开的社交平台，是不是已经脱离了公司能控制的范围？这和'有没有恶意'无关，是'信息是否已经泄露'的客观事实问题。" |
| "在家处理效率更高，公司应该是允许的" | 追问："效率高低是一回事，但你有没有确认过，公司是否给你的个人电脑开通过授权、做过安全核验？没有书面授权的设备，出了问题谁来担责？" |

**回扣导入**：

> "现在回到开头那个判断题——把含手机号的截图发到工作群讨论规则，到底违规不违规？
>
> 答案是：**违规**。即使是工作群、即使出发点是认真讨论问题，**未脱敏的用户手机号被发到群里（哪怕群里都是同事）也构成敏感信息扩散**。正确做法是：先对截图做脱敏处理（遮挡手机号），或者干脆不附截图、只用文字描述问题本身，再通过正式渠道反馈给负责制定规范的人。"

**教师总结话术**：

> "三个场景看似不同，共同点是什么？**都在用'出发点是好的'去掩盖'客观上数据已经离开了受控范围'这个事实。** 标注员本人就是数据安全链条上的一环。接触原始数据的人越多，泄露风险越高。'只是私下看看''只是截个图''反正是工作群'——这类想法都是常见的违规诱因，记住这条链条意识，比记住法条本身更重要。"

---

### 环节六：深化——违规后果分析（130–160′）

**讲授脚本**：

> "很多人觉得'截图发个群''拷贝一份带回家'顶多算'不太规范'，不会有什么实质后果。这个想法低估了问题的严重性——我们分三层看。"

**逐层讲解**：

| 层次 | 具体后果 |
|---|---|
| 对用户 | 手机号、地址这类信息一旦流出，轻则被骚扰电话、精准诈骗盯上；如果是医疗、金融类敏感数据，可能被用于更严重的身份冒用 |
| 对公司 | 根据《数据安全法》《个人信息保护法》，公司对外部泄露负有合规责任，轻则被监管部门处罚、客户索赔，重则项目被叫停、公司资质受影响 |
| 对本人 | 造成泄露的具体操作人需要承担相应责任，情节严重的甚至要承担法律责任，而不是"批评教育"就能了结 |

**板书核心句**：

> **代价和动作的大小完全不成比例**——一次随手的截图外发，后果可能远超当事人的预期。

**学员活动**：讨论"为什么合规培训反复强调'截图''私拷'这类看起来很小的动作"，请2–3人用自己的话复述这句话背后的逻辑。

**教师追问**：

> "有没有发现，这三层后果里，哪一层是最容易被新人忽略的？"

（引导学员意识到：大多数人只想到"对公司"或完全没想到"对用户""对自己"，而"对自己要担责"这一层恰恰是最容易被低估的）

---

### 环节七：判别口诀归纳与变式练习（160–190′）

**讲授脚本**：

> "三个场景讲完了，但考试和实际工作不会只出现讲过的原题。我们把判断逻辑收敛成一句口诀，用来应对没见过的新场景。"

**板书判别口诀**：

> **这条信息离开我手上之后，去了一个受公司管控、能追责的地方，还是一个管不着、也追不到的地方？**
>
> 去受控渠道（如正式工单系统）通常没问题；去工作群、个人社交账号、私人设备，都属于管不着的地方，一律先脱敏或先问。

**变式练习**（含1个违规 + 1个不违规，检验是否过度泛化）：

| 场景 | 学员判断 | 正确答案 |
|---|---|---|
| 用个人网盘备份当天标注的原始数据文件，方便晚上在家接着干 | | **违规**——个人网盘不受公司管控，原始数据离开了受控渠道 |
| 把当日完成标注数量的截图（不含任何用户数据或原始样本内容）发朋友圈炫耀进度 | | **不违规**——截图内容只是工作量数字，不含受管控的原始数据或个人信息 |

**预期学员反应与教师应对**：

| 学员反应 | 教师应对 |
|---|---|
| 认为第二条也违规，理由是"反正是发朋友圈，和第一个案例一样" | 追问："判别口诀问的是'信息'本身是什么，不是'发不发朋友圈'这个动作本身。这张截图里有没有原始数据或个人信息？" —— 引导意识到口诀的关键变量是"内容"，不是"渠道"本身 |
| 认为第一条不违规，理由是"只是为了方便工作" | 用环节一、五已经强调过的话反问："'方便工作'这个理由，前面三个场景是不是也都用过？它能不能改变'数据离开受控范围'这个客观事实？" |

**教师总结**：

> "这道变式练习是本课题最关键的一步：**判别口诀不是用来把所有'发出去'的行为都打成违规，而是帮你准确分清哪些真的违规、哪些不违规**。只会死记三个案例，遇到没见过的场景就会乱猜；真正学会口诀，才能举一反三。"

---

### 环节八：分组互评——学员自编场景（190–215′）

**任务布置**：

> "每组发一张空白场景卡片。请你们**自己编一个违规场景和一个不违规场景**（各写2–3句话描述），不要照抄前面讲过的案例。写完后和邻组交换，用判别口诀判断对方写的两个场景，并说明理由。"

**教师巡回指导要点**：

- 发现学员编的"违规场景"其实判别模糊（如没写清楚是否含个人信息）时，提示："把场景写具体——这个信息到底含不含用户的隐私内容？流向了哪里？"
- 发现学员把"不违规场景"写成了变相的违规场景（如"发朋友圈但配文里透露了用户姓名"）时，提示回看判别口诀的"信息内容"这个关键变量。

**汇报与点评**（约5分钟）：抽2–3组展示自己编的场景和对方的判断，教师点评判别依据是否准确，而非只看结论对错。

---

### 环节九：阶段性小测（215–230′）

**教师活动**：发放5道小测题，覆盖四部法规基本规定的识别 + 延伸法规高频触发原因 + 场景判断（题目方向对应题库单选9–14、判断3），当堂巡视，统一讲评。

**学员活动**：独立完成，交卷后对照答案自评，标出做错的题目对应哪一类知识点（法规内容记忆类，还是场景判断类）。

### 环节十：小结与作业（230–240′）

**知识回顾**（请学员口述，教师补全）：

1. 国标四部法规和延伸两部法规分别管什么？为什么延伸法规更高频触发？
2. 判别口诀是什么？它判断的关键变量是"动作"还是"信息内容/流向"？
3. 违规一旦发生，对用户、对公司、对本人分别会造成什么后果？

**回扣主线**（板书收口）：

> "这节课的核心不是背下六部法规的名字，而是记住一条判断逻辑：**看信息流向，不看动机好坏**。标注员本人就是数据安全链条上的一环，这条链条意识，比记住法条本身更重要。"

**作业**：见下方"作业与课后任务"表。

## 七、板书设计

**主板书区**

```
国标四部：劳动法 / 劳动合同法 / 网络安全法 / 知识产权法   （管用工关系、版权，低频触发）
延伸法规：数据安全法 / 个人信息保护法                      （管你每天的具体操作，高频触发）

数据安全链条：标注员本人也是链条上的一环
  接触原始数据的人越多 → 泄露风险越高

判别口诀：
  信息离开手上后，去的是【受控可追责】的地方，还是【管不着追不到】的地方？

┌──────────────── 一旦泄露，后果 ────────────────┐
│ 对用户：骚扰电话 / 精准诈骗 / 身份冒用            │
│ 对公司：监管处罚 / 客户索赔 / 项目被叫停          │
│ 对本人：个人担责，不是"批评教育"就能了结          │
└──────────────────────────────────────────────────┘
```

**副板书区（违规 vs 不违规 判别对比，变式练习用）**

```
              违规                          不违规
场景举例      含隐私截图发工作群/个人网盘备份   截图仅含工作量数字发朋友圈
判别关键      含原始数据或个人信息              不含任何原始数据/隐私信息

判别口诀落脚点：看"信息内容"，不是只看"发没发出去"这个动作本身
```
