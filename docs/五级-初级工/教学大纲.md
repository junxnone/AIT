## 一、课程性质与定位

五级/初级工是本职业的**入门等级**，也是国标中培训学时最多的等级（60 学时，高于四级的 50 和三级的 40）。原因很直接：**零基础学员需要先把工具和规范学会，才谈得上做得准。**

本等级的能力关键词是「**完成**」——

| 职业功能 | 五级要做到 |
|---|---|
| 数据采集和处理 | 能利用设备、工具**完成**原始业务数据采集；能**完成**数据库内业务数据采集；能按要求**完成**数据整理归类与汇总 |
| **数据标注**（考核最大比重） | 能根据标注规范**完成**文本、视觉、语音数据清洗；能根据标注规范**完成**文本、视觉、语音数据标注；能利用工具对标注后数据**分类**与**统计** |
| 智能系统运维 | 能**开启**智能系统、能**简单使用**；能**记录**系统功能应用情况与应用数据情况 |

**一句话概括五级的角色**：按照别人写好的规范，把数据采准、洗净、标对，并把过程记录下来。

> 📌 **贯穿全课程的一条主线**：**规范怎么写，就怎么标——拿不准不要自己发挥，要问。**
> 初学者最常见、也最致命的错误不是"不会标"，而是"遇到规范没写清楚的边界样本时，自己凭感觉定了一个标准，并且一直这么标下去"。一个人自作主张的一致偏差，会污染整批数据，且极难在质检中被发现（因为他自己内部很"一致"）。
> 正确做法：**标注过程中遇到规范未覆盖的情形，记录下来上报，由规范制定者统一裁定后再批量处理。** 这条贯穿课题 2-1 至 2-5，也是四级"审核"与三级"制定规范"能力的起点。

## 二、培训对象与前置要求

**申报条件**（满足其一，以当地公告为准）：

- 累计从事本职业或相关职业工作 **1** 年（含）以上；
- 本职业或相关职业学徒期满；
- 取得技工院校、中等及以上职业院校本专业或相关专业毕业证书（含在读应届生）。

**知识前置**：

- **无特殊专业要求**，零基础可入学；
- 具备基本的计算机操作能力（文件管理、浏览器使用、中英文录入）；
- 职业能力特征要求：具有一定的学习能力、表达能力、计算能力，**空间感、色觉正常**（视觉数据标注需要）。

## 四、各课题教学要求

> 标注说明：**【知】** = 知识要求（理论考点）｜**【技】** = 技能要求（实操考点）｜**【素】** = 素养要求

### 课题 0-1 职业认知、等级体系与职业守则（4 学时）

- 【知】**能完整表述职业定义**：使用智能训练软件，在人工智能产品实际使用过程中进行数据库管理、算法参数设置、人机交互设计、性能测试跟踪及其他辅助作业的人员
- 【知】能说明本职业包含**数据标注员**、**人工智能算法测试员**两个工种
- 【知】能说明五个等级的名称与各级能力重心
- 【知】**能表述职业守则三条**：诚实公正、严谨求是；遵章守法、恪尽职守；勤勉好学、追求卓越
- 【技】能在给定情境中判断行为是否符合职业守则（如：为赶进度随意批量标注、擅自把样本数据拷贝外发、发现规范有歧义选择上报）
- 【知】能说明考核形式、题型与合格标准
- 【素】建立"数据质量决定模型上限"的职业价值认知——标注不是机械劳动，错一个标签就是给模型喂一条错误知识

### 课题 0-2 法律法规与数据安全基础（4 学时）

- 【知】能说明《劳动法》《劳动合同法》中与劳动者权利义务相关的基本规定
- 【知】能说明《网络安全法》《知识产权法》与数据工作的关联点（国标明列四部法规）
- 【知】能说明《数据安全法》《个人信息保护法》的基本要求（延伸内容，实际认定高频涉及）
- 【技】**能识别日常工作中的数据安全违规行为**：私自拷贝 / 外发数据、在非授权设备处理数据、截图分享含个人信息的样本、使用非授权渠道获取的数据
- 【知】能说明保密义务、数据最小必要原则、脱敏的基本概念
- 【素】理解**标注员本人就是数据安全链条上的一环**——接触原始数据的人越多，泄露风险越高

### 课题 0-3 计算机、办公软件与 Python 环境（4 学时）

- 【技】能完成文件与目录管理、压缩解压、编码格式识别与转换（UTF-8 / GBK 乱码处理）
- 【技】**能熟练使用 Excel / WPS**：排序、筛选、查找替换、分列、去重、条件格式、常用函数（`IF`/`COUNTIF`/`SUMIF`/`VLOOKUP`）、数据透视表
- 【技】**能完成 Python 环境安装与 Jupyter Notebook 的基本使用**（见 `../公共资源/环境搭建指南.md`）
- 【技】能运行给定的 Python 脚本、读懂报错信息的第一行并定位问题
- 【知】能说明 CSV / Excel / JSON / TXT 等常见数据文件格式的特点与适用场景

### 课题 0-4 人工智能与机器学习入门（4 学时）

- 【知】能说明人工智能、机器学习、深度学习三者的包含关系
- 【知】**能解释监督学习、无监督学习、强化学习的区别**，并能判断给定任务属于哪一类
- 【知】**能说明监督学习为什么高度依赖标注质量**——标注即"标准答案"，答案错了模型学到的就是错的
- 【知】能说明神经网络的输入层—隐藏层—输出层结构，理解"训练即调整权重"
- 【知】能说明训练集、验证集、测试集的作用
- 【知】能说明常见 AI 任务类型（分类、检测、分割、识别、生成）与所需标注形式的对应关系

### 课题 1-1 设备与工具的原始业务数据采集（4 学时）

- 【知】能说明常见数据来源渠道：用户行为日志、业务系统导出、传感器 / 设备采集、第三方采购、公开数据集
- 【知】**能说明采集前必须确认的三件事**：数据用途、授权范围、采集口径（字段定义、时间范围、抽样规则）
- 【技】**能使用采集设备 / 工具完成原始业务数据采集**（图像拍摄、音频录制、屏幕 / 日志导出等），并满足给定的规格要求（分辨率、采样率、格式、命名规则）
- 【技】能按规范完成采集文件的命名、归档与采集记录登记
- 【技】能识别采集过程中的质量问题（图像模糊 / 过曝、录音底噪过大 / 截断、日志字段缺失）并当场重采

### 课题 1-2 数据库内业务数据采集（SQL 查询与导出）（4 学时）

- 【知】能说明数据库、表、字段、主键、记录的基本概念
- 【技】**能编写基础 SQL 完成数据查询与导出**：`SELECT` / `WHERE` / `ORDER BY` / `LIMIT` / `GROUP BY` / `COUNT` / 基础 `JOIN`
- 【技】能根据数据需求说明书，将业务需求翻译成查询条件（时间范围、状态筛选、字段选取）
- 【技】能将查询结果导出为 CSV / Excel，并验证导出行数与预期一致
- 【素】**导出前先 `COUNT` 核对数量**——这是避免"少导一半数据还没发现"的基本习惯

### 课题 1-3 业务数据整理归类（4 学时）

- 【知】能说明数据整理的基本要求：格式统一、字段规范、编码一致、无明显脏数据
- 【知】能说明归类的作用——归类体系影响后续标注效率与一致性
- 【技】**能根据数据处理要求完成业务数据的整理与归类**：按业务维度分组、建立目录结构、统一命名规则
- 【技】能处理常见格式问题：日期格式不统一、全半角混用、首尾空格、单位不一致、大小写混乱
- 【技】能用 Excel 与 pandas 两种方式完成同一整理任务

### 课题 1-4 业务数据汇总（Excel + pandas）（4 学时）

- 【知】能说明常见汇总口径：计数、求和、均值、最大 / 最小、占比、同比环比
- 【技】**能根据数据处理要求完成业务数据汇总**并输出汇总表
- 【技】能用 Excel 数据透视表完成多维汇总
- 【技】**能用 pandas 的 `groupby` / `agg` / `pivot_table` 完成同样的汇总**并导出结果
- 【技】能对汇总结果做合理性自查（总数是否对得上、占比之和是否为 100%、有无异常极值）

### 课题 2-1 文本 / 视觉 / 语音数据清洗（6 学时）

- 【知】能说明数据清洗的目标：去除重复、缺失、异常、噪声数据，统一数据格式
- 【技】**文本清洗**：去重、去空、去乱码、去 HTML 标签与表情符号、统一编码与全半角、过滤超长 / 超短样本、敏感信息替换
- 【技】**视觉清洗**：剔除损坏 / 重复 / 模糊 / 过曝图像，统一分辨率与格式，核对图像与标注文件的对应关系
- 【技】**语音清洗**：剔除静音 / 截断 / 底噪过大的音频，统一采样率与格式，核对音频与文本的对应关系
- 【技】能用 pandas 完成结构化与文本数据的自动化清洗，并输出清洗后文件与清洗记录
- 【知】**能说明清洗必须按规范执行、并保留原始数据**——清洗是不可逆操作，不能直接覆盖原文件

### 课题 2-2 文本数据标注实操（4 学时）

- 【知】能说明常见文本标注任务类型：文本分类（情感、意图）、命名实体识别（NER）、序列 / 槽位标注
- 【技】**能根据标注规范完成文本分类标注**
- 【技】**能根据标注规范完成实体标注**，并严格遵守规范中的**实体边界切分规则**（如"北京大学第三医院"整体标注还是拆分，必须依规范而非凭感觉）
- 【技】能正确处理规范中定义的特殊情形：多标签、嵌套实体、不确定样本的标记方式
- 【素】**遇到规范未覆盖的边界样本，记录并上报，不自行定标准**

### 课题 2-3 视觉数据标注实操（4 学时）

- 【知】能说明常见视觉标注任务类型：图像分类、目标检测（矩形框）、关键点标注、语义 / 实例分割
- 【技】**能根据标注规范完成图像分类与目标检测标注**，框选做到**贴合物体边缘、不遗漏、不重复**
- 【技】能正确处理遮挡、截断、密集小目标、模糊目标等情形（依规范规定的处理方式）
- 【知】能说明标注文件的常见格式（如 YOLO / VOC / COCO 的基本结构）及其与图像文件的对应关系
- 【素】**宁可慢一点标准确，也不要为赶量粗框**——框偏一点，模型学到的位置就偏一点

### 课题 2-4 语音数据标注实操（4 学时）

- 【知】能说明常见语音标注任务类型：语音转写（ASR 标注）、说话人分割 / 识别、语音情感与语调标注
- 【技】**能根据标注规范完成语音转写**，并严格遵守规范对语气词、重复词、口音词、数字读法、标点的处理规定
- 【技】能完成时间轴切分标注（标出某说话人的起止时间）
- 【技】能正确处理听不清、多人重叠、背景噪声干扰的片段（依规范标记为存疑而非猜测填写）
- 【知】能说明转写规范的统一性为什么重要——同一个"嗯"有人写有人不写，模型就学不到稳定规律

### 课题 2-5 标注后数据分类与统计（4 学时）

- 【知】能说明标注交付前须完成的自检项：数量完整、格式合规、标签取值合法、文件对应关系正确
- 【技】**能利用分类工具对标注后数据进行分类**（按标签、按任务批次、按质量状态分目录 / 分表）
- 【技】**能利用统计工具对标注后数据进行统计**：各标签数量与占比、标注完成量、缺漏统计、类别分布可视化
- 【技】能用 Excel 与 pandas 两种方式输出标注统计报表
- 【技】**能从统计结果中发现异常**——某类标签占比异常高 / 某批次完成量异常低 / 出现规范外的标签取值

### 课题 3-1 智能系统基础操作（4 学时）

- 【知】能说明智能系统的基本组成与常见界面功能分区
- 【技】**能够进行智能系统开启**：登录、权限确认、环境与服务状态检查
- 【技】**能够简单使用智能系统**：数据导入导出、任务创建与领取、提交与保存、结果查看
- 【技】能识别常见操作异常（登录失败、上传失败、任务无法提交、页面无响应）并按流程上报
- 【素】**操作前确认当前处于哪个环境**（测试 / 生产），避免误操作真实数据

### 课题 3-2 智能系统维护与运行记录（2 学时）

- 【知】能说明运行记录的作用：问题可追溯、异常可复现、绩效可核查
- 【技】**能够记录智能系统功能应用情况**：功能使用时间、使用内容、运行是否正常、异常现象描述
- 【技】**能够记录智能系统应用数据情况**：处理数据量、完成量、异常数据量及其类型
- 【技】能填写规范的运行 / 维护记录表，做到**要素齐全、描述具体、时间准确**
- 【素】**异常描述要写现象不写结论**——写"点击提交后页面提示 500，重试 3 次均失败"，而不是写"系统坏了"

## 五、教学条件要求

**场地**：计算机机房，每人一机；视觉标注课题建议配备鼠标（触控板不利于精细框选）。

**软件环境**（详见 `../公共资源/环境搭建指南.md`）：

- Python 3.11、Jupyter Notebook
- pandas 2.x、numpy、matplotlib、openpyxl、pillow
- Excel 或 WPS
- 数据库客户端（任一支持 SQL 的工具，用于课题 1-2；本资料提供 SQLite 练习库，无需安装服务端）
- 标注工具（任选一款开源工具用于演示，如 LabelImg / Label Studio；**具体工具界面操作因考区而异，本课程讲方法与规范，不绑定工具**）
- 音频播放与查看工具（课题 2-4）

**数据与教具**：`../五级-初级工/数据集/`（由 `../公共资源/生成数据集.py` 生成）；投影设备；采集实操所需的手机 / 相机 / 录音设备（可用学员自带设备）。

## 六、考核方式与评分

### 理论知识考试

- 形式：闭卷机考
- 本资料题库：单选 140 + 多选 30 + 判断 30 = 200 题，另配 100 题模拟卷
- 内容分布（参考权重，**非国标原文数值**，来源见 `../00-国标对应表.md` 第五节）：职业道德与法规 10%、基础知识 15%、数据采集和处理 25%、**数据标注 35%**、智能系统运维 15%

### 操作技能考核

- 形式：现场 / 模拟操作，4 道题，各 25 分，共 100 分，120 min
- 本资料提供 6 道全真格式实操题：

| 编号 | 试题名称 | 对应国标 | 考核时间 | 配分 |
|---|---|---|---|---|
| 五-1 | 商品图像原始数据采集与归档 | 1.1 业务数据采集 | 20 min | 25 |
| 五-2 | 销售业务数据整理归类与汇总 | 1.2 业务数据处理 | 25 min | 25 |

- 每题含场地设备要求、试题正文（分小问标配分）、评分表、参考答案（含可运行代码）

### 常见失分点（授课时须反复强调）

1. **漏标** —— 一张图里有 5 个目标只框了 3 个，是视觉标注最高频扣分项。
2. **标签误用** —— 没吃透规范里相近类别的区分点，凭感觉选。
3. **边界样本自行发挥** —— 规范没写的情形自己定了个标准，还标得很"一致"。
4. **格式不合规** —— 文件命名、编码、保存格式不按要求，内容对了也扣分。
5. **不做自检就提交** —— 导出后不核对行数、不检查有无空值和非法标签取值。
6. **超时** —— 实操题时间紧，平时练习必须计时；先把所有小问做完，再回头精修。
7. **覆盖原始数据** —— 清洗时直接在原文件上改，无法回溯。

## 七、与四级的衔接

本级是四级的直接前置。对应关系：

| 五级（做） | → | 四级（审 + 优化） |
|---|---|---|
| 课题 1-1 / 1-2 数据采集 | → | 四级课题 1-1 / 1-2 数据质量检测 |
| 课题 1-3 / 1-4 整理归类与汇总 | → | 四级课题 1-3 / 1-4 处理方法优化与建议书 |
| 课题 2-2～2-4 标注实操 | → | 四级课题 2-3 / 2-4 标注数据审核与纠错 |
| 课题 2-5 分类与统计 | → | 四级课题 2-1 / 2-2 聚类分析与标签体系设计 |
| 课题 3-1 / 3-2 系统操作与记录 | → | 四级课题 3-1 / 3-2 系统维护部署与功能优化 |

**先把五级的"做"练扎实，四级的"审"才有判断依据**——没亲手标过几千条数据的人，审不出标注员为什么会在某类样本上集体出错。
