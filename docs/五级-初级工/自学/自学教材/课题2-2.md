## 写在前面：这节课要解决什么问题

前面的课题练的是"识别数据有没有问题"，这一课要换一个角色：你要亲手完成一批**规模化的标注任务**——200条商品评价的情感标注。这是你第一次在真实工作量下做标注，表面上看是个熟练度练习，但真正的考点不在"标得快不快"，而在一件更容易被忽视的事上：

**标到第150条、已经有点累的时候，遇到一句话怎么标都说得通，你会怎么做？**

多数零基础的人在这种时候会凭感觉随手定一个标签继续往下标，觉得"反正差不多""不然问谁去"。这一课就是要告诉你：这个"凭感觉随手标"的瞬间，恰恰是整个标注工作里最容易出问题、也是考试最爱考的坑。本课题会带你搞清楚三件事：标注任务到底分几类、遇到拿不准的样本该走什么流程、以及为什么连"评分"这种看起来很客观的数字，都不能当作抄近道的依据。

## 学习目标

读完本课题，你应该能够：

1. 说清常见文本标注任务类型——**文本分类、命名实体识别（NER）、序列标注/槽位标注**——并能说出三者标注对象的本质区别（整体 vs 局部）；
2. 说明标注规范对保证多人标注一致性的作用，以及"待裁定"标签存在的意义；
3. 说明实体边界切分、嵌套实体的处理依据是**规范而非个人语感**；

5. **在标注过程中准确识别"规范未覆盖的边界样本"，并按规定流程记录与上报**，不自行决定。

## 一、常见文本标注任务类型

标注员做的不只是"判断情感积极消极"这一种活。实际工作里，文本标注常见有三大类任务，**标注对象完全不同**：

| 任务类型 | 标注对象 | 典型场景 |
|---|---|---|
| **文本分类** | 给**整段文本**打一个类别标签 | 本课题的情感分类（积极/消极） |
| **命名实体识别（NER）** | 框出文本中的**局部实体片段**（人名/地名/机构名等） | 识别客服对话里的机构名、人名 |
| **序列标注/槽位标注** | 标出一句话里用户想查询的**具体片段** | 对话系统中标出"帮我查一下北京到上海的高铁"里的出发地/目的地 |

**这三类任务最核心的区别是什么？**先自己想一下，再往下看。

文本分类是对"整段话"下一个判断；NER和槽位标注是对"这段话里的某一小片段"下判断。**标注对象是整体还是局部，就是最核心的分界线**——这也是为什么本课题实操重点练文本分类：它是三类里标注对象最整体、判断成本最低的一种，适合作为零基础的起步任务。

### NER 的难点：实体边界

看这句话：**"北京大学第三医院"**。有人会把它整体标成一个机构实体，有人会拆成"北京大学"+"第三医院"两个。这句话到底该怎么标？

不是看哪个标注员语感更好，**是看标注手册有没有明确的切分规则**。手册写"医疗机构全称整体标注"，所有人就该标一个；手册没写，分歧就会一直存在，谁标的都"说得通"。这和课题2-1讲过的概念是一回事——这属于"标准不一致"问题，**根因在手册，不在数据本身**。

再练一个类似的句子巩固一下："上海交通大学附属瑞金医院的专家出诊时间请查官网"——这句话里"上海"这个地名，其实是嵌套在机构名里面的，这就引出下一个概念。

### 更复杂的情形：嵌套实体

"北京大学第三医院"这个机构名里，其实也嵌着"北京"这个地名——一个实体名字里包含了另一个实体，这叫**嵌套实体**。要不要把内部的"北京"也单独标出来？

答案同样不是凭感觉，**是看标注手册对嵌套实体有没有专门规则**——有规则就按规则标（比如规定"只标最外层机构实体，内部地名不单独标"）；**没规则就是边界样本，记录上报**，不是自己拍板决定一个处理方式然后继续标下去。

### 多标签：一条文本可以有不止一个标签

还有一种常见情形：一条文本同时命中多个类别。比如"这个产品质量不错，但是物流太慢了"这句话，如果任务要求同时标出"产品质量"和"物流体验"两个维度，就各给一个标签——这叫**多标签标注**，和只能选一个类别的**单标签标注**是两种不同的模式。

标注任务开始前必须先确认当前是单标签还是多标签模式，**不能标到一半自己改规则**，否则前后标注的口径会不一致。如果规范没有明确说清楚这是不是多标签任务，正确做法同样是**先确认任务模式，不确定就上报，不能自己默认**一种处理方式往下标。

> 🔑 **判别口诀**：拿到一个标注任务先问自己——"我在判断的是整句话，还是句子里的某个片段？"整句话→分类；片段→NER/槽位。再问一句"边界/嵌套该怎么切？"——答案永远是看手册规则，不是看语感。

## 二、最重要的一条原则：遇到边界样本，记录上报，不自行发挥

刚才看到，不管是情感分类还是实体边界，判断依据最终都指向同一个东西——**标注规范**。现在讲清楚：遇到规范没覆盖的情形，到底该怎么办？

标注200条评价的过程中，你一定会遇到规范没有明确覆盖的情形（比如混合情感的评价，或者"还行吧，一般般"这种态度不明朗的评价）。很多人第一反应是："规范没写，那我自己判断一个合理的处理方式不就行了？反正我是按常理来的。"

**先自己想一想，这个想法错在哪里，再往下看答案。**

### 为什么不能自行发挥？——说机制，不说现象

原因有两层，**缺一不可**：

> **第一层**：你凭常理判断的标准，和写规范的人心里想的标准，**不一定是同一个标准**。你的个人判断可能和规范制定者的意图不一致，标的方向本身就可能错了。
>
> **第二层，也是更隐蔽的一层**：哪怕你标得"自洽"（自己前后一致），**别的标注员遇到同类情形会有不同的"自洽"**——于是同一类样本在不同人手里得到了不同标签。模型训练时看到的就是互相矛盾的信号，等于白白制造噪声。

设想一下：假设这批数据有5个标注员，各自给模糊样本定了不同的个人标准，标出来的数据会是什么样子？答案是——同一类情形，在数据集里会出现好几种互相矛盾的标签，模型根本学不出一个稳定的判断逻辑。

更麻烦的是：如果你已经按自己的标准批量标了几十条，后面发现判断方向错了，**这几十条全部要返工**——这比一开始多花几秒钟上报，代价大得多。

> 📌 **"待裁定"标签的真正作用**：它不是摆设，而是把**个人判断权限止在规范边界内**的机制。流程是：**规范未覆盖 → 标记"待裁定" → 记录原文 → 课后统一提交讨论裁定 → 裁定结果补回规范**，成为以后同类样本的处理依据。

> 🔑 **判别口诀**：标到第150条觉得累了，遇到一句话怎么标都说得通——**先标"待裁定"记下原文，再继续往后标**，不要为了赶速度自己拍板。

## 三、评分能不能代替情感判断？——用真实数据验证开篇判断

现在回到开头那个判断：标情感标签时，能不能图省事直接参考评分？

**答案是不能。而且后果比想象的严重。**

对 `reviews_to_label.csv` 这200条数据做一次统计会发现：

| 现象 | 实测数字 |
|---|---|
| 文字内容情感方向与评分方向**相反**的样本 | **65 / 200（32.5%）** |
| 模板文案"还行吧，一般般"在数据中出现的次数 | **8次** |
| 这8次对应的评分 | **从1星到5星都有**（1、2、3、3、4、5、5） |

**这说明什么？**

- 约**三分之一**的评价，用户打的星级和他留下的文字内容实际表达的情感方向是**相反**的——评分高但文字在抱怨（比如开头那条"客服一直不回复，态度差"打了4星），或者评分低但文字在夸。如果图省事直接拿评分当情感标签，这部分会被**整体标反**，而且因为是"按规则批量处理"，这种错误很难在标注环节被自己发现。
- "还行吧，一般般"这句话，不同用户打出了从1星到5星的全部区间。**同一句话，不同人读出来的情感方向完全不一样**，说明这句话本身的情感**就是模糊的**，不是哪个标注员"没读懂"，而是它客观上无法仅凭字面确定积极还是消极，应该交给判断规则或直接标"待裁定"。

> 🔑 **判别口诀**：情感标签**看文字内容，不看评分数字**。评分是用户自己打的星级，和文字真实表达的态度经常对不上；标注时只认"评价内容"这一列，评分不作参考依据。

**回到开头的判断**：直接按评分标情感标签不靠谱——这不是"偶尔会错几条"的小概率问题，而是**接近三分之一的数据会被系统性标反**的严重问题。

## 四、实操任务：完成200条商品评价情感标注

理论讲完了，现在轮到你亲手标一遍——这是本课题认知冲突真正落地的地方，光看文字讲解体会不到"疲劳递减"这件事有多真实。

**任务**：打开 `数据集/reviews_to_label.csv`，用 Excel 或 WPS 表格即可，不需要写代码。对照下面的标注规范，在"情感标签"这一列填"积极"/"消极"/"待裁定"，200条全部标完。

**标注规范（节选，与操作技能题五-4一致）**：
- 积极 = 对商品/服务整体持肯定态度；消极 = 持否定态度
- 遇到混合情感、无法判断的样本，标记为"待裁定"，不得自行决定
- **标注依据是"评价内容"这一列本身，不是"评分"这一列**

**自我监督要点（没有老师在旁边巡回提醒，自己要盯住这几条）**：

1. 如果发现自己标注速度突然变快，很可能是在凭惯性快速打标——随机回头抽查最近10条，确认有没有该标"待裁定"而漏标的情形。
2. 标注过程中如果发现自己反复在"评价内容"列和"评分"列之间对照、犹豫，提醒自己：只看文字内容，评分不作参考。
3. 拿不准的样本先标"待裁定"继续往后做，不要卡在一条上纠结太久——但要同时记下原文，整理成一份"待裁定清单"。
4. 标到后半段（比如第150条以后）尤其要警惕：这正是疲劳感最强、最容易"随手标一个"的阶段，也是本课题开篇认知冲突真正发生作用的地方。

**产出**：200条标注结果 + 一份"待裁定"样本清单（含原文）。标完后，用第三节的真实统计数字对照一下自己的标注结果，看看自己有没有把评分和文字内容对不上的样本标反。

## 五、标注完成后：三个典型错误自查

标完之后，不要觉得"标完了就万事大吉"，对照下面三种典型错误自己复查一遍——这些都是零基础学员最容易踩的坑：

| 典型错误 | 应诊断出的问题 |
|---|---|
| 把"客服一直不回复，态度差"（评分4星）标成"积极" | 误用评分代替文字内容判断，应依据文字内容判为"消极" |
| 把"还行吧，一般般"统一按同一个标签处理（如全标"积极"） | 该文案本身模糊，不同场景含义不定，拿不准应标"待裁定"而非强行统一处理 |
| 标注到第180条左右，连续多条未经仔细阅读就标同一标签 | 疲劳导致的"凭惯性标注"，应放慢速度或留意自己的标注节奏 |

复查时问自己：**我标的依据是手册规则，还是个人语感/图省事的捷径？**这句自问同样适用于前面讲的实体边界、嵌套实体——判断依据永远是同一个东西。

## 九、小结

| 要点 | 一句话 |
|---|---|
| 三类标注任务 | 文本分类（整体）/ NER（局部片段）/ 序列标注（具体查询片段） |
| 实体边界/嵌套实体怎么判 | 看手册规则，不看语感；没规则就上报 |
| 核心原则 | 边界样本记录上报，不自行发挥 |
| 不能自行发挥的两层原因 | 个人判断可能偏离规范意图；各标各的会让模型学到矛盾信号 |
| 情感标签依据 | 看文字内容，不看评分数字 |
| 本课题最大的提醒 | 拿不准的时候，交给规则和流程，而不是交给自己的直觉或一个看似能走捷径的数字字段 |

## 十、自测练习（含完整参考答案）

> 这是一份自学材料，答案直接写在题目下方，不做折叠隐藏。**请先自己独立作答、写下你的答案，再往下看参考答案核对**——这一步不能跳过，否则起不到检验学习效果的作用。

**练习 1**：标注过程中遇到一条规范没有明确覆盖的评价，正确的处理方式是什么？

**参考答案**：标记为"待裁定"，记录该样本原文，提交给项目负责人或规范制定者统一裁定，而不是自己凭感觉定一个标准继续往下标注。裁定结果应该补充进标注规范，作为后续同类样本的处理依据。

**练习 2**：为什么标注到后面越来越累的时候，更要坚持"遇到不确定的就上报"这个原则？

**参考答案**：因为疲劳状态下最容易为了赶速度而随意决定边界样本的标签，而这种"随手标"的判断往往缺乏一致性——同一个人在不同时间、不同人之间对同类边界样本的判断可能完全不同。这种不一致会直接污染训练数据，而且因为标注员自己"标得很一致"（都是自己随手定的），这种问题在后续质检中反而不容易被发现。

**练习 3**：实体边界切分规则的作用是什么？举例说明。

**参考答案**：实体边界切分规则规定了命名实体的标注范围该切多宽，保证不同标注员对同一类实体的标注一致。例如"北京大学第三医院"这个机构名，规则需要明确规定是整体标注为一个机构实体，还是拆分成"北京大学"+"第三医院"两部分，这个规则必须写入标注手册并严格遵守，不能凭标注员个人感觉决定。

**练习 4**：命名实体识别（NER）和文本分类的标注对象有什么不同？

**参考答案**：文本分类是给整段文本打一个类别标签（如判断整条评价是积极还是消极）；命名实体识别是在文本中框出具体的实体片段（如人名、地名、机构名），标注对象是文本中的局部片段而非整体，标注难度和精细程度通常更高。

**练习 5**：多标签标注和单标签标注的处理方式有什么区别？

**参考答案**：单标签标注要求每条样本只能归入一个类别；多标签标注允许一条样本同时具有多个标签（比如一段文本既涉及价格又涉及质量）。标注时须按照规范明确当前任务是单标签还是多标签模式，不能混淆处理方式，否则会导致标注结果不一致。
