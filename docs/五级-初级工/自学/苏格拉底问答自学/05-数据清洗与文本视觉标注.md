## 第一节：数据标注之前，先把"脏"的部分洗掉

### 清洗到底要解决什么问题

老师开门见山问你：如果让你自己总结，数据清洗要去掉哪几类问题？

答案：**去重复、去缺失、去异常、去噪声、统一数据格式**。这五类是清洗要解决的核心内容，不同数据类型（文本/视觉/语音）体现的具体形式不同，但都归属这五大类。

### 一份625条评论数据的实测清洗

```python
import pandas as pd
df = pd.read_csv("../数据集/reviews_raw.csv")
n_raw = len(df)

print("重复行:", df.duplicated().sum())
print("空/空白评价:", df["评价内容"].astype(str).str.strip().eq("").sum())
print("含HTML:", df["评价内容"].astype(str).str.contains("<").sum())
print("非法评分:", (~df["评分"].between(1,5)).sum())
```

实测：共625条记录，**重复行25条、空/空白评价10条、含HTML标签30条、非法评分12条**（评分字段正常取值应为1-5）。

老师追问：**重复记录为什么必须去掉，不是"多几条也无所谓"吗？**

重复记录会导致模型在训练时对该样本的表述过度学习，造成局部过拟合；而且重复数据还会虚增数据量，影响后续基于数据量的统计和分析结果的准确性。非法评分同理——0分或6分都不在规定范围内，很可能是录入错误或系统异常，保留会给统计分析带来错误信息。

清洗代码：

```python
df = df.drop_duplicates()
df["评价内容"] = df["评价内容"].astype(str).str.replace(r"<[^>]+>", "", regex=True)
df = df[df["评价内容"].str.strip() != ""]
df = df[df["评分"].between(1, 5)]

df.to_csv("reviews_cleaned.csv", index=False, encoding="utf-8-sig")
print(f"清洗前 {n_raw} 行 → 清洗后 {len(df)} 行")
```

### 一条铁律：原始数据绝不能覆盖

老师指着这行代码问你：`df.to_csv("reviews_cleaned.csv", ...)` 和 `df.to_csv("reviews_raw.csv", ...)`，如果你不小心写成了后者，会发生什么？

**清洗是不可逆操作**。如果直接在原文件上修改保存，一旦清洗规则本身有问题（比如误删了本该保留的样本），就再也无法恢复原始数据重新处理。所以无论做什么清洗操作，都要先把原始文件保留好，清洗结果另存为新文件——这是整个清洗环节唯一一条"绝对不能破例"的规则。

### 换成图像和语音，清洗的思路一样吗

文本清洗讲完了，老师带你快速过一遍另外两种数据类型：

- **视觉清洗**：剔除损坏/重复/模糊/过曝图像，统一分辨率与格式，核对图像与标注文件的对应关系
- **语音清洗**：剔除静音/截断/底噪过大的音频，统一采样率与格式，核对音频与文本的对应关系

表现形式不同，但本质还是"去重复、去缺失、去异常、去噪声、统一格式"这五类问题在不同数据类型上的具体化——这和 03 篇讲"采集质量问题可以迁移到图像/音频/日志"是同一个思考方式：**原则不变，变的只是检查清单的具体内容。**

## 第二节：文本标注——最重要的不是标得快，是遇到拿不准的样本怎么办

### 常见文本标注任务类型，先分清它们标的是什么

老师列出三类任务，让你先猜每一类"标注对象"是什么：

- **文本分类**：给整段文本打一个类别标签（情感、意图）
- **命名实体识别（NER）**：框出"人名/地名/机构名"等实体片段，标注难点在**实体边界**——比如"北京大学第三医院"该整体标还是拆开标，必须依规范而非凭感觉
- **序列标注/意图槽位**：标出客服对话中用户想查询的具体内容

文本分类标的是"整段文本的归属"，NER 标的是"文本里的局部片段"——标注对象的粒度不一样，标注难度和精细程度自然也不一样。

### 真正的核心原则：遇到边界样本，记录上报，不自行发挥

老师给你一个任务场景：对200条评价按情感标签（积极/消极）标注，标注过程中一定会遇到规范没有明确覆盖的情形，比如一条混合情感的评价——"东西质量一般，但客服态度特别好"。

**先别往下看，自己想一想：如果你是标注员，遇到这种情况会怎么处理？**

正确做法是：标记为"待裁定"，记录原文，课后统一提交讨论上报，**不自行决定一个标准然后继续往下标**。

老师追问三层"为什么不能自行发挥"：

- 你的个人判断可能和规范制定者的意图不一致；
- 如果你自己定了一个标准，并且用这个标准标注了几十条类似样本，一旦判断方向错了，这几十条数据全部要返工；
- 更严重的是：**其他标注员可能对同类情形有不同的理解**，大家各标各的，模型学到的就是互相矛盾的信号。

这正是 01 篇讲"职业守则"时埋下的伏笔——自己定标准往下标,和"赶进度不核对"是同一类危险：犯错的人自己是"一致"的，常规质检反而很难发现。而且老师会提醒你一个反直觉的场景：**标注到后面越来越累的时候，更要坚持这条原则**。因为疲劳状态下最容易为了赶速度随意决定边界样本的标签，这种"随手标"往往缺乏一致性，同一个人在不同时间都可能判断不同，但这种不一致会被质检漏掉，因为标注员自己心里觉得"我每次都这么判断，挺一致的"。

实体边界切分同理——"北京大学第三医院"该整体标还是拆开标，这个规则必须写进标注手册并严格遵守，不能凭标注员个人感觉决定。

## 第三节：视觉标注——框选质量比你想象的更容易踩坑

### 三类常见任务，精度要求完全不同

- **图像分类**：给整张图打标签
- **目标检测（Bounding Box）**：框出图中物体的矩形框位置
- **语义/实例分割**：给图像每个像素打类别标签，精度要求比画框高得多

### 框选质量标准，老师用三句话帮你记住

- **贴合物体边缘**：不大不小，不留多余空白，也不切掉物体的一部分
- **不遗漏**：一张图里有几个目标就框几个，密集小目标也不能因为嫌麻烦而漏框
- **不重复**：同一个物体不要重复框选

老师追问一个本质问题：**为什么"框偏一点"不是美观问题，而是会直接影响模型精度？**

目标检测模型是通过学习标注框的位置坐标来判断物体在图像中的位置，标注框如果偏大、偏小或偏移，模型学到的"物体应该在哪里"这个判断标准就会跟着偏差——这不是审美层面的瑕疵,是直接影响下游模型定位精度的核心因素。

### 三种特殊情形，怎么处理才对

| 情形 | 正确做法 |
|---|---|
| 物体部分被遮挡 | 按可见部分框选，不猜测被遮挡部分的范围 |
| 密集小目标 | 逐个框选，不因为小而遗漏 |
| 模糊目标 | 若无法确定类别，标记为"存疑"而非强行归类 |

老师出一道题检验你是否真的理解了"遮挡"这一条：**物体被部分遮挡时，能不能凭经验猜测被遮挡部分大概是什么形状，把框画得"完整"一点？**

不能。猜测补全的边界不准确，反而会引入错误的位置信息，不如老老实实按实际可见的轮廓框选。同理，遇到模糊、无法确定类别的目标，也不应该强行归类到最接近的类别——强行归类可能引入错误的标签信息，标记"存疑"能让后续审核环节知道这是需要特别关注的样本，而不是把不确定的判断悄悄混入正常数据中。

核心素养一句话收尾：**宁可慢一点标准确，也不要为赶量粗框。**
