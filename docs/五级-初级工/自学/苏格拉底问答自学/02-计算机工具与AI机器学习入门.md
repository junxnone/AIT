## 第一节：工具是用来干活的，先别纠结"要不要学编程"

很多零基础学员一听到"Python环境""Jupyter"就开始紧张：我是来做标注的，为什么要学编程？

老师会先给你定一个心态：**这门课不要求你成为程序员，只要求你能用工具把"整理归类汇总"这件事做得又快又准**。接下来带你过一遍这份职业最常用的几个工具动作。

### Excel 四个核心函数，你真的分得清吗

老师列出四个函数，先不给解释，让你自己猜一猜每个是干什么的：`IF`、`COUNTIF`、`SUMIF`、`VLOOKUP`。

猜完了吗？公布答案：

| 函数 | 作用 |
|---|---|
| `IF` | 条件判断 |
| `COUNTIF` | 按条件计数 |
| `SUMIF` | 按条件求和 |
| `VLOOKUP` | 按条件查找匹配值 |

这里最容易被考试盯上的坑是**混淆 `COUNTIF` 和 `SUMIF`**——前者回答"有多少条满足条件"，后者回答"满足条件的这些数加起来是多少"。记混的根源往往是没有在心里问清楚自己到底想要"个数"还是"总额"。配合数据透视表，这四个函数基本能应付日常的数据整理归类与汇总任务。

### Python 环境到底在装什么

老师不会让你死记安装步骤，而是先问一句：**你觉得"安装 Python"和"打开 Jupyter 跑代码"之间，中间还缺了什么环节？**

答案是"安装依赖包"。完整链条是：安装 Python → 安装依赖包 → 打开 Jupyter Notebook → 运行代码。很多新手卡住的地方恰恰是跳过了第二步——代码里用到的工具包（比如处理表格的 pandas）必须先用 `pip install` 装好，环境才能跑起来。

### 报错不可怕，可怕的是不会读报错

老师会出一道实战题：你跑代码时屏幕弹出一长串红色文字，第一反应是什么？

如果你的第一反应是"完了看不懂，算了"，这正是最该纠正的习惯。老师教你一个诀窍：**Python报错信息通常最后一行才是最关键的**——错误类型加简要原因，前面一长串是"报错是怎么一步步发生的"调用链，初学阶段可以先跳过，直接看最后一行。

三类最常见的报错，试着自己先猜原因再看答案：

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError` | 包未安装 | `pip install` 对应包名 |
| `FileNotFoundError` | 文件路径或工作目录不对 | 核对相对/绝对路径 |
| `UnicodeDecodeError` | 编码格式不匹配 | 尝试指定 `encoding="gbk"` 或 `"utf-8"` |

注意第一个报错有一个隐藏陷阱：如果你明明已经 `pip install` 过还是报这个错，大概率不是没装，而是**装到了别的 Python 环境里**，当前运行的环境和你装包的环境对不上。

## 第二节：人工智能、机器学习、深度学习——三个圈到底怎么套

### 先做个判断

老师给你摆三个生活中的例子，全部都打着"AI"的旗号：

① 手机人脸解锁——用大量"人脸照片+身份标签"训练出一个模型，判断"这是不是机主本人"；
② 购物APP把用户自动分成"价格敏感型""品牌忠诚型"几类，但没有人提前告诉系统该怎么分；
③ 扫地机器人刚买回家总撞墙，用几天后会自己学会绕开障碍物。

**先别往下看，花一分钟判断：这三个功能背后是不是同一种学习方式？如果不是，差别在哪？**

写下你的判断，我们一步步拆解。

### 三个圈的包含关系

老师先画三个大小不同、层层嵌套的圈：**人工智能 ⊃ 机器学习 ⊃ 深度学习**。

接着追问：既然机器学习是人工智能的一部分，是不是所有人工智能都得靠机器学习实现？

不一定。像早期红绿灯自动配时系统、"你问退货就自动回复退货流程"这类功能，靠的是人提前写好的"如果…就…"规则，并没有从数据中"学"规律的过程——这也算人工智能的一种（自动做出"智能"反应），但不是机器学习。

反过来问：机器学习里是不是所有方法都叫深度学习？

也不是。决策树、线性回归、支持向量机这些"老资格"方法不用神经网络，照样能从数据里学出规律。深度学习特指用"多层神经网络"学习的那一类方法，是机器学习大家族里的一个分支。

判别口诀：一个系统是不是靠"人提前写死规则"运行的？是 → 可能是AI但不是ML；是不是从数据里"学"出规律，还用了多层神经网络？是 → 才是DL。

### 两个判别问题，套进任何AI任务都能分出范式

老师给你两把尺子，不要求你死记三大范式的定义，而是学会用这两个问题去套：

> **问题一**：这个任务有没有人工给出的"标准答案"（标注）？
> **问题二**：如果没有标准答案，学习信号是从数据自己的结构里来，还是从外部一次次的反馈（奖励/惩罚）里来？

现在回到开头三个例子，自己动手把这张表填出来，再对照答案：

| 场景 | 有没有标准答案 | 信号来源 | 范式 |
|---|---|---|---|
| ① 人脸解锁 | 有——人脸照片+身份标签 | 人工标注 | 监督学习 |
| ② 用户自动分群 | 没有，没人提前定好分几类 | 数据自身结构 | 无监督学习 |
| ③ 扫地机器人学走位 | 没有固定答案 | 环境即时反馈（撞墙/顺利通过） | 强化学习 |

揭晓开头的判断：三个功能**不是同一种学习方式**，分别是监督学习、无监督学习、强化学习。

### 两个最容易判断错的陷阱

老师专门提醒两个高频误判：

**误区一**：把"用户自动分群"误判为监督学习，理由是"系统也在'学'用户特征"。
纠正方法：学习≠监督学习，问自己——有没有人提前告诉系统"这个用户该归为哪一类"？没有，就不是监督学习。

**误区二**：把"扫地机器人学走位"误判为无监督学习，理由是"也没有标注答案"。
纠正方法：扫地机器人撞墙后立刻"知道"这样不对，这个"知道"就是即时反馈信号。**有没有即时反馈信号，是强化学习和无监督学习的分水岭。**

判别口诀收尾：先问"有没有标准答案"——有 → 监督学习；没有，再问"有没有即时反馈信号"——有 → 强化学习，没有 → 无监督学习。

**检验一下迁移能力**：系统根据历史交易记录，自动识别出一批"可能存在欺诈"的异常订单，这些订单之前没有任何人标注过"是不是欺诈"。套用两个问题自己判断一下——没有标注答案，排除监督学习；没有即时反馈信号，是从数据本身找出"不正常"的结构——答案是无监督学习。

## 第三节：标注质量为什么重要——从结论到机制

### 回顾一个你已经知道的结论

01 篇里提过"标注错一次，模型就学错一次"，这里要往下挖一层：**模型内部到底发生了什么？**

监督学习模型训练的过程，简单说是：模型先对一个样本做出自己的判断，拿这个判断去跟标注好的标准答案比较，发现差距后朝"缩小差距"的方向调整自己内部的判断规则。这个过程在成千上万条样本上反复进行。

关键在这里：**模型调整的方向，完全是由标注这个"标准答案"决定的**。标对了，模型朝正确方向逼近；标错了，模型调整方向也跟着错，而且这种错误很难在训练阶段被发现，往往要到模型上线后才暴露。

### 一个容易想错的追问：错误占比很小，是不是就没事

老师出一道题：假设训练数据有10万条，其中只有50条标错了，占比0.05%，是不是就不用管了？

**不能一概而论，要分两种情况看**：

| | 随机噪声 | 系统性错误 |
|---|---|---|
| 表现 | 标注员纯粹手滑，错误随机散落 | 对某一类样本理解有偏差，持续、稳定标错成同一个方向 |
| 对模型的影响 | 被大量正确样本"投票"稀释掉 | 不会因为数据量大就消失，反而被当成"稳定规律"学进去 |
| 能否靠数据量大解决 | 可以 | 不可以 |

"占比只有0.05%，数据量这么大肯定没事"这句话只在"错误是随机的"这个前提下成立。如果错误是系统性的，哪怕占比再小，也会被模型稳定地学进去，变成固定偏见。

判别口诀：错误是随机散落的 → 数据量大可以稀释；错误是朝着同一方向反复出现的 → 数据量再大也救不了，必须从规范源头修。

### 不同任务，标注形式必须精确匹配

老师再抛一个问题：标注质量这么关键，是不是只要"标得认真"就够了？

还不够——**标注形式必须精确匹配模型要学习"预测什么"**，形式不对，标得再认真也没用。

| 任务类型 | 所需标注形式 | 为什么必须是这种形式 |
|---|---|---|
| 图像分类 | 整图打一个类别标签 | 模型只需回答"这张图是什么" |
| 目标检测 | 画框标出物体位置 | 模型要回答"东西在哪"，只给类别标签教不会位置 |
| 文本分类 | 整段文本打一个类别标签 | 与图像分类同理 |
| 语音识别 | 音频转文字 | 要把连续声音转成文字序列，一个标签表达不了 |

追问加深理解：如果给目标检测任务只标一个"图里有猫"的类别标签，不画框，模型能学会"猫在哪个位置"吗？——不能，标注里根本没有位置信息，模型无从学起。判别口诀：模型要输出什么形式的答案，标注就必须提供那个形式的标准答案，形式不匹配，标了也白标。

### 最后澄清一个误解：无监督学习是不是不用人介入了

无监督学习不需要人工标注"标准答案"，是不是训练师在这个环节完全不用管了？

不是。系统自动分出的群体（比如把用户分成5群）对公司运营有没有实际业务意义，仍然需要训练师判断。监督学习里训练师的价值体现在"标注"；无监督学习里训练师的价值转移到了"判断结果是否有意义"——**不同范式里具体工作不一样，但"人的判断"从来没有消失**。

## 自测问题

1. 一个系统根据用户近期浏览和购买记录，自动把促销券发放策略拆成多个版本做AB测试，并根据每个版本带来的实际转化率动态调整发放策略。请用本篇的"两个判别问题"判断它属于哪种学习范式，并说明判断依据。
2. 假设你发现某批10万条训练数据里有200条标注错误（占比0.2%），你会先问哪个问题来判断这是否值得警惕？为什么"占比小"不能直接作为"不用管"的理由？
